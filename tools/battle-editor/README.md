# 夜鸦 · Godot 修改器

以 E 盘 Vue / Pixi 修改器为基础，加入动作逐帧编辑、素材替换和 C 盘战斗参数。它与 Godot 游戏共同使用 assets/data/battle.json，工作区单独保存在 assets/data/editor-project.json。

## 打开

双击工程根目录的 OPEN_MODIFIER.bat。服务只监听本机 http://127.0.0.1:4329/。启动脚本复用已有服务；只有前端源码更新才重新构建。

## 常用操作

- 动作工坊：播放、暂停、逐帧查看，拖动当前帧位置，调整尺寸和播放速度，导入 PNG 文件夹或精灵图集。
- 素材工坊：画笔、擦除、裁剪、调色和另存；将结果替换到动作工坊当前帧。
- 战斗参数：伤害、动作速度、命中帧、接招帧、命中范围、击退、蓄力和远射。
- 场景画布：查看原角色与木桩，拖动出生点，调整训练场边界和颜色。
- 打击感：命中停顿、震屏、受击闪白和形变强度；控制保存后自动应用。
- 备份与回收站：恢复保存前的版本。恢复后还需保存才能应用到游戏。

顶部“保存并打开游戏”直接启动 Godot；游戏已打开时显示“保存并刷新游戏”。保存后自动重置训练并应用新配置。

Ctrl+S 保存；Ctrl+Z / Ctrl+Y 撤销与重做。画笔或裁剪导出不会覆盖原图；使用中的动作图片受删除保护。

## 开发验证

在本目录运行 E:\npm.cmd run build。在工程根目录运行 E:\node.exe tests/test_editor.mjs，该测试会暂时修改配置并恢复，产生备份和测试素材回收记录，不能与人工调参同时运行。

完整用户说明见工程根目录 README.md，开发交接见 docs/开发交接.md。该修改器不依赖 Maker。
