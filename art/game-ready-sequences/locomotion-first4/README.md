# 游戏要用的跑跳序列帧

2026-10-18 补入遗漏的“前4秒”。使用本机 `mmh3_前4秒_试跑.mp4`：107 帧、24 FPS，角色更大且背景没有平台和界面图标。它不是此前六段 Krita 手修文件的一部分，也没有做 3px 像素化。

这里保留去除灰色背景后的完整尺寸透明 PNG；视频原文件没有改动。`manifest.json` 记录视频及各帧 SHA256。运行副本只裁透明边；完整107帧也在修改器动作库中保留，名为“原版_前4秒完整预览”。

游戏绑定：起跳37–42、下落43–46、落地47–50、向右跑步67–71。向左由游戏镜像显示。视频里的角色位移通过逐帧脚底原点移除，场景位移由游戏控制。

重建配置和运行裁剪图：在项目根目录运行 `python tools/art/import_first4_locomotion.py`（需要 Pillow）。可继续在动作工坊逐帧调整停留时间和位置。
