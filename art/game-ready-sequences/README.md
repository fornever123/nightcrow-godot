# 游戏要用的序列帧

**用户已选定用于后续游戏开发的素材，2026-10-17 修改完成的非 3px 原版。**

本目录共 6 段动作、880 个时间帧，角色、特效和合成图三套共 2640 张透明 PNG。保留导出后的原始尺寸、文件名、透明度和像素数据；没有再像素化或缩放。

| 动作原名 | 帧数 | 画布尺寸 |
|---|---:|---|
| 空中a | 56 | 1600 × 1600 |
| mmh3_拔刀40 | 158 | 1536 × 1536 |
| mmh3_冲刺攻击_v2 | 56 | 3072 × 960 |
| mmh3_死亡_v1 | 124 | 1536 × 1536 |
| mmh3_左侧格挡_v5 | 226 | 1792 × 1152 |
| mmh3_action_00014 | 260 | 2112 × 1152 |

每段动作的文件夹：

- `05-character/`：角色帧。
- `05-effects/`：对应的特效帧。
- `04-despill/`：角色和特效已经合成的帧。

基础帧率为 24 帧/秒。同名角色帧与特效帧对应同一时刻。接入时可选择“角色＋特效分层”或“直接用合成图”；使用合成图时应关闭额外刀光，避免重复叠加。

## 使用约定

这批素材标记为**游戏要用**。本次上传只归档素材，尚未替换游戏里的现有动作或战斗配置。后续接入应从本目录选取，按动作拆分并校准角色大小、脚底位置和命中时机。不要把之前的 3px 版本或旧 FrameBaker 手调项目当作本批素材。

`manifest.json` 记录完整帧清单和每张 PNG 的 SHA256，可检查上传或下载是否完整。`.gdignore` 用于避免 Godot 提前导入全部源帧；正式接入时再复制所需片段到运行资源目录。

可继续逐帧修改的 `.kra` 原版工程已在本机单独备份，此目录上传的是游戏使用的完整 PNG 序列。
