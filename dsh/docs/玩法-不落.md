# 玩法：**不落**（DSH 版 · 设想稿 2）

> 状态：**设想，没写代码。** 上一版「未竟」被否（“一看就不好玩”），存档在 `玩法-未竟.md`。
> 这一版只解决一件事：**每一秒手上都得有事干。**

---

## 0. 一句话

**这条街没有地面。地面是泡在雨里的光，谁碰谁被重新定住。你要踩着刚被你打上天的那群东西，一直待在上面。**

三个动作，循环到底：**挑上去 → 踩着它 → 再挑一只。**

---

## 1. 上一版错在哪

上一版把玩家的手交给了布景：断光脉是"按一下开关"，杀怪是道具替她做的，第一分钟还在走路看风景。

这一版反过来：**所有东西都得你自己打上去。杀不是目的，留在天上才是。**

---

## 2. 核心规则（五条，一眼记住）

1. **湿街是光**。地面积水是一层停住的光。怪落地 → 立刻「回光」：回 40% 血、壳变硬、脚下铺一圈 0.8 秒的冻结池；她落地 → 双腿白瓷化 1 秒、连段清零、屏幕边泛白。**落地不是死，是变难。**
2. **怪就是地**。被击飞、被打死的怪，身体是实心的。踩上去 → **重置空中跳（2 段）和空中冲刺斩（1 次）**。你的机动性靠踩别人续。
3. **打人续命**。空中每命中一下 +1 段空中跳（原版规则），打空就往下掉。
4. **天上有几只**。HUD 只有这一行字；同时空中的怪数就是分数倍率。
5. **清完一波，天才开始下雨**。那一波的光被打散了，雨落回来，她能喘一口；下一波再来。

## 3. 她的招，全部变成"起重机"和"救援"

| 招 | 在这条玩法里的活 |
|---|---|
| **W+J 上挑** | 主起重机。挑得越高，天上能待的越久 |
| **空中三连** | 一边打一边续跳，主力输出 |
| **冲刺斩** | **捞人**：横过去接住快落地的那只；也是唯一快速换位 |
| **弹刀** | **炸上天**（原版就是炸飞）：把已经落地、正在下沉的东西顶回去 |
| **S+J 下砸** | **反冲**：空中砸中怪 = 她弹起来、怪往下；用来把掉下去的砸回空中 |
| **蓄力斩（霸体）** | 挑**重怪**（坠石）唯一够得动的招；霸体让她在重力场里站住 |
| **刀气** | 够不到的那只（钉在墙上的、远处的） |
| **大招** | 全场一起抛上天：所有怪一次大冲量 + 滞空 2 秒，连段不落地 |

注意：**没有一条规则要你等**。所有招都是"现在就用"，区别只在用在哪只身上。

## 4. 怪物：全部按"怎么跟重力作对"设计

统一的视觉语法：石头/湿布/骨头，全部**重**；浮灯是唯一**轻**的东西；紫只给她。

### 4.1 坠石（引子）

矮胖石身，走得慢，**质量大**：普通三连只让它挪一步，上挑只离地一格。它会主动往台阶下跳，去砸地面。

- 落地 → 铺一圈冻结池，池子里的东西（包括她）变慢。
- **正解**：蓄力斩 / 弹刀把它炸起来，再上挑接空连。
- 教的是：**有的东西你得换招才挑得动。**

### 4.2 钩（二波）

细长、快，会飞扑到任意一只怪身上钩住往下拽。被钩的怪**重量翻倍**。

- 杀钩 → 被钩的那只被弹回空中（救命）。
- 它专门在你连段中途出现，逼你**放弃当前连段去救另一只**。
- 教的是：**优先级**。

### 4.3 浮灯（二波）

鼓胀、极轻，越打越往上飘；身体是软的，**吸收伤害**，打它像打棉花。

- 它是全场最好用的踏板：踩上去弹得很高。
- 所以它既是楼梯，也是损失（打死了就少一块楼梯）。
- 教的是：**留一只当楼梯。**

### 4.4 钉（三波）

把自己钉进地里，钉住之后从地面往天上射。

- 在空中砍它没用（钉死了），要**下砸**、**刀气**、或者用弹刀把它的钉子崩开。
- 它是"你够不到、又必须处理"的那种东西。
- 教的是：**换工具，不是换位置。**

### 4.5 牵（三波）

两只一组，中间一根光索。**一只落地，另一只被拽下去。**

- 砍断光索可以救（但两只都会失去牵引，开始各自乱跑）。
- 教的是：**先拆关系，再打架。**

### 4.6 碑（终 · Boss）

街尽头那块钉在地上的巨大石碑，四条锁链把它锁在湿街里。

- 它每 20 秒**下沉**一次：全场往下吸（重力场，滞空变短、掉落变快）。
- 四条锁链各挂一个"链锤"，是可挑飞的实体：把链锤挑起来、砸回去，断一条锁。
- 四条断完 → 碑倒下，碎成一堆浮石；二阶段：在浮石之间继续**不落地**打它的核心。
- 教的是：**把"不落"推到极限。**

## 5. 关卡与模式

- **场地**：河岸街竖起来用——台阶/河岸/廊桥本来就是三层高度，镜头跟着她上下（原版就是双轴跟随）。第二场地是钟楼前广场，更空、更高。
- **模式**：一条命，5 波 + 碑，一波 25～40 秒，整局 6～8 分钟。死了从**本波开头**重来，不是从头。
- **评分 S / A / B**：滞空秒数 + 最高连段 + **最大同时空中数** + 无落地加分。
- **重开一秒**：R 立刻重来本波，不读条。

## 6. 手感（每一帧都要有回应）

| 事件 | 反馈 |
|---|---|
| 打中 | 怪被挑上去，拖一条白气；闷响（湿布 + 石头），不是金属 |
| 踩到怪 | 一声闷响 + 她脚下一圈紫色的气垫涟漪（紫只给她） |
| 怪落地 | 玻璃落水声 + 光池铺开 + 那只怪变白变硬，动作变慢 |
| 她落地 | 双腿结霜白瓷化，1 秒不能动；屏幕边泛白 |
| 天上有 N 只 | HUD 一行字，N 越大字越亮 |
| 清波 | **雨声回来**，整条街从白变回蓝 |

---

## 7. 为什么这次"一眼好玩"

- 一句话画面：**空中十几只，她站在其中一只的头上，打另一只。**
- 每一秒都有一个手能做的决定：先挑哪只、先救哪只、踩哪只当跳板。
- 失败是看得见的、有点好笑的、而且能马上再来：全场同时掉下去，街面结霜，重开一秒。
- 它把原版已经调好的东西（击飞越来越高、空中命中给跳、弹刀炸飞、冲刺斩）**全部变成主菜**，不是加一层新规则压在上面。

---

## 8. 风险和对策

1. **单一（一直往上打）** → 五只怪的重力差异 + 每波场地抬高 + 碑的下沉压力，节奏一直在变。
2. **踩怪手感（目标太小）** → 判定放宽到 1.5 倍，脚下画一圈"气垫"，看得见踩得到。
3. **太难** → 落地只变难、不死；踩到任何东西就回满空中跳；死亡从本波开头。

## 10. 另外两个方向（如果这个还不对）

- **「提速」**：每断一次光，全世界（包括她）加速一档，靠连续出刀维持高速；慢下来就会被围死。
- **「切线」**：刀光在空中留一条 0.5 秒的光痕，怪撞上去就被切开；你画线，怪撞线。

## 11. 要你定的三件事

1. **名字**：不落 / 悬街 / 别落地。我倾向「不落」。
2. **落地惩罚的轻重**：现在定的是"变难不死"；也可以做成"落地 3 次本波失败"。
3. **竖切**：第一波 + 坠石 + 钩 + 踩怪，一场两分钟就能看出好不好玩。要不要就做这个。
