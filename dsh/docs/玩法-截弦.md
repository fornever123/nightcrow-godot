# 玩法：**截弦**（Jié Xián）—— DSH 版核心玩法

> 这是 DSH 线**新做的一版**玩法，独立于原版雨街战斗，也独立于本目录里之前的「错拍」。
> 用户要求：不落俗套、自己的创新、自己设计怪物 / 关卡 / 模式；先设想，再交付。
> 入口：根目录 `OPEN_DSH.bat` → `res://dsh/scenes/chord_trial.tscn`。

---

## 0. 一句话

**敌人的每一招，出手前都先甩出一根光弦；弦绷紧的那一瞬用刀截断，这一招就从它身上永远消失，变成你鞘里的一张牌。**

失败不是「被打」，而是「被看穿」；变强不是「数值变大」，而是**敌人会的东西越来越少，你会的东西越来越多**。

---

## 1. 方案筛选（先找最好玩的，再定）

先列了六个方向，按「和横版动作的爽感是否相容 / 读招是否清楚 / 有没有新东西 / 能不能做出曲线」四个维度筛：

| 方向 | 一句话 | 结论 |
|---|---|---|
| A 时间当货币 | 暂停时间按 HP 计费 | 节奏碎，且和原版「昼光停时」的设定撞车，弃 |
| B 刀痕即地形 | 斩击在空气里留下可站的刀痕 | 偏解谜，战斗变慢，弃 |
| C 影我 / 延迟 | 打敌人 0.6 秒后的影身 | 本目录已有「错拍」，不重复 |
| D **夺招** | 把敌人的攻击截下来变成自己的招 | **选它**：防守直接变资源，读招天然清楚，能做「敌弱我强」的曲线 |
| E 光区 / 暗区 | 只在光里能造成伤害 | 变成走位管理，爽感被抽走，弃 |
| F 节奏判定 | 按拍子出刀 | 容易变成背谱，弃 |

**D 的风险是退化成 QTE（看到提示按一下）。** 这一版用三件事把 QTE 感打掉：

1. **招是有形体的**：不是图标，是一根从敌人手里拉到你脚下的**弦**——空间上的线，要用刀锋去够。
2. **弦要绷紧才断**：前 55% 是松的，砍上去只是挥空；后 45% 才发亮可截。**越晚截，收益越高**——你必须站在弦里等。
3. **多弦要选**：同一时刻可能有两三根弦（一高一低、一左一右、一白一朱），一刀只截得断一根。站哪儿、截哪根，是每一秒都在做的决定。

参考坐标（只借思路，不借机制）：《只狼》把「防守」变成「进攻资源」；《Absolver》把招式做成可编的牌组；《洛克人》打赢 Boss 拿它的武器。
**截弦的不同点**：牌组不是战前编的，是**在战斗里从敌人身上现拆的**；敌人的血条不是血，是它**还会几招**。

## 2. 核心机制

### 2.1 弦

敌人每次攻击前，从手上甩出一根弦，钉在你**出弦那一刻**站的位置（不追踪）。弦上有一颗**拍**（珠子）朝落点走。

```
敌人手 ●━━━━━━━━━━━○─────────✕ 落点
                    ↑拍        剪口
        松（前 55%，砍不断）   绷（后 45%，可截）
```

- 弦不追人：**你走开，这一招就落空**——但你什么也得不到。
- 奖励只给「站在原地把它截下来」的人。

### 2.2 截（核心动作）

刀锋在弦绷紧后扫过弦 → **截断**。判定用刀锋的判定盒去和整条弦求交，不用点得很准。

按「拍走到哪儿」分三档：

| 判定 | 拍的位置 | 收益 |
|---|---|---|
| **断** | 55% – 78% | 基础伤害、+12 弦力、夺招 |
| **截** | 78% – 93% | 1.25 倍伤害、+20 弦力、夺招 |
| **绝** | 93% – 100% | 1.6 倍伤害、+30 弦力、夺招，额外震退 |

「绝」要求你在弦几乎贴脸时才出手——这是这套玩法的心跳。

### 2.3 夺招 / 刀鞘

截断的招变成一张**纸符**飞进刀鞘。鞘只有 **3 格**，每张符**只能用一次**。

- `K` 放最新一张，`1 / 2 / 3` 指定放哪张。
- **鞘满时再截一张**：最旧的那张会当场自鸣放出去（「满鞘自鸣」），不浪费——奖励不是惩罚。

夺来的招就是敌人刚失去的那一招，四种 + Boss 一种：

| 符 | 来自 | 效果 |
|---|---|---|
| **剪** | 提线童子 | 面前扇形三连斩，瞬间爆发伤害 |
| **障** | 伞姬 | 纸伞护身 2.5 秒，挡下下一次弦击并反弹；朱弦碰到伞会碎 |
| **鼓** | 鼓腹翁 | 地面冲击波向左右各推 700，击倒并破朱弦 |
| **双** | 双弦伶 | 身前身后交叉双斩，大范围，破朱弦 |
| **判** | 无常判官 | 朱印落章：全屏 2 秒定身 + 高伤，破全部朱弦 |

### 2.4 朱弦

朱红色的弦**截不断**：刀砍上去会「铮」地被弹开。只能躲，或者用夺来的招把它打碎。

白弦是「收成」，朱弦是「账单」。一眼分得清，是这套玩法能站住的前提。

### 2.5 断幕（R，弦力满）

弦力满 100 按 `R`：

- 全场**已经甩出来的弦一齐截断**（每根按「绝」结算）；
- 时间放慢到 0.35 倍，持续 2.4 秒；
- 慢动作里出刀必「绝」，伤害 ×1.6；
- 屏幕翻成纸白，正中落一枚巨大的「断」印。

这是把「我读懂了这一整套谱」兑现成伤害的时刻。

### 2.6 敌人怎么死

**不是掉血掉死，是被拆空。**

每只傀儡身上挂着 N 根提线 = 它还会 N 招。每截断一招，那根线断掉、那招永久消失。线全断 = **空弦**，傀儡当场散成一地纸片。

所以战斗的形状是反的：**开局它什么都会，你只能挨；打到后面它只剩一招，你鞘里揣着它自己的四招。** 最后一击通常是用它自己的招打的。

血条只做保底（砍身体也能磨死），主路径永远是拆招。

## 3. 操作

| 键 | 键鼠 | 手柄 | 作用 |
|---|---|---|---|
| A / D（←→） | 同 | 左摇杆 / 十字键 | 移动 |
| W / 空格 | 空格 | A | 跳（可二段） |
| J | 左键 | X | 斩（三段；刀锋也是截弦的判定） |
| Shift | 右键 | B | 闪步（有无敌帧，**不截弦**） |
| K / 1·2·3 | K / 1·2·3 | Y | 放刀鞘里的招 |
| R | R | RB | 断幕（弦力满） |
| F5 | F5 | Back | 重来 |
| Esc | Esc | Start | 退出 |

**闪步不截弦**是有意的：面对一根弦，你永远在「截（收益）」和「闪（安全）」之间选一个。

## 4. 怪物（全部新设计，纸影戏傀儡）

统一语法：**黑纸剪影 + 白刻线 + 一根提线**。朱红只给朱弦和判官的印。

### 4.1 提线童子（引子）

- 剪影：小身子、方头、一根竹板；头顶三根线吊在空中。
- 招式：**敲**——竹板举高，一根竖直弦钉在你脚下，落点炸出一根墨刺；**扫**——贴地一根弦横扫过来。
- 读法：教学怪。动作慢、弦少，专门教你「等它绷紧」。
- 夺到：**剪**。

### 4.2 伞姬（一折）

- 剪影：细高个、纸伞、长袖；伞骨是白线。
- 招式：**伞张**——伞面打开，三根弦同时扇开（左、中、右），只有中间那根钉着你；**伞旋**——一根弧形弦绕着她转半圈。
- 读法：三根弦里选一根截。截中间那根，另外两根自己散；截旁边那根，中间照样落。**位置开始有意义。**
- 夺到：**障**。

### 4.3 鼓腹翁（二折）

- 剪影：矮胖、圆肚（同心墨圈）、两截短臂。
- 招式：**擂**——双拳砸肚，一根贴地弦滚过来，要跳；**擂朱**——肚子裂开一道朱线，甩出一根**朱弦**（截不断，只能躲或破）。
- 读法：第一次出现「不能截的弦」。教玩家分清白与朱。
- 夺到：**鼓**。

### 4.4 双弦伶（二折）

- 剪影：极瘦、两张脸（一白一黑）、两条长绸。
- 招式：**交**——两条弦一高一低同时到（头高 / 脚高）；**缚**——一根弦斜着钉在你身后，落点在你退路上。
- 读法：一刀只能截一根。要么选一根、挨另一根；要么闪走两根都躲。**这是全套玩法里最硬的一个选择。**
- 夺到：**双**。

### 4.5 无常判官（三折 · Boss）

- 剪影：高帽、白面具、一手判笔一手卷宗；身后悬着一排空白卷轴。
- 招式：**判笔**（巨竖弦）、**卷宗**（三连弦依次落）、**墨押**（贴地弦）、**幡**（大弧弦）、**朱批**（朱弦）。
- 二阶段：他把自己被夺走的招**用朱线缝回来**——那些招变成朱弦，只能用你鞘里的招打碎。**你偷得越多，他缝得越狠。**
- 三阶段：**绝笔**——六根弦同时绷紧、依次落下的一整套谱。这是他最后的全部，也是你「断幕」最好的落点。
- 死亡：所有提线一齐断，整个人塌成一堆纸，天空落一枚朱印：**弦尽**。

## 5. 关卡：一轴纸卷，四折

一镜到底的横版纸卷，走到纸门就进下一折；过关补 1 颗心（「拾纸补心」）。

| 折 | 场地 | 内容 | 教什么 |
|---|---|---|---|
| 引子 · 纸桥 | 纸桥、月、远山；两块可站的高台 | 1 只童子（只有一招，故意慢） | 站进弦里 · 等绷紧 · 截 |
| 一折 · 伞影 | 桥廊、挂灯、松 | 2 童子 + 1 伞姬 | 多弦选一根 |
| 二折 · 鼓台 | 大鼓、鼓台、雨檐 | 鼓腹翁 + 2 双弦伶 | 朱弦 / 高低双弦 |
| 三折 · 判台 | 判官案、悬卷、朱日 | 无常判官 | 全部 |

场地有高低差：高台的弦是斜的，站上去截和站在地上截，刀锋够到的位置不一样。

## 6. 手感与反馈（每一刀都要有回应）

| 事件 | 反馈 |
|---|---|
| 挥空 | 一声干纸响，刀光淡 |
| 截断 | 60ms 顿帧 + 白闪 + 弦断成两截卷曲落下 + 纸符飞向刀鞘 + 一枚「断 / 截 / 绝」印 |
| 被弦打中 | 墨溅满屏边、一颗心撕成纸片、1.1 秒纸白闪烁无敌 |
| 夺招 | 纸符入手的声音（一声脆响 + 一声低鼓） |
| 放招 | 每个招有自己的音色和笔画：剪=三声裂纸，障=伞骨撑开，鼓=闷鼓，双=交叉双响，判=落章 |
| 断幕 | 整屏翻白、时间变慢、墨从四边压进来、巨大「断」印砸下 |
| 空弦 | 傀儡的线一根根断，最后整个人散成纸片，纸片落地有声 |

声音全部**程序合成**（`chord_audio.gd` 现场生成 PCM），不新增音频文件：裂纸、弦崩、闷鼓、木鱼、落章，音色统一在「纸 + 木 + 弦」这一族里。

## 7. 美术方向：活的纸影戏

和原版雨街**故意相反**：原版是冷蓝夜雨、厚涂；这一版是**暖白纸、黑墨、朱红印**。

- 底：米白纸（#EDE6D4）+ 纸纹噪点；
- 远景：三层墨山（0.10 / 0.16 / 0.24 明度），一轮淡朱日；
- 中景：松、塔、鼓、判台，全是剪影；
- 世界：黑纸剪影角色，白刻线勾边，**紫色只给主角的刀**；
- 前景：飘落的纸屑（不是雨）、纸边撕裂、四角墨晕。

一句话：**这是被昼光钉住的那一瞬的背面——一张还在动的纸。**

## 8. 精通曲线

1. **会用**：站在弦里，等它亮，一刀。
2. **会选**：三根弦里截中间那根；高弦跳起来截。
3. **会贪**：「绝」的窗口只有 7%——敢不敢再等半拍。
4. **会管鞘**：鞘满会自鸣，所以要在满之前把招打出去；打谁、什么时候打，是资源管理。
5. **会破朱**：朱弦不能截，只能靠夺来的招——所以「先截白的、再用白的破朱的」是循环。
6. **会断幕**：等场上弦最多的一瞬开 R，一次全截，收益最大。
