# 玩法：**未竟**（DSH 版 · 设想稿）

> **状态：已被用户否掉，存档不再推进。** 原话：“你这一看就不好玩”（2026-11-03）。
> 否的原因（我的判断）：把玩家的手交给了布景——断光脉是"按一下开关"，杀怪是道具替她做的，第一分钟还在走路看风景。**不要删这份**，下一版 `玩法-不落.md` 要能看出这一版错在哪。
> 规划入口：`OPEN_DSH.bat` 默认进新的「不落」；「错拍」「截弦」留副入口。
> 名字备选：**未竟 / 一瞬街 / 解冻**（见 §13）。

---

## 0. 一句话

**这条街停在一秒里，所有事都没做完；她的剑一断光，那些没做完的事就接着做完——包括正朝她挥下来的那一刀。**

三个词概括体验：**静 → 断 → 活过来**。

- **静**：整段街没有雨声。雨悬在半空，一颗一颗，能看清每一颗。
- **断**：一刀下去，一声玻璃裂开的脆响。
- **活过来**：雨声轰一下回来，颜色回到墙上，那一秒继续往前走。

她走过的地方开始下雨。这就是进度条。

## 1. 先找玩法：怎么筛的

先列了八个方向，只问三个问题：**它能不能打**（还是变成了走格子）、**读不读得出来**（不用 UI 也看得懂）、**有没有新的东西**。

| # | 方向 | 一句话 | 结论 |
|---|---|---|---|
| 1 | 光=血 | 受伤就是变暗，越暗敌人越看不见你、也越凶 | 好看，但和"受伤"这件事抢注意力，先记下当高难变体（见 §7） |
| 2 | 剑变重 | 斩下来的光挂在剑上，剑越来越重、越挥越慢，得找地方卸掉 | 会把爽快感拖慢，弃 |
| 3 | 预演 | 出刀前先看完这一秒的结果再决定 | 和「错拍」的影身撞车，弃 |
| 4 | 节奏 | 按拍子出刀 | 变成背谱，弃 |
| 5 | 影子替打 | 她的影子在真实时间里替她出手 | 和「错拍」撞车，弃 |
| 6 | 夺招 | 把敌人的招截下来变成自己的 | 和「截弦」撞车，弃 |
| 7 | 光区/暗区 | 站光里怎样、站影里怎样 | 变成站圈吃 buff，弃 |
| 8 | **定格释放** | **敌人被光定在动作中间；断它的光，它把那个动作做完** | **选它** |

选它的三条理由：

1. **它的武器是这条街本身。** 你打的每一场，弹药都是场景里被冻住的那些人、那辆车、那口吊钟。不需要新系统去造资源。
2. **成本和收益都写在画面上。** 放出来的动作朝哪儿、打得到谁、会不会砸到自己，全部在定格的那一格里看得见。没有条、没有数字、没有提示箭头。
3. **它不奖励"防守"。** 前面两条 DSH 玩法（错拍、截弦）本质都是"接住对方的招"。这一条是**你主动把世界点着**——风险是你自己造的，收益也是。

**最大的风险是变成解谜**（站对位置、按顺序点）。三条对策写在 §11。

## 2. 它和这个游戏的关系

- **世界观**：设定集 §3 写得很清楚——光被斩断，停滞的时间重新开始流动。这条玩法就是把"重新流动"做成看得见、玩得到的东西：不是回血、不是加数值，而是**一个被打断的动作终于被做完**。这一条比原版任何一场战斗都更贴"斩光"这两个字。
- **角色**：还是朔 / 绝影，还是制式长剑、鸦羽披肩、冷紫刀光。她做的还是本职工作，只不过这次她斩的是**一整条街的永恒**。
- **动作**：她的招一招不改，只换用途（§4）。三连、上挑、空连、冲刺斩、蓄力霸体、弹刀、刀气、大招全部有用，而且各有各的活。
- **背景**：直接用雨街那套分层拼接图，上面盖一层"停格"；解冻的地方把停格层擦掉，露出原来的雨、湿反光、雾。**同一个场景，两种状态**——比新画一套背景便宜，也比新画一套更有说服力。

## 3. 核心规则（一页记住）

1. **停格**：这条街停在某一秒。定格的雨、人、车、招牌全是**硬的**——能站、能挡、能撞。
2. **光脉**：每具定格体身上垂着一根光，连到光源。**光脉就是开关**：刀锋扫过就断，不需要点得很准（判定盒与光线求交）。
3. **放行**：光脉一断，那具身体**把被打断的那个动作做完**——挥完刀、砸下锤、扑出去、倒下去——然后塌成一地湿衣服。雨声回来一小块。
4. **活体**：街上还有活着的东西。它们不归光管，抢光、补光、挡光、切线。
5. **光会回来**：主光源没断，被放出来的东西会被重新定住。**砍断主光源 = 整段街一起解冻**，那是最疯也最赚的一刀。

一句话总结规则：**光的开关是免费的，代价全在放出来之后。**

**两种打法都成立，而且都好玩：**

- **当导演**：一段一段放，算好每个动作会砸到谁、自己站哪儿。稳、准、连锁长。
- **当纵火犯**：一次全放，让整段街同时活过来，用命和走位换时间和分数。乱、快、上限高。

这条玩法不规定你必须当哪一种。

## 4. 她的每一招，在新规则里干什么

| 招 | 在这条玩法里的活 |
|---|---|
| **J 三连** | 断光脉（最快的开关）；打活体 |
| **W+J 上挑** | 够高处的光脉；把活体挑进定格体里，**撞裂壳**（借敌人的身体替你开一具） |
| **空中三连** | 断高处/吊臂上的光脉；滞空看清楚"放行"的轨迹再落 |
| **Shift 冲刺斩** | **边冲边断**——"砍完就走"的唯一正解；跨过被光柱封住的路 |
| **蓄力斩（霸体）** | 断**粗光柱**（主光脉、灯母的脉）；站在"放行"里不动，看着它从你身边过去 |
| **L 弹刀** | 弹回"光针"（断脉瞬间甩出来的光刺）；**把光针弹到另一根光脉上 = 远程连锁**（高手向） |
| **K 刀气** | 够不到的、或被蛾啃着的光脉——抢在它被啃完之前切 |
| **S+J 下砸** | 砸裂光壳：把一具定格体提前弄塌/弄醒 |
| **R 大招** | 斩尽全场光：**一次把整段街放完**。连锁最多、风险最大 |

注意：**没有冷却、没有消耗。** 断光永远可以用。这是故意的——限制玩家的不该是资源，而是"你敢不敢让这件事发生"。

## 5. 怪物（六只，全部新设计）

统一的视觉语法：**定格体 = 白瓷/石膏剪影 + 一根金白光脉**；**活体 = 近黑剪影 + 发光眼**（跟原版敌人同一套语言，形状全新）；紫只给她。

### 5.1 灯奴（引子 · 教学）

四条腿、方头、一只手举着一盏小灯。它举的灯是附近 **2～3 根光脉的副光源**。

- **杀它 = 那几根脉一起断 = 2～3 具身体同时放出来。** 所以"先杀灯奴"是错的——它活着，那几具就是你的弹药；它死了，弹药自己引爆。
- **拆引信**：不打身体，只打断灯杆——光脉改从主光源直连，不再连锁，但更难断。
- 教的是：**光源和光脉不是一回事。**

### 5.2 食光蛾（二折）

巴掌大、灰白、翅膀像两张薄纸，扑到光脉上开始啃。啃完，那根脉**永久消失**——那具定格体再也放不出来，你少一件武器。

- 它啃的时候最脆（黏在光上飞不动）。
- 它逼你分配刀气：**先打蛾，还是先放那一刀？**

### 5.3 持镜像（二折）

细高个，举一面手镜，把主光**折**到已经放出来的东西上——**重新定住**（半血复活，而且这次钉在原地）。

- 它是"敌人也会用规则"的证明：你不能慢悠悠地打。
- 杀掉它，镜子碎成一滩光，站进去回一点血（她本来就私藏晓光回血，设定集里有）。

### 5.4 盾奴（三折）

把一具定格体扛在身前当盾。它不懂光，只懂"这面盾是硬的"。

- **盾是一发上了膛的子弹**：砍断盾的光脉，盾那个动作会砸在它自己身上。
- 教的是最直接的一课：**定格体是武器，不只是掩体。**

### 5.5 守针（三折）

长针决斗者。快、直、会从上方和下方突刺。

- 它会**主动切断光脉**——把你还没放出来的武器作废。
- 它是这条玩法里唯一的"纯动作怪"：逼你空连、冲刺斩、弹刀，跟机关没关系。

### 5.6 灯母（终 · Boss）

玻璃做的女人，两只手举着一圈用断环碎片拼的灯。**她就是主光源。**

- 她身上垂下一百根光脉，每一根钉着她"最后那一秒"里的一段：一个动作、一个人、一个没说完的转身。
- **切一根，放一段。** 每一段放出来的东西都在这个场里变成新的家具/新的敌人。
- 一百根切完，她**醒过来**——第二阶段：她是活的了，用整条街解冻后的东西打你（吊灯砸下来、货架倒、雨终于全部落下）。
- 死法：她塌下去，灯还亮着——最后那圈灯是她自己的，得由你斩。灯灭，天开始下雨。

## 6. 关卡（三段 + 终）

| 段 | 场地 | 一句话 | 教什么 |
|---|---|---|---|
| **一 · 雨篷街** | 雨篷、门厅、湿台阶（复用雨街第一段） | 出口被一根粗光柱封着，断光柱才开门——可光柱一断，街上三具定格体全放出来 | 断脉 / 放行 / 被自己放出来的东西砸到 |
| **二 · 吊货街** | 货栈、吊臂、三层滑轮（复用中段） | 光脉从吊臂上垂下来，蛾在啃，镜在补 | 抢光、连锁、纵向走位 |
| **三 · 廊桥疗养院** | 廊桥、疗养院的窗、河（复用第三段） | 母亲抱着孩子，两个人一起被钉在门口那一秒 | 选择（见下） |
| **终 · 灯母** | 街尽头 + 断环碎片 | 一整条街的主光源 | 全部 |

**第一段的节奏**（也是竖切要做的全部）：

1. 走进去。没有雨声。雨悬在头顶。玩家会先停下来看——这一停就是钩子。
2. 一具定格体举着刀站在路中间，后颈垂着一根金白的脉。**砍它。** 刀挥完，把一个路灯削断，灯灭了，雨声轰一下回来。
3. 灯奴从雨篷上下来追她。她发现砍灯更快。
4. 出口那根粗光柱：三连砍不动，得上蓄力斩。断的瞬间，整段街一起解冻——三具定格体同时开始动——**第一次真正的混战**。
5. 门开了。身后是雨。

**第三段的选择**：两条路。**放**——怪多、路短；**不放**——绕远、要打守针、但那个门口一直站着两个人。选了之后街景会记住（回头看一眼，她还在那儿）。**没有一句台词，没有对错提示，评分里也不给分。**

## 7. 模式结构

- **一次夜巡**：三段 + 灯母，一条命，段与段之间有检查点（死了从本段开头来）。
- **评价 S / A / B**：用时 + 受伤次数 + **连锁数**。
- **连锁是这条玩法的 style meter**：
  - 1 段 = **断**
  - 2 段 = **连断**
  - 3 段以上 = **长夜一瞬**（短暂慢镜，雨声推到最大，屏幕边上的白全部退掉）
  - 判定：一次"放行"的动作为 0.8 秒内杀掉的东西都算进同一条连锁；连锁可以被下一次放行接上（放 → 杀 → 再放 → 再杀）。
- **高难变体（先记下，不做）**：**「光即血」**——受伤不减血，减"她身上的光"；光越少，活体越难看见她（潜行），但她的刀也越暗、越打不痛。这是上面 §1 表里的第 1 号方向，单独做一档。

## 8. 手感与声音（这一条最重要）

**声音就是这套玩法的 UI。**

| 事件 | 反馈 |
|---|---|
| 停格中 | **没有雨声。** 只有脚步的水声、极轻的风、远处的钟。 |
| 断光脉 | 一声**玻璃/冰裂**的脆响（高频、干净、不带金属味）；0.4 秒内雨声渐入 |
| 放行的动作命中活体 | 闷响 + 90 ms 顿帧 + 墨/血溅 + 那人塌成湿衣服（不是尸体） |
| 被放行的东西砸到 | 鸦羽炸开（披肩挡了一下）、屏幕失声 0.3 秒、再回来 |
| 连锁 | 屏幕边缘的白一层一层退掉；雨声一层一层大起来（不用 UI 条） |
| 大招 | 整屏白 → 所有脉同时断 → **0.2 秒完全静音** → 雨声最大 → 黑 |

音色方向：**玻璃、水、湿衣服、木头、远处的钟**。不要电子音、不要低频轰。原版那套挥刀/受击照用。

## 9. 美术

- **底**：复用 `assets/image/rain_street/` 的分层拼接和雨 shader（只读，不改）。
- **停格层**：银白调 + 悬浮雨珠（每颗一个小 sprite，能看清）+ 凝固水花 + 静止的雾 + 极轻的纸白噪点。
- **解冻**：用 mask 把停格层擦掉，露出原来的雨和湿反光。**她走过的地方开始下雨。**
- **定格体**：白瓷/石膏剪影，边缘一圈极细的亮边；后颈/胸口一根金白的光脉。
- **活体**：近黑剪影 + 一点发光眼（跟原版敌人同语言，形状全新）。
- **配色铁律**：紫只给她和她的刀；朱红只给第 3 段远景里的钟楼（永远 5:59）；冷蓝只给警署门灯。

## 11. 三个风险和对策

1. **变成解谜（站对位置、按顺序点）**
   → 放行是瞬时的、有伤害的、会打到你自己的；活体一直在动，没有"标准答案"；场景里**从不出现必须按顺序的锁**（粗光柱要蓄力斩，这是唯一的手法门槛）。
2. **看不过来（一屏十根光脉）**
   → 一段同时最多 **3 根**；只有"此刻可断"的脉才发亮；定格体和活体是两套完全不同的剪影，扫一眼就分得开。
3. **慢（等、看、再砍）**
   → 第一段的第五步就是混战；灯奴和守针会一直往前压；停格只停"雨和尸体"，**活体从来不停**。

## 12. 和「错拍」「截弦」的区别

|  | 错拍 | 截弦 | **未竟** |
|---|---|---|---|
| 核心 | 敌人的逻辑跑在 0.6 秒后 | 截断来袭的弦，夺招 | 切断供光，把定格的动作放完 |
| 玩家在做 | 打未来、躲过去 | 等弦绷紧、选弦 | 选哪一段"未完成"放出来、站哪儿 |
| 收益 | 合拍伤害 | 夺来的招 | **借来的杀** |
| 失败 | 被本体打中 | 被弦打中 | 被自己放出来的东西砸中 |
| 资源 | 延迟条 | 刀鞘 | **没有资源，只有后果** |

**和外面那些最像的，也不一样：**

- 《旷野之息》的静止器：那是个物理玩具，你往里**加**能量；这里每个动作是**写好的**，你只决定它**什么时候发生**、以及**你站在哪儿**。
- 《只狼》的弹反：那是把"防守"变成资源；这里没有"接住"，只有"放出去"，风险是你自己制造的。
- 《Superhot》：那是"你不动世界不动"；这里是"世界不动，你去动它"。
- 《毁灭战士》的处决回血：那是击杀换资源；这里**回血只在你把光放出来、并且站在那滩光里**的时候——回血的地方永远是刚炸过的地方。

## 13. 要你定的三件事

1. **名字**：未竟 / 一瞬街 / 解冻。我倾向「未竟」。
2. **第三段那个门口的尺度**：真的"放出来就没了"（狠、记得住），还是"放出来就只是走了"（软一点）。这一条决定这条玩法是冷还是暖。
3. **竖切做哪一块**：我建议 **第一段 + 灯奴 + 灯母的第一刀**（30～40 分钟能玩到，能看出好不好玩）。要不要先只做第一段的"门厅到开门"。
