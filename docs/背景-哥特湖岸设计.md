# 背景重做设计：「鸦夜 · 哥特湖岸」（2026-10-25，只是方案，用户说“干活”后才改代码）

示意图：`docs/视觉设计/gothic_lake/layout_bands.png`（1280×720 设计分辨率，各层占哪一条带）。

## 1. 现状和问题（截图：`scene_shot.gd` 拍的 x=1000 / x=2500）

- 现在的背景是第七轮「月下东方园林湖」：垂柳、六角亭、石拱桥、石灯笼，**像素画**（`night_pixel.gdshader` 整层像素化 + 调色板量化）。
- 主角是 **高清日系 Q 版立绘**（`ai-hd-20261020`，干净描边 + 赛璐璐上色），大招参考图是 **哥特城堡 + 湿木栈道 + 湖面倒影**。
  背景在画法（像素 vs 高清）和题材（东方园林 vs 哥特城）上都和角色、大招对不上。
- 大月亮半径 95 像素、高亮，抢画面；角色在屏幕上只有约 85 像素高，背景比战斗区抢眼的老问题还在。
- 地形平台（`terrain.gd`）是程序画的像素块，换高清背景后它们会变成新的“画法打架”点（见第 7 节，放在第二阶段）。

## 2. 定调

- **题材**：夜晚湖边的湿木栈道；湖对岸是哥特大教堂式城堡和沿岸的城镇灯火，后面是山，天上是厚云层。和大招参考图同一个地点——平时打怪的地方就是放大招的地方。
- **画法**：高清日系动画背景（手绘质感数字绘画），**不再像素化**。远处柔、雾化、低对比；越近越清楚、轮廓越干净。近景物件带一点干净的描边感，配主角的 Q 版画风。
- **颜色**：去饱和的石板灰蓝 + 银白月光；唯一的暖色是琥珀灯光 `#F0A04B`（紫色的补色，衬主角）。**背景里不出现紫色**——紫色只属于主角、剑气和大招。
- **光向**：月亮在右上，所有物件右上边缘受光、左下暗；灯光是局部暖光。
- **明度分工**：天空和远景中等偏暗、低对比；湖面（角色身后那一条，屏幕 y 440～580）**平静、少细节、中暗**，是战斗区的安静背景；栈道比湖面暗一档但有湿木反光；前景最暗。
- **大招兼容**：大招期间画面转黑白，所以背景只靠明度也要分得出层次（城堡、湖面、栈道三档明度要拉开）。
- **不要的元素**：魔法阵、水晶、星形闪光、发光粒子、紫光、新的大月亮。背景本来就有的月亮保留，但缩小（半径约 55 像素），躲在城堡尖塔旁边，不再是最亮最大的东西。流星、花瓣、萤火（园林味）去掉。

## 3. 分层（1280×720 设计坐标，角色站的地面 floor_y = 屏幕第 580 行）

视差 = 跟镜头移动的倍率（0 不动，1 跟地面一起走）。现在一轮三处封印大约走 5500 屏幕像素，倍率 0.04 的层一整轮只挪 220 像素，所以城堡地标几乎一直在画面里。

| # | 层 | 屏幕位置 | 视差 | 谁来做 | 循环方式 | 贴图尺寸（像素密度） |
|---|---|---|---|---|---|---|
| ① | 天空 + 云 | 0～460 | 0.01 | **AI**，整张不透明（不画月亮） | 一张，镜像重复（0.01 倍几乎不动） | 1920×690（1.5×） |
| — | 月亮 + 月晕 | 中心约 (1000,150)，r≈55 | 0 | **程序**（着色器画圆盘 + 淡淡的月面纹理 + 柔光晕） | 固定在屏幕上 | — |
| — | 星星闪烁、薄云飘过月亮 | 上半屏 | 0.01 / 风飘 | **程序**（沿用 `night_sky` 闪烁，噪声云丝很淡） | — | — |

- 密度：项目是 1280×720 + `canvas_items` 拉伸，1080p 屏放大 1.5 倍、2K 屏 2 倍。远景本来就柔，存 1.5×；中近景要清楚，存 2×。AI 原图不够大时，出图工具有 2× 放大（Upscale / 高清修复）就开；没有我用脚本放大，远景够用。
- 角色身后（湖面 440～580）只有平静水面和倒影，不放任何高对比细节。

## 4. 各层怎么接进现有代码（“干活”后才做）

1. **新素材目录** `assets/scenery/gothic_lake/`（webp + `layers.json`）。旧的 `moon_embankment/` 留着当后备，新背景验收后再说删不删。
2. **处理脚本** `tools/art/make_gothic_lake_layers.py`：洋红抠图（去粉边、边缘去溢色）→ 裁出该层的带 → 缩到目标尺寸 → 找最佳接缝 + 渐变做首尾无缝（沿用现在 `seamCost` 的做法）→ 输出 webp 和 `layers.json`（尺寸、top、视差、周期、灯的位置）。
3. **`night_backdrop.gd`**：按上表换一套层；**对外接口全部保持不变**——`camera`、`floor_y`、`ok`、`meta`、`tex`、`pixel_mat`、`_pix`、`moon_screen()`、`nearest_lantern()`、`lantern_flicker()`、`lantern_light()`、`near_top()`、`horizon_y()`、`set_ult_mode()`。
   所以 `night_trial.gd`、`night_light.gd`、`player.gd` 和大招相关文件都**不用改**（另一个对话在改的那些文件一个都不碰）。
   - `nearest_lantern()` 改成查“程序摆放的铸铁路灯”列表，角色身上的暖光照旧能用。
   - `set_ult_mode()` 照旧：大招期间藏前景 ⑧ 和飘尘。
4. **像素化关掉**：`night_pixel.gdshader` 的 `pixelate = false`、`quantize = false`，只保留“退后调色”（去饱和、压暗），参数重调；滚动不再对齐 2 像素格。
5. **着色器**：新增 `lake_water.gdshader`（替代 `night_sea`）、`wet_planks.gdshader`（湿木反光，灯和月亮的高光条随镜头滑动）、月亮着色器；沿用 `night_reflect`（倒影）、`night_fog` / `night_mist`（雾）。
6. **测试**：`tests/test_night_combat.gd` 的 `test_backdrop()` 按新层改断言；跑 `GODOT=engine/Godot_v4.7.2-stable_win64_console.exe bash tools/dev/runtests.sh`（跳过 `ai_hd_visuals`）。
7. **验收**：`scene_shot.gd` 在几个 x 截图（含三处封印）、`BG=1` 只拍背景、大招黑白下截一张；对比改前改后，检查战斗区明度、紫色占比、冷色彩度（沿用 `keyart_check.py`）。

## 5. 出图顺序

0. **定调图**（整张合成，只定风格和构图，不直接进游戏）→ 我把真主角按游戏尺寸合成上去检查（角色清不清楚、明度分层、大招黑白下层次）。
1. 定调通过后，按 ③ 城堡 → ④ 对岸 → ⑦ 栈道 → ⑥ 栈道零件 → ① 天空 → ② 远山 → ⑧ 前景 的顺序一张一张出，**每张都附上通过的定调图**当参考。
2. 每张出来先给我，我检查（见第 8 节）后处理入库，不合格就只改那一张。

附图建议：定调图附 `tools/art/src/ult/feather/ref_wide_stop.webp`（场景和气氛）+ `assets/image/ai-hd-20261020/idle/pose_001.png`（画风）。之后各层附通过的定调图。

## 7. 第二阶段（可选，背景通过后再定）：平台皮肤 + 鸦

- 现在的平台（`plank` 木台 / `slab` 断桥石板 / `roof` 亭子屋檐 / `stone` 石台）是代码画的像素块，换高清背景后会显得突兀；`roof` 的中式亭子也和哥特题材不配（建议改成铸铁顶的哥特小凉亭）。
  做法：AI 出“左端 + 可平铺中段 + 右端”的三段式零件，`terrain.gd` 只换画法，碰撞数据一点不动。提示词等背景定调通过后再给。
- 鸦的点题：几只乌鸦停在系船柱上，主角走近时飞走（需要 2～3 帧的小精灵图），远处偶尔有鸦群剪影飞过（程序画）。和大招的鸦羽不冲突：平时只出现黑色剪影，不带紫光。

## 8. 每张图我收图时的检查项

- 严格侧视：水平线水平、建筑正对镜头、地面没有斜。
- 洋红底干净：没有渐变、阴影、光晕溢到洋红上；物件里没有粉/洋红色（否则抠图会抠穿）。
- 首尾能接（②④⑦）：左右两端高度、密度、亮度一致。
- 光向统一：右上受光；暖色只有灯和窗。
- 没有紫色；冷色彩度 ≤16（`keyart_check.py`）。
- 角色合成后：角色身后那条带（440～580）平静、中暗，眯眼看角色是最先看到的东西；转黑白后城堡 / 湖 / 栈道三档明度分得开。
