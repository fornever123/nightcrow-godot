# 战斗恢复说明

这次的问题来自迁移不完整：战斗动作能运行，但命中时的震屏、声音、撞击反馈等没有完整接进新游戏。近战还有一个“木桩停住了，角色自己没有停住”的错误，所以打起来很轻。

现在已补好：

| 你看到或感觉到的变化 | 现在的效果 |
|---|---|
| 命中顿一下 | 轻击停约 0.10 秒，第三刀约 0.18 秒，满蓄力约 0.32 秒；角色与木桩分别计算 |
| 屏幕震动 | 普攻沿击退方向震，上挑向上震，重击和撞击更明显，远射较轻 |
| 命中位置与时间 | 剑真正挥出时才命中，停在出刀姿势；不会在蓄势阶段就扣血 |
| 连段 | 顿帧期间仍能提前按下一刀；恢复接招窗口和出招走位 |
| 击飞和撞墙 | 保留浮空追击加成、墙壁或地面撞击的额外伤害，补声音和震屏 |
| 打击反馈 | 木桩闪白、小型命中效果、实际伤害数字与连击统计 |
| 声音 | 接入 C 盘的挥剑、命中、重击、弹刀、蓄力、跳跃、落地和远射声音 |

双击工程中的 OPEN_GAME.bat 打开游戏。靠近木桩，点按 J 试普攻；及时再按 J 试连段；按住 J 再松开试蓄力；W + J 上挑；K 远射；R 重置。

修改器左侧的“打击感”可以调整震屏和停顿倍率。默认停顿倍率 1、震屏倍率 1.55。要逐招微调，进入“战斗参数”。改完点“保存并刷新游戏”。

角色原图和原刀光保持原样。上挑、远射、弹刀还没有专门动作图；木桩不会主动攻击，所以不能靠木桩练弹刀。场景仍是你要求的空场景和木桩，没有新增玩法。

已通过 103 项机制与修改器检查，也检查了游戏实际渲染的轻击和重击画面。旧 C 盘工程没有修改。
