## 1. 游戏是什么【定】

- 2D 横版动作游戏，Godot 4.7 引擎。章节制，每章 3～5 段相连的战斗场地，最后是 Boss，按 D～S 评价结算。手感接近《鬼泣》：挑飞、空中连段、弹刀、大招。
- 画面：竖直方向约三层楼，上下大量相连；战斗区两屏以上，镜头双轴跟随。**角色在屏幕上约 100～120 像素高**（1920×1080 画面）。
- 目标气质：**冷峻、阴郁、带一点危险，而且很帅**。用户给雨夜街道定的参照是“鬼泣那种很帅的街道”“雨夜伦敦”。
- 第一版只有主角可玩，其他角色先当 NPC 和 Boss，以后做成可玩角色给本地双人对战（PVP）用。所以世界里要有几个和主角同一量级、对“光”有不同答案的人。【定，用户 10-31】
- **几乎没有对话。**【定，用户 10-31】游戏以战斗和怪物的表现为主。故事靠这些讲：
  - 怪物长什么样、怎么动、**怎么死**；
  - Boss 战本身（比如活圣像的黑色倒影）；
  - 场景里看得见的东西：钟停在 5:59、长椅泡在水里、小孩画的裂开的太阳；
  - 极少的文字：每章一两句，刻在墙上、写在瓶子上、Boss 名字下面的一行小字。

  写角色和背景时，**写他怎么做、长什么样，不要写他怎么说**。
- **要有各种奇观。**【定，用户 10-31】从雨夜伦敦出发，后面每章都要有一眼记住的景象，而且奇观要和世界规则有关。现有的奇观清单见第 8 节开头。奇观以“分层 2D 背景 + 光影 + 少量动态”能做出来为准，靠尺度和构图取胜。

## 2. 故事：被斩断的黎明【提案】

很久以前，这个世界只有一天。

每天早上太阳升起，挂在天上的那道巨大石环会把一切复原到前一天早上的样子。摔碎的杯子回到桌上，伤口合拢，死去的人在床上醒来。没有人会老，没有人会真正死去。可也没有任何东西能改变：孩子永远长不大，城市永远是那座城市，昨天说过的话，今天早上就没有发生过。每个地方都活在自己那一天里，彼此看不见，也到不了。人们后来管这个时代叫**永昼**。

七十年前的一个夜里，守夜者修会的三百名剑士站在光环的影子下，在天亮前一分钟同时出刀。光环碎了，停在天上；太阳再也没有升起。那一夜活着回来的不到一半。修会管那一夜叫**百刃之夜**。

从那以后，时间第一次开始往前走。人开始变老，伤口会留疤，死去的人不会再醒来。原本困在各自那一天里的地方，第一次在同一片夜空下看见了彼此：维多利亚式的雨港、漂在云海上的浮空古堡，还有更多地方，隔着云海遥遥相望。每个地方都停在被斩断那一刻的天气和时辰里：雨港永远在下那一夜的雨。

现在，所有地方都是夜晚。天上横着那道碎掉的光环，断口发着青白色的微光：那是被斩下来的黎明，还卡在裂缝里。

长夜并不安稳。断口每晚都会漏下一点光，叫**晓光**。被晓光照到的东西会复原：伤口合拢、碎片拼回去，人也会忘掉这七十年里发生的事。有人把它当药，有人把它当灾。还有一群叫**晨使**的东西，带着光走进夜里，想把黎明缝回去。修会派出**斩光人**，把漏下来的光一道道斩掉。

而月亮，一年比一年暗。

## 3. 世界的硬规则

写角色、画背景时都不能违反。

1. **全世界都是夜晚。**【提案】唯一的“白天”是晓潮（大片晓光漏下）和浮岛古堡里那个被关住的早晨。**白天在这个世界里意味着危险。**
2. **两边都对，两边都痛。**【提案】
   | | 永昼（斩断以前） | 长夜（现在） |
   |---|---|---|
   | 得到 | 没有死亡、没有病痛、什么都不会失去 | 时间会走：人会长大，城会变，说过的话算数，选择有分量 |
   | 代价 | 什么都不会改变，所有人困在同一天里 | 会老、会病、会死；没有阳光，庄稼越来越难种；月亮一年比一年暗 |

   不要把任何一方写成纯粹的坏人。
3. **晓光会复原。**【提案】能治伤、能救命，也会抹掉一个人这七十年的人生。【补充】复原的程度和照到的量有关：一缕光只合拢伤口、让人恍惚一下；一捧光会让人忘掉几天到几年；整片晓潮会把人退回七十年前的样子。复原过的东西会留下一点痕迹：衣服上的补丁消失、旧伤疤不见，熟人一眼就看得出来。
4. **光是能斩的。**【提案】晓光有形，像丝、像水、像刃。**被斩断的光会失去颜色，落成黑色的羽毛。** 乌鸦会聚到斩过光的地方啄这些羽毛。
5. **没有神器。**【定，用户 10-31】黎明是三百个人一起斩断的，用的都是修会的制式长剑。世界里不存在“只有某人拔得出”“决定世界命运”的武器或道具。
6. **各地风格不同。**【定，用户 10-31】每个地区有自己的文化和建筑，不是统一的伦敦街风格。角色的外观跟出身地走。
7. **每个地方停在自己的时辰和天气里。**【提案】比如雨港永远下雨。天气不会变，这是各地的身份。

## 4. 时间线和纪年【补充】

| 时间 | 发生了什么 |
|---|---|
| 永昼（长度不可考） | 每个地方重复同一天。没有历史，只有“那一天” |
| 永昼末期 | 复原开始变得不完整：有人早上醒来少了一段记忆、少了一只手。只有极少数人察觉（这是第 12 节的秘密） |
| 夜历元年（七十年前） | 百刃之夜。三百名守夜者在天亮前一分钟出刀，光环碎裂。活着回来的不到一半。首任团长“死在那一夜” |
| 夜历 1～10 年 | 各地第一次看见彼此，开始通航、通商、打仗。第一次有人死了不再醒来，第一个冬天死了很多人。守夜者修会在各城设分部 |
| 夜历 10～40 年 | 晓光开始从断口漏下来。黑市出现晓光碎片。修会设立“斩光人”这个职位 |
| 夜历 40～60 年 | 第一批晨使出现在偏远地方。月亮被发现在变暗 |
| 夜历 70 年（现在） | 晨使第一次大批进城。游戏开始 |

- **纪年**：各地统一用“夜历”，从百刃之夜那一刻算起。现在是夜历七十年。
- **一天怎么算**：没有日出，各城都靠钟。雨港的钟楼停在 5:59（离天亮差一分钟），但城里其他钟照常走，人们照钟睡觉起床。“该天亮的时候”是一天的分界。
- **第一代人**：永昼时代出生、斩断后才开始变老的人。现在全是七八十岁以上的老人，是世界上最老的人。

## 5. 天空：断环、月亮、晓光

这是所有背景共用的天空元素，**每张户外背景都要有其中至少一样**。

### 断环【提案，已有图】
- 一道横跨天空的巨大石环，已经碎成好几段，各段错开、悬在天上，周围漂着碎石块。
- 石质：灰白色的巨型石砖砌成，表面有接缝和古老的纹路，看起来像一座倒在天上的城墙。
- **断口和裂缝发青白色的光**（被斩下来的黎明卡在里面），是冷的、凝住的光，不是火。参考 `docs/视觉设计/keyart/gameplay_frame_v2.webp`（右上角那一圈，裂缝发青绿光）。
- 远近：在云海上（比如浮空古堡）离得近，能看清砖缝；在雨港城被云和雨挡住，只露出一段暗影。【补充】
- 已有图：`gameplay_frame_v2.webp`（断环带青光裂缝，最接近设定）、`cloud_causeway_v3.webp`（一整段石环弧，没有发光裂缝，接入时要补）。雨港的天空图 `assets/image/rain_street/sky.png` 里**还没有断环**，大纲建议以后加一段远远的。

### 月亮【提案】
- 是夜里主要的光源，冷白、偏蓝。
- **月亮一章比一章暗**（长夜的倒计时）。不写成“世界末日”大字，只靠画面：越往后越发灰发暗、边缘发锈。【补充】现有的几张 keyart 月亮都很亮，以后按章节调暗。
- 注意：大招和特效里**不用月亮当特效元素**（用户 10-26 要求），背景里可以有月亮。

### 晓光【提案 + 补充】
- 从断口漏下来、落到人间的光。和断口里那种冷青白不同，**落下来的晓光是暖白到淡金色的**，像清晨第一道阳光，柔和、温暖、好看，正因为好看才危险。
- 形态：屋顶上落下的一缕光丝、突然泛白的煤气灯、河面浮起的一层发光晨雾、一大片晓潮。
- 晓光照到的地方会“复原”：碎玻璃拼回、枯花重新开、积水倒映出白天的天空。
- 被斩断以后变成黑色羽毛，落地后慢慢化成灰。【补充】

### 晓潮【提案】
- 断口偶尔漏下一大片晓光，整片地方突然变成白天。被照到的东西全部开始复原：断桥自己接上，死去的鸟飞回枝头，来不及躲的人忘掉自己是谁。
- 可以做成关卡机制：**白天 = 危险**，玩家要躲进影子里。在哪里发生、怎么做，还没设计。

## 6. 势力

### 守夜者修会【提案】
- **是什么**：百刃之夜出刀的那个修会。现在守着长夜，在各城设分部。总部在一座漂流的钟塔里（据点候选，未定）。
- **信条**【补充】：“守夜”——黎明不能回来，时间必须往前走。誓词的最后一句是“愿你醒来时，还是你自己”。
- **纹章**：十字、紫菱、鸦羽。【定，来自主角三视图】
- **制服**【补充，按三视图推出来】：黑色为主，银色金属件（护肩、护手、靴扣），胸口、腰带、发饰上嵌紫菱形宝石，背后挂鸦羽。不同职位的区别在披肩长短、银件多少，不在颜色。普通成员没有那么多露肤，主角的样式是她自己的改法（见第 11 节）。
- **兵器**：全员用**修会制式长剑**：直剑、银色十字护手、柄头和护手中心嵌紫菱。斩过光的剑会留下残色，所以斩光人的剑身发紫，斩得越多越深。
- **职位**【补充】：
  | 职位 | 做什么 |
  |---|---|
  | 大团长 | 修会首领 |
  | 分部长 | 一座城的修会负责人 |
  | **斩光人** | 一线剑士，专斩漏下来的晓光和晨使。全修会几百人，雨港分部十几人 |
  | 守钟人 | 看管各城的钟，记录晓光出现的时间和地点 |
  | 记羽人 | 收集斩光人斩落的黑羽，登记、缝披肩、烧掉多余的 |
  | 见习 | 十几岁入会的孩子，跟着斩光人跑腿 |
- **夜名**【补充】：入会时取一个和夜有关的单字或双字名字（朔、宵、玄羽这类），本名不再用。主角的本名候选就是夜名。
- **禁忌**：斩光人不能私留晓光。【提案】
- **名声**：各城离不开他们，也恨他们。他们斩掉的是人们想要的东西。

### 晨使【提案】
- **是什么**：想把黎明缝回去的一方。它们相信自己在拯救大家：让所有人回到不会死的那一天。**它们不是坏人。**
- **样子**：白瓷一样的皮肤、头顶金色光环、没有五官，很干净、很安静。和守夜者的黑紫正好相反。
- 【补充】身上有细细的金色裂纹，像修补过的瓷器（金缮）。走路几乎没有声音，脚不沾水。它们走过的地方，雨会停一下，水洼里倒映出白天的天空。被斩开时整个身体碎成瓷片，瓷片里的光被斩断，化成一蓬黑羽。
- **四类**（沿用现有 AI，只换外观）：
  | 类型 | 外观（补充） | 行为 |
  |---|---|---|
  | 晨使侍从（近战） | 白袍、手持短刃，光环小 | 贴身砍 |
  | 持钟晨使（重甲） | 高大，抱一口金钟，袍子厚重 | 敲钟复原周围（治疗同伴、修复掩体） |
  | 晨使弓手 | 身形细长，弓是一道弯曲的光 | 放晓光箭 |
  | 晨使投弹手 | 手里托着发光的球 | 抛光球，炸开时照亮一片、短暂复原地形 |
- **首领**：第一晨使，永昼时代的“复原者”。
- 【补充】晨使从哪来：永昼时代负责“每天早上复原一切”的东西，斩断以后失去了工作，在长夜里游荡了几十年，现在想把工作要回来。

### 归晓教会【补充，用户 10-31 要求“有一些宗教元素，比如教堂”】
- **信什么**：黎明是神的恩典，永昼是神给人的乐园，百刃之夜是人亲手斩断了恩典。教会相信总有一天黎明会归来，所以叫“归晓”。
- **他们不是坏人。** 这是写教会时最重要的一条。
  - 教会办着雨港的疗养院（就是哥特廊桥那一片），照顾第一代老人、病人和临死的人。
  - 他们用一点点晓光当药，帮人止痛、合拢伤口。
  - 在一个会老、会病、会死的长夜里，教会是普通人唯一的安慰。
- **和其他势力的关系**：
  - **和修会**：同一座城里的两种答案。教会为黎明祈祷，修会把漏下来的光斩掉。双方表面客气、彼此需要（修会的人受伤也会被送进疗养院），心里互相看不顺眼。
  - **和晨使**：教会把晨使当成天使、黎明的先兆；晨使对教会没有任何回应，像根本没看见他们。
- **假晓是教会的仪式**：每天到“该天亮”的时候，大教堂的钟楼敲响，全城调亮灯再熄回去。雨港的钟楼（朱红表盘）就是大教堂的钟楼。
- **外观语言**：白、象牙、淡金；长袍、高领、细金边；光环形的头饰；彩色玻璃窗。注意和晨使的白瓷金环要分得开：教会是**人**，布料、蜡烛、旧书、磨损的金线；晨使是**瓷**，干净、无缝、没有五官。
- **圣物**：黑玻璃瓶里的晓光、刻着光环的银坠、5:59 停住的怀表。

### 各地的人
- 很多普通人偷偷想要黎明：第一代老人、失去亲人的人、种不出庄稼的村子。【提案】
- 每个地方的立场见第 8 节。

## 7. 社会和日常生活【补充】

这一节全部是补充，给写角色背景的人用。

### 没有太阳的生活
- **光**：雨港靠煤气灯；古堡里面有阳光。光是贵的，穷人家晚上（其实一直是晚上）只点一盏灯。
- **吃的**：庄稼越来越难种。主食是能在暗处长的东西：蘑菇、根茎、河鱼、灯下温室里种的菜（煤气灯烤着的玻璃房）。“灯下菜”是好东西，过节才吃。
- **冷**：没有太阳，世界一年比一年冷。冬天死人多。
- **病**：长夜里的人会生病，这在永昼里是不存在的。医生是新职业，七十年里才慢慢出现。晓光碎片能治病，所以黑市一直有。

### 颜色就是规则【定】

### 背景分层【定】
| 层 | 视差系数 | 内容 | 亮度 |
|---|---|---|---|
| 天空 | 最远 | 夜空、月亮、断环、云 | 最暗 |
| 远景 | 约 0.10 | 城市或山的剪影 | 暗 |
| 中景 | 约 0.35 | 远一点的建筑 | 不超过站立层的 60% |
| 近景 / 站立层 | 1.00 | 角色能站的楼、平台、街面 | 基准 |
| 前景 | 约 1.25 | 栏杆、藤蔓、铁链剪影 | 深色剪影，别挡角色 |

- 背景**按层分开出图**，不要一张图出完整画面，否则做不了视差。
- 背景里**不画角色、不画 UI**。
- 能站的地方（屋顶、阳台、挑台、桥面）要让人一眼看出能站。竖直方向约三层楼，上下要能连通。
- 角色在画面里约 110 像素高（1920×1080），所以门、窗、阳台的尺寸按这个比例来：一层楼约 280 像素。

### 出图规矩【定】
- 图片由用户自己用 GPT 或即梦生成。AI 只给中文提示词（每条单独一个代码块）+ 参考图。
- 用户给了远景、中景、近景、地面的具体描述时，**严格照写，不加地标、不改写**。
- 局部修图比整张重画可靠：要改成图，就拿成图当底图，只列要改的几处。

### 特效元素的限制【定】
- 主角的特效只用影、鸦（黑羽）、紫。**不要**月亮、魔法阵、水晶、星星当特效元素。
- 晓光和晨使的特效用白、暖白、金。

## 12. 秘密和结局（剧透，给作者看；角色在故事前期不知道）【提案】

1. **表面**：长夜里，晨使来抢夜晚。修会派斩光人守住一个又一个地方。
2. **第一层**：想要黎明回来的人比主角以为的多得多；月亮在变暗，长夜也撑不了太久。
3. **第二层**（在哪揭示还没定）：斩断黎明的真正原因不是“自由”。永昼本来就在崩坏：每天复原得越来越不完整，有人早上醒来少了一段记忆、少了一只手。斩断黎明是在所有东西被复原坏之前**止损**。
4. **第三层（浮空古堡）**：首任团长没有死。他（她）斩断黎明后后悔了，躲进古堡里那个被关住的早晨，每天醒来都忘掉自己做过的事。那个早晨是百刃之夜**唯一没斩到的一块黎明**，是首任团长自己藏起来的。
5. **各方争的**就是这个早晨：第一晨使要把它送上断环，让天重新亮起；大团长要把它熄掉，让长夜永远定下来。它是一个地方，不是谁能揣在怀里的道具。
6. **结局**由最后各方的战局决定：
   - 永昼回来（所有人回来，什么都不再改变）；
   - 长夜定下来（一切会继续失去，但会继续往前走）；
   - 第三条路：让那个早晨只升起一次、不再复原，需要很多人一起付代价（谁想出来的还没定）。
   - 主角决定的是她站在哪一方、那一战打成什么样。

## 13. 写角色背景的规矩【定，来自用户 10-31 的六次修改】

用户对主角改了六次，下面是从这些修改里总结出的口味。所有新角色同样适用。

**要做到：**
- **每个角色是对“黎明该不该回来”的一种答案**，答案来自他自己的生活，不是口号。
- 角色的特别之处来自**他在这个世界里干的事**：他的差事、他和晓光 / 长夜的关系、他每天要面对的具体选择。
- 个人故事要有分量，但**只关系到他自己和身边的人**，不决定世界结局。
- 能力用世界规则解释（第 3 节）。
- 外观、武器、配色能从出身地和职业推出来（第 10 节）。
- 要“很帅”，有魅力，有态度。

**不要做（用户已经明确否掉的）：**
- **太特殊**：天选之人、世界依托他、注定的血脉、唯一能做到某事的人。
- **神器**：只有他拔得出的剑、决定世界命运的武器或道具。
- **太平淡**：只剩“出身普通、用普通武器”，没有个人故事和态度。
- **太老套**：被家人遗忘、宿敌是叛变的搭档或青梅竹马、通灵的老动物伙伴、冷面杀手配一句固定口头禅、“其实偷偷想要 X”的秘密愿望、悲惨身世驱动一切。
- **太奇特**：职业或身份太猎奇、和世界冷峻的调子不搭（被否掉的主角方向：剑舞演员、晓光走私贩、按件计酬的公司职员）。
- **邪恶教会**：信光的人不是坏人。不要写成“光明教会其实是邪恶的”“伪善的神父”“黑暗女主揭穿教会”。光有它真实的好处，教会有它真实的善意；冲突来自两种都有道理的答案。活圣像的倒影是黑的，不等于她是恶魔。
- 不要用旧占位名：“夜鸦”“影卒 / 影弓 / 影爆”“影子怪物”都已作废。
- 不要给主角加新的悲惨过去，不要改她的大招名，不要让她成为世界的中心。
- **新鲜感不要靠画风硬求。** 哥特伦敦、教堂、鸦羽黑衣剑士这套画风很多作品用过，帅就够了；新鲜感来自世界规则、怪物和 Boss 的设计。在外观上硬求新会变成“太奇特”。
