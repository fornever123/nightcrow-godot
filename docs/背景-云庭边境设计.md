# 第一关背景「云庭边境」设计（2026-10-25，方案阶段，未改代码）

依据：`docs/世界观-天穹残响.md`（用户提供的世界观与美术总纲，最高优先级）。
本文取代 `docs/背景-哥特湖岸设计.md` 和 `docs/世界观与背景-沉钟湖.md` 的题材和配色；那两份里的**技术部分**（分层接入方式、`night_backdrop.gd` 对外接口不变、关掉像素化、处理脚本、收图检查流程）照旧适用。

## 1. 为什么第一关选「云庭边境」

- 总纲里它的作用就是“建立整个游戏‘漂亮但异常’的第一印象”，第一次看到断裂穹环。
- 明亮的青绿天空、暖沙石墙、铜绿屋顶，和主角的黑白紫反差最大（总纲第十九节：温暖梦幻世界 × 冷峻角色）。
- 一路往右打的平直地面，最自然的就是一条悬在云海上的古代石砌长堤，正好横版。

## 2. 这一关的世界观落点

- **地点**：旧天穹王国边境的「云庭」——一条古代穹环维护长堤，架在云海上方的山脊之间。坠冠日后长堤一部分断落，现在长堤边上长出了花园小镇，有风车、晾衣绳、暗红旗帜。
- **极美**：云海、花园小镇、铜绿屋顶、风车。
- **震撼**：天空里一段巨大的断裂穹环穿过云层，断口处一串环体碎片停在“正在坠落”的那一瞬（残响：定格），几百年没有落下来。
- **残响的痕迹（克制，只放远处）**：断口碎片定格在半空；云海里有一道“倒流”的细瀑布从断崖往上流进云里。都能用总纲的规则解释，不放无来由的水晶和浮岛。
- **主角**：失谐者，能进入残响区。
- **敌人「影」的建议解释**（总纲没写，供你定）：影 = 坠冠日那一刻的人留下的“时间残影”，被残响困在原地、攻击闯入者；她的紫剑能切断残响，所以一刀下去影就散了。现有的「封印」竞技场可以改称「残响点」：影聚集的地方，斩尽这一波，残响就被暂时切断。玩法不变。
- **乌鸦**：长堤栏杆、风车顶上偶尔停着乌鸦；远处有乌鸦飞向穹环断口（“乌鸦飞去的地方，旧世界还没有彻底死去”）。

## 3. 时间和配色

- **时间**：明亮的午后偏傍晚，阳光从左上来，暖色侧光。不是夜晚。
- **主色**：青绿天蓝（天空）。**辅色**：暖沙、暖灰（石材）。**点缀**：铜绿屋顶、旧金、暗红旗帜。
- **不要**：深海蓝、蓝紫天空、高饱和赛博蓝、大面积紫色和纯黑、纯白大建筑、照片感和 3D 感、数字光滑渐变、AI 式无意义的高频纹理、城堡、龙、骷髅、魔法水晶、无来由的浮岛。
- **画法**：高品质 2D 手绘水粉——厚涂、不透明颜料感、轻微干刷、纸面颗粒、大色块、3～4 阶明暗、形体清楚。
- **可读性**：角色附近简单，角色远处华丽。角色身后那条带（屏幕 y 约 420～580）只有柔和的云海和远处小镇的大色块，没有密集小物件和高亮碎片。

## 5. 对现有代码的影响（“干活”后再做）

- `night_backdrop.gd` 换层，对外接口照旧，`night_trial.gd`、`player.gd` 和大招文件不用改。
- 从夜晚改成白天，有三处要重调（都不在大招相关文件里）：
  1. 后期 `night_light.gd` / `night_post.gdshader`：月光光柱 → 阳光；冷色调色 → 暖色调色。`moon_screen()` 接口保留，返回太阳的位置。
  2. 背景退后调色 `night_pixel.gdshader`：关掉像素化和量化，去饱和/压暗参数按白天重调。
  3. 石灯笼暖光：白天 `lantern_light()` 返回很弱的值（或只在铜灯柱下面一点点），角色身上不再有明显的灯笼暖光。
- 大招黑白：明亮背景转黑白后层次照样分得开（天空亮、远景中、地面暗一档），要截图核对。
- 平台（`terrain.gd`）的像素画皮肤和中式亭子屋檐会和新背景打架，第二阶段换成暖沙石台、修补过的木台、铜顶小凉亭。
- 游戏名「夜鸦」、关卡名「月下堤岸」、UI 文案是否跟着改，由你定。
