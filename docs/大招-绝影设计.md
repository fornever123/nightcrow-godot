# 大招「绝影」设计（2026-10-24 定稿版，已实装）

## 0. 定稿过程

- 被否定的方案：「千刃」（十次瞬移斩）、只换素材的五段版、「一闪」居合、AI 刀光、月下浮空连斩（特效太少）、“化成影子剪影”（剧情说不通）。
- 用户的要求：
  - 要有动画感，表现要帅、特效要多，走 DNF 觉醒 + 艾尔之光必杀的路子。
  - 角色的元素是**影和乌鸦**，不用月亮、阵纹、晶石、星星这类元素。
  - 局内角色帧本身偏糊，不能放大；所有特写都用高清图。
  - 特效要和她背后的羽翼联动。
- 角色设定（见三视图）：她背上**只有一侧有羽翼**。大招逻辑就从这里来：影子补出另一只翼，凑成一对。

## 1. 分镜（60 帧/秒，正常放完约 3.1 秒；参数在 `player.gd` 的 `ult_*`）

1. **觉醒（0～21）**：全场定住，世界压暗、褪色（不全黑）。她脚下涌起黑色影焰，影子沿地面缠住屏幕里每只影。背后的真翼张开，另一侧由影子凝出一只影翼（纯黑、紫色轮廓）。
2. **切入（22～43）**：斜带、深紫集中线、高清化影立绘（半边脸影子化、眼睛拖光）、题字「绝影」和「绝」字印章。
3. **挑（44～59）**：上挑，把所有影挑上天，在她前方排成一排。她带着双翼升空，配向上的速度线和光柱。
4. **连斩（60～95）**：空中一段、二段，共四刀（第 69、74、83、91 帧）。每刀都有：
   - 一道横扫整排敌人的黑色影刃（紫色刃口）、星光；
   - 翅膀猛扇一下，从翼上甩出羽毛；
   - 镜头往里一顿。

   第 2、4 刀有一群影鸦穿过敌群；第 4 刀加冲击帧。
5. **蓄势（96～107）**：巨大影鸦（高清图）在她头顶前方成形，带紫色辉光。
6. **绝（108～落地）**：白闪，她和影鸦一起俯冲，配向下的速度线和竖直光线。所有影被一起砸到地上，用的是影现有的下砸物理。
7. **落地**：黑白反色冲击帧 3 帧、贴地冲击环、地面冲击。影鸦撞散成羽毛。
8. **收刀特写（落地后 6～38 帧）**：白闪切入高清甩剑背影图，按高度铺满并慢慢推近，配上下黑边。
9. **爆鸦（落地后第 38 帧，`ult_reveal`）**：切回游戏画面，每只挨刀的影碎成一群影鸦飞散。伤害数字这时才冒出来，影翼散成羽毛，真翼收拢。

镜头：局内最多推近 1.2 倍。伤害：空中每刀 6（不致死），终结 66，共 90，正好是影卒的满血。
