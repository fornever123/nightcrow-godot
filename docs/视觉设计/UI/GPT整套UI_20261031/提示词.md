# 整套 UI · 以 GPT 出图为主（10-31）

用户 10-31：“以gpt生成为主，设计ui方案”。

## 为什么换做法

左上血条前后改了七轮都没过。每轮都是我先定主题和画法，再让 GPT 照着画或由我手画，结果不是简陋就是像通用素材。
这次换过来：**设计交给 GPT，整屏一起出**。我只在提示词里写死三件事：画面上要显示哪些信息、多大、哪些东西不要。风格让 GPT 发挥，用户看图选；选中的那张图就是整套 UI 的风格标准，后面的画面都照它出。

整屏一起出还有一个好处：左上、右上、敌人头顶、弹出字是同一套语言，不会像之前那样左上改完和右上对不上。

## 流程

| 轮 | 用户用 GPT 出什么 | 附图 | 出完之后 |
|---|---|---|---|
| 1 | 整屏战斗 HUD，4 版风格各出 1 张 | 底图 + 主角立绘 | 用户挑 1 张（也可以说“A 的左上 + B 的右上”） |
| 2 | 同一风格的其他画面：大招满 / 低血状态、暂停菜单、试玩结算页、标题画面 | 选中的那张 + 底图 | 定全套样子 |
| 3 | 拆素材：每个部件单独放大画在纯黑底上 | 选中的那张 | 我抠图、切片、接进 Godot |
| 4 | 我在 Godot 里做动效（发光呼吸、白闪、残影、抖动、点亮），录实机视频 | — | 用户看实机 |

细线、血条本体、数字这些代码画更干净，第 3 轮只拆“画出来才好看”的部件：徽记、框和边角件、评价字母、分隔饰件。

## 第 1 轮：整屏战斗 HUD（4 版，用户各出 1 张）

四条提示词只有“风格”那一段不同。

### 1-1 交给 GPT 自由设计

```
第一张图是我的 2D 横版动作游戏的实机截图，1280×720，现在没有任何 UI。第二张图是游戏主角：一个黑发里有一缕白发、紫色眼睛的黑衣女剑士，身上有银色棱角甲片、紫色菱形饰物和黑色鸦羽，用一把银色长刀。游戏的场景是维多利亚哥特风格的雨夜河岸街，整体冷峻阴郁。

请在第一张截图上设计一整套战斗 HUD，画成游戏实机画面的样子。场景、人物、敌人、雨、灯光全部保持原样，只往上加 UI。画面比例保持 16:9。

画面上要有这些 UI，位置和大小严格照写：
1. 左上角：主角的生命和“绝影”能量（绝影是她的大招）。生命现在是 75/100，绝影能量攒了 3/5。整块宽度不超过画面宽度的三分之一，高度不超过 80 像素。血条要细，大约 4～6 像素高。可以有一个代表主角的小徽记，不超过 60 像素高。
2. 右上角：连击评价。一个大写评价字母“A”（评价从低到高是 D C B A S），旁边写段位名“华丽”，下面写连击数“23 连击”。整块高度不超过 120 像素。
3. 主角右边三个黑袍敌人头顶：各有一根很短很细的敌人血条，宽约 50 像素、高约 3 像素。
4. 中间那个敌人身上方：一个伤害数字“128”，小号，不要挡住敌人。
5. 画面正上方偏中：一条短短的弹出字“弹刀！”，表示刚刚弹开了敌人的攻击。

风格由你设计：要和第二张图的主角是同一套设计语言，也要放在这条雨夜哥特街上不违和。要帅，要精致，像一款成熟的商业动作游戏的 HUD，而不是手游。

```

### 第 1 轮结果（10-31）：四张几乎一样

存为 `第1轮_1-1自由.webp`、`1-2鬼泣式`、`1-3只狼式`、`1-4渎神式`。四张都是同一个结构：左上一枚紫光尖刺徽记 + 一根横血条 + 5 段紫格，右上银色大“A”带紫色划痕 + 华丽 + 23 连击，中上带饰线的“弹刀！”。差别只在徽记细节（1-3、1-4 是眼睛）。另外 1-2～1-4 的血条是红的，1-3 的“A”是红的，1-1 的血条是紫的，都不合色板。
用户：“怎么这么像”。原因是提示词本身：
1. 四条有九成字一样，结构是我写死的（左上徽记 + 细条 + 5 格、右上字母 + 段位 + 连击、中上弹出字），GPT 只能在饰件上变；
2. 风格那段太短，压不过前面一长串相同的约束；
3. 都附了同一张立绘，GPT 把她的紫菱、尖刺银甲、鸦羽直接搬成了徽记；
4. 如果是在同一个对话里连着出，前一张图也会被当成参考。

### 第 1 轮 · 拉开版（四条结构和材质都不同）

改法：只写要显示什么和多大，**结构交给每条各自规定、而且互相不同**；不附立绘，只用文字描述她；每条各开一个新对话出。
