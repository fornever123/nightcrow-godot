# 小徽细条 · GPT 整块重画（以 GPT 出图为准）

用户 10-31：五枚矢量徽记“都不行，以 gpt ai 画图出结果为准”“以 gpt 图片为主”。
从这一步起不再拿我画的矢量图当设计稿，以用户用 GPT 出的图来评。我画的 `小徽细条_实机原尺寸.png` 只当**布局草稿**给 GPT 看大小和粗细（骨架用户已经认可）。

**附图**（每版都附这两张）：
1. `小徽细条_实机原尺寸.png`：实机截图 + 左上布局草稿，让 GPT 照着大小、位置、粗细画。
2. `tools/art/src/ult/cold/portrait_hd_magenta.webp`：主角，让徽记和她对得上。

**为什么这样写**：前面 GPT 画的几版都把 UI 画得太大太满，所以每版都写死“保持草稿的大小和粗细、条要细”。徽记有 4 版：第 1 版让 GPT 自己设计，第 2～4 版指定主题。
