# 小徽细条 · 徽记（GPT 出图提示词）

用户 10-31：“骨架对，画精徽记”。骨架见 `小徽细条_实机原尺寸.png`、`小徽细条_三态放大.png`。

## 只让 GPT 画这一枚徽记

血条和绝影格用代码画（细线干净）。GPT 只出徽记，一张图里并排三个状态，框完全一样，只有眼睛不同，方便在游戏里叠化做睁眼动画：

1. **闭眼**（充能中）：眼皮合上，缝里透一线紫光。
2. **半睁**（快满 / 睁眼动画中间帧）。
3. **睁眼**（大招满）：紫色虹膜 + 黑色竖瞳，和她本人的眼睛一样。

低血变红、挨打白闪、发光呼吸都在游戏里用 shader 调色，不用另画。

**为什么要画大**：游戏里徽记只有约 55 像素高，所以要求轮廓大而清楚、对比强，细节是加分项，缩小后看不清也不能糊成一团。出图后我抠底、缩小，贴回样图给你看。

**附图**：
1. `小徽细条_三态放大.png`：看徽记的形状和在 HUD 里的位置。
2. `src/参考_她的眼睛.png`：主角眼睛的局部，看虹膜和竖瞳的样子。

## 提示词

```
给我的 2D 动作游戏画一个 HUD 徽记，放在血条最左边。第一张图是现在的占位版（最左边那个尖拱形小框和里面的眼睛），第二张图是主角眼睛的样子。

画一张宽图，横向并排三个徽记，大小、位置、外框完全一样，只有眼睛不同：
左：眼睛闭着，眼皮合成一条线，缝里透出一线紫光。
中：眼睛半睁，露出一半紫色虹膜，紫光变强。
右：眼睛完全睁开，紫色发光虹膜，中间是黑色细长竖瞳，虹膜纹理和第二张图一样，周围有一圈淡紫色光晕。

徽记的外框：竖放的哥特尖拱形，上下两头都是尖的，像一扇哥特式尖拱窗，也像一只竖着的眼睛的轮廓。外框是做旧的银，两道细边，中间刻着细细的哥特窗花纹，边缘有冷色高光。尖拱的顶端和底端各伸出一根小小的银色鸦羽形尖饰。框里是深黑色，带一点蓝紫。眼睛横放在框的正中间，眼皮也是银色雕刻，睫毛像细小的羽毛。

每个徽记大约 400 像素宽、560 像素高，三个之间留出空隙。背景透明（如果做不到透明，就用纯黑色背景，不要有任何别的东西）。
正面平视，不要透视，不要投影到背景上。轮廓要大而清楚、对比强，缩小到 50 像素高时还能一眼看出是尖拱框里的一只眼。
精致度像《鬼泣5》《猎天使魔女》的 HUD 图标，克制，不要堆装饰。颜色只用银、黑、深紫。不要金色，不要宝石、水晶，不要星星、月亮、魔法阵，不要文字。
```
