# 左上血条 / 大招 · C 影墨（GPT 概念图提示词）

用户 10-31 选 C 影墨，要求“gpt 生成吧，你多想几版”。图片由用户自己用 GPT 出。

**附图**（每版都附这两张）：
1. `docs/视觉设计/UI/现状截图_20261031/00_无UI底图.png`：实机截图，让 GPT 对上街景的画风、颜色和 HUD 大小。
2. `assets/image/ult/cutin.png`：主角立绘，让 GPT 画出能认出是她的剪影（短发、一缕白发、刀）。

**共同难点**：黑色的影子放在夜景上会看不清，所以每版都写了“边缘冷银反光 + 背后衬一层淡雾”。

| 版 | 血 | 绝影 | 一句话 |
|---|---|---|---|
| 1 墨痕一笔 | 一笔书法墨痕的长度 | 起笔浓墨里聚出的侧脸剪影，眼缝紫光 | 最“帅”、最鬼泣 / 只狼 |
| 2 路灯长影 | 她被路灯拉长、投在湿石板上的影子 | 剪影从脚往上填紫 | 和雨街路灯绑在一起，最有场景感 |
| 3 角落影渊 | 从屏幕角落渗进来的黑暗，沿上沿爬多远 | 黑暗里一只只睁开的紫眼 | 接大招的“影子化 / 领域”，最有压迫感 |
| 4 墨刃 | 一条浓墨带，尾端被撕成影羽飘走 | 斜穿墨带的刀光，从护手往刀尖亮紫 | 影 + 刀，最干净、读数最清楚 |

动效（之后在 Godot 里做）：墨的边缘一直像烟一样流动；挨打时墨被打散、溅出墨点或影羽，失去的那段先留一道淡灰残影再退；低血时墨变薄、发抖、烟更多；放大招时紫光一下子冲满，然后墨收回去重新长。

## 第 1 版：墨痕一笔

```
第一张图是我游戏的实机截图（1280×720，雨夜哥特街道，2D 横版动作），第二张图是主角立绘（黑衣女剑士）。在第一张图的左上角画上血条和大招 UI，画面其他地方保持原样。

UI 是一笔横向的书法墨痕：用一支大毛笔从左往右一笔扫出去，起笔重而圆，收笔带飞白和散开的细墨点，长度约占画面宽度的三分之一。这一笔的长度就是血量，现在大约是四分之三；收笔后面还拖着一段很淡的灰色墨痕，表示刚失去的血。
墨是浓黑色，底色带一点蓝紫，表面湿亮，边缘有冷银色反光。墨痕上沿有几缕黑烟往上飘，像影子在蒸发。
起笔处的浓墨里聚出主角的侧脸剪影，要能认出是第二张图里的她（短发，有一缕白发）。剪影眼睛的位置是一道细长的紫色光缝，半睁着，代表大招正在充能。
墨痕右端用骨白色的斜体衬线字写血量“75”。墨痕背后衬一层很淡的灰白雾气，让黑墨在夜景上看得清。

颜色只用墨黑、冷银灰、骨白和深紫，紫色只用在眼睛上。不要金色，不要宝石、水晶，不要魔法阵、月亮和星星。
画风和截图里的街景一致：半写实手绘，暗调，带雨夜冷光。UI 正面平视，轮廓清楚，宽不超过画面的三分之一，高不超过画面的五分之一。
```

## 第 2 版：路灯长影

```
第一张图是我游戏的实机截图（1280×720，雨夜哥特街道，2D 横版动作），第二张图是主角立绘（黑衣女剑士）。在第一张图的左上角画上血条和大招 UI，画面其他地方保持原样。

UI 是主角被路灯拉长的影子。左上角是她半蹲、手按刀柄的居合架势全身黑色剪影，大约 90 像素高，要能认出是第二张图里的她（短发，一缕白发，腰间的刀）。她身后左边有一点暖黄的路灯光晕。
她脚下有一条长长的影子，向右平铺出去，像被身后的路灯拉长、投在湿漉漉的石板地上。这条长影就是血条：影子的长度就是血量，现在大约是四分之三。影子尖端像墨一样晕开；尖端后面只剩一段很淡的水渍倒影，表示失去的血。影子下面是一条细细的湿石板边线，有积水反光和雨点涟漪。
剪影内部从脚往上渐渐被深紫色的光填满，现在填到腰部，代表大招正在充能。
影子右端用骨白色的斜体衬线字写血量“75”。整个 UI 背后衬一层很淡的灰白雾气，让黑色的剪影和影子在夜景上看得清，剪影和影子的边缘有冷银色的反光。

颜色只用墨黑、冷银灰、骨白、深紫，加上一点点暖黄路灯光。紫色只用在剪影里。不要金色，不要宝石、水晶，不要魔法阵、月亮和星星。
画风和截图里的街景一致：半写实手绘，暗调，带雨夜冷光。UI 正面平视，轮廓清楚，宽不超过画面的三分之一，高不超过画面的五分之一。
```

UI 是从屏幕左上角渗进来的一团活的黑暗，像浓墨在湿纸上漫开，边缘伸出细长的影子触须和黑烟。黑暗沿着屏幕上沿往右爬出一条带状的边，这条边伸到哪里就是血量，现在伸到画面宽度的三分之一左右，最前端是还在往前爬的墨须；墨须后面有一段很淡的灰色痕迹，表示失去的血。
角落那团黑暗的中心有一只大眼睛，旁边的影子里还藏着四只小一些的眼睛。五只眼睛里有三只已经睁开，是发光的紫色竖瞳，另外两只还闭着，只透出一条紫缝。睁开的眼睛越多，大招越满。眼睛的样子和第二张图里主角的紫色眼睛一致：冷、锐利，不要恐怖血腥。

颜色只用墨黑、冷银灰、骨白和深紫，紫色只用在眼睛上。不要金色，不要宝石、水晶，不要魔法阵、月亮和星星。
画风和截图里的街景一致：半写实手绘，暗调，带雨夜冷光。UI 正面平视，轮廓清楚，宽不超过画面的三分之一，高不超过画面的五分之一。
