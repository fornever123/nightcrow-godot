# 左上血条 / 大招 · 紫菱羽翼（我自己定的角度）

用户 10-31 看完影墨四版：“都不行，自己想角度”。

## 角度：HUD 跟她走，不跟街景走

前面五轮（剑、斜刃 / 鸦眼 / 爪痕、银鸦、影墨……）都在配**街景**：暗、旧银、哥特、墨。可是她本人的立绘（`cutin.png`、`portrait_hd_magenta.webp`）是另一套语言：
- 亮面、锋利的**银色棱角甲片**，带斜切倒角和尖角；
- 头饰、领口、腰带、护手上反复出现的**紫色菱形宝石**——这就是她的标志；
- 黑底、往蓝紫渐变的**鸦羽翅膀**；
- 刀身上的**紫色电纹**。

左上角是“她”的状态，所以 HUD 应该像是同一个角色设计师给她画的配件：清楚、锋利、有光泽、高对比，而不是又一件做旧的哥特摆件。紫色本来就留给主角，在这里用是对的。菱形宝石来自她的服装，不是大招特效里禁止的“水晶”。

## 设计

- **紫菱头像框**：左边一个竖放的菱形框，就是她身上那颗紫菱的形状放大。银色棱角边框，斜切倒角，四个角是尖的。框里是她的头像（黑发一缕白、紫眼、羽毛头饰），和立绘同一种画风。
- **半边羽翼**：菱形框后面向左上展开半边鸦羽翅膀，黑羽、羽尖往蓝紫渐变，和立绘的翅膀一样。
- **血条**：从菱形右角往右伸出一根锋利的银框长条，两端是斜切尖角，条身亮白带淡紫光泽，用小菱形刻度分格；掉的那段先变淡紫残影。
- **绝影条**：血条下面一根更细的条，深紫色，里面流着和刀身一样的紫色电纹。
- **动效**（之后在 Godot 里做）：充能时电纹在绝影条里流动，菱形框边缘的紫光慢慢变亮；满了翅膀一下子全展开、羽尖亮紫，头像的眼睛亮起，菱形框闪一道电纹；挨打时菱形框白闪、整块一抖、血条掉的那段碎成小菱形片；低血时头像变暗、血条透出酒红；放大招时翅膀收拢、羽毛向右飞出。
