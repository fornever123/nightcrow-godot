# 左上血条 / 大招 · 银鸦落羽（① 银鸦骨雕 + ③ 鸦翼落羽）

用户 10-31 选 ① + ③ 混搭。图片由用户自己用 GPT 出，这里放提示词和附图说明。

## 设计

- **鸦首**：左端旧银雕乌鸦头侧面，喙朝右。鸦眼是空眼窝，平时透一点紫光呼吸；大招满了睁成紫色竖瞳（接大招开场的“眼睛”）。
- **血 = 玻璃管里的暗酒红液体**：鸦首后面伸出一根银箍玻璃管（像手杖杆），液面高度就是血量，读数是连续的。右端银尖封头，旁边斜体衬线血量数字。
- **绝影 = 管下 5 根鸦羽**：黑羽银边，能量从羽根往羽尖填紫。不用宝石 / 水晶（§1：大招元素不要水晶）。
- **③ 的落羽当挨打特效**：挨打时饰件上被打落几根黑色碎羽，沾着雨往下飘。

## 动效

| 状态 | 动效 |
|---|---|
| 常态 | 银面反光每几秒扫过一次；液面随角色跑跳轻晃；眼窝紫光呼吸 |
| 充能 | 羽毛从羽根往羽尖填紫；一根满时银边一闪、羽毛轻抖 |
| 大招满 | 翅膀微张，5 根羽毛紫光脉动；鸦眼睁成紫色竖瞳；“J+K 绝影”从翅尖滑出 |
| 挨打 | 整件抖；液面猛晃溅起；玻璃管闪一道裂纹再淡掉；掉的那段先留淡紫残影再退；几根碎羽被打落、沾雨飘下 |
| 低血 < 30% | 液体随心跳一明一暗；玻璃留细裂纹；鸦首暗下去；偶尔掉一根羽毛 |
| 放大招 | 5 根紫羽一齐向右射出，鸦眼闪白；羽毛变暗，再从羽根慢慢长回 |
