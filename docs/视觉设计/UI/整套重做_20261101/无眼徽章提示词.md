# 整套 HUD · 左上徽章不带眼睛（GPT，11-01）

用户 11-01 看了银羽影版的出图后说：“这个眼睛不行，换一个”“不能有眼睛”。
→ 左上徽章里不画任何眼睛（不画人眼，也不画乌鸦的眼睛）。其余照银羽影版：
- 整套材质是银色。
- 徽章要有紫色、鸦羽和影子。
- 布局保留：红血条和“75 / 100”、五格紫色大招条、中间“弹刀！”横幅、右上“A / 华丽 / 23 连击”、敌人小血条、伤害数字。
- 不要菱形。

徽章元素取自设定集里修会的纹章（十字、鸦羽）、修会制式长剑，以及斩光规则（被斩断的光落成黑羽、七十年前那一剑斩碎了天上的光环）。纹章里本来有紫菱，按用户要求去掉。

整套要精致、帅、有气势，像精品 2D 动作游戏的 HUD。不要任何眼睛，不要任何菱形或钻石形的装饰（剑的护手和柄头也不要嵌菱形宝石），不要金色，不要星星、月亮、魔法阵、水晶，不要大面板。
