# 模仿版 · 左上徽记动势版（GPT，11-01）

用户 11-01：“不好看这个图案太死板”（看的是左上的徽记：模仿版的双线银边菱形 + 下挂尖饰，以及之前那些圆 / 十字 / 尖拱徽记）。
**问题**：徽记全是左右对称、四平八稳的规整框，静止，和血条各管各的。
**改法**：其他照模仿版不动（Lilies 式两头双箭头发丝细血条、“75 / 100”、绝影 + 五颗暂停菜单式紫菱、波次字、右上哥特“A”）。只换左上徽记：**不要框、不对称、像动作做到一半被定格，徽记和血条长在一起**——血条的银色发丝框从徽记甩出的那一笔里延伸出去。风格守暂停菜单：银色发丝线、哥特感、紫色只用在发光点和紫菱上。以 GPT 出图为准（用户 10-31）。
