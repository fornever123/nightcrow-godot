## 一、这个风格到底是什么

视频里出现了三套场景：月夜湖边、黄昏森林、雾中遗迹。它们的共同点如下。

| 项目 | 特征 |
|---|---|
| 画法 | **水粉 / 绘画式概念美术**。柔和笔触、空气透视，近处细节密，远处虚化。不描线，也不是平涂赛璐璐 |
| 分层 | 固定四层：远景（雾、山、远塔）→ 中景（拱门、石柱、残墙）→ 地面条带（可行走）→ 前景（近黑剪影草丛、树根、残墙） |
| 明度 | 远景中低明度、偏青；中景中明度；地面中明度、细节最多；**前景几乎纯黑** |
| 配色 | 青绿、靛蓝、灰黑做底；**暖琥珀色只用来点缀**（窗口微光、石缝、发光小植物） |
| 构图 | 严格侧视；中央下方留出清晰的行走区；左右两端用前景剪影框住画面 |
| 工艺 | 宽幅图、左右无缝平铺；透明层统一用纯洋红 `#ff00ff` 做抠像底 |

### 和我之前推导的结论对照

| 我之前的推导（`背景美术方向.md`） | 参考视频 | 结论 |
|---|---|---|
| 青灰作冷色基调 | 青绿、靛蓝 | ✅ 一致 |
| 琥珀只作点缀 | 琥珀只作点缀 | ✅ 一致 |
| 越远越暗、越软 | 同样 | ✅ 一致 |
| 前景加深色剪影 | 有，而且很重 | ✅ 一致 |
| 近处赛璐璐 + 粗描边 | **水粉绘画，不描线** | ❌ 不一致，改为参考视频的画法（见第三节） |

明暗和配色方面，你选的参考和可读性测试得出的结论基本一致。真正需要改的只有「画法」这一项。

## 二、合成测试：把我们的角色放进参考场景

380 px 角色放进遗迹场景，做了三个版本：原画、轻度像素化（3 px 块）、像素化加白色轮廓光。

### 结果

1. **原画版：角色能看清，但像贴上去的。** 角色是平滑的赛璐璐，背景是带颗粒感的绘画笔触，质感不一样。
2. **轻度像素化：融入得最好。** 像素块的硬边和背景笔触的颗粒感接近，角色像是属于这个画面。380 px 下面部和护甲仍然能看清。
3. **白色轮廓光：淘汰。** 像贴纸，很廉价。需要轮廓光的话，只能用很细的低亮度冷色边，不能用白色。

### 意外收获：像素化顺带解决了刀光锯齿

之前查出刀光边缘有 AI 放大留下的阶梯和块状纹理。像素化以后，这些阶梯变成了**看起来是故意的像素台阶**，问题基本消失。刀光拆层仍然值得做，但不再紧急。

### 暴露的问题：前景剪影挡住了角色

测试里角色正好站在参考图前景那根大黑柱后面，身体被挡掉一大块。参考视频本身是场景展示，不是战斗游戏，所以可以这样放；我们的战斗画面不行。

## 三、修正后的背景方向

**采用参考视频的「水粉概念美术 + 四层视差」，再加三条战斗游戏专用的规则。**

### 保留参考视频的做法

- 水粉 / 绘画式概念美术画法。
- 四层：远景、中景、地面条带、前景。
- 青绿、靛蓝、灰黑做底，琥珀点缀。
- 宽幅无缝平铺，洋红 `#ff00ff` 抠像底。

### 必须加的三条规则（参考视频没有，战斗需要）

| 规则 | 原因 |
|---|---|
| **前景剪影只放在画面左右两端和底部 20% 以内**，中央行走区绝不放遮挡物；需要放大件遮挡物时，角色走到它后面就半透明 | 测试里角色被前景挡住，战斗中这会直接看丢自己 |
| **地面条带的纹理要比中景安静**：行走线附近细节少、对比低，复杂纹理只放在条带下方的剖面里 | 参考场景地面很花，380 px 角色脚下也是花的，落地、受击时读不清 |
| **背景禁用饱和紫，夜景的蓝也要压饱和度** | 角色的紫发、紫刀光一碰紫背景就融进去（可读性测试已证明）。月夜场景那种高饱和靛蓝离紫太近，要压低 |

### 角色的配合方式（你说可以略微像素化）

- **推荐轻度像素化**：显示 380 px，内部按 1/3 分辨率渲染（块大小 3 px），颜色减到约 48 色，保留深色描边。
- 2 px 块（更细腻）还没测；最终块大小进游戏实测后定，做成可调参数。
- 不加白色轮廓光。需要分离时，用 1–2 px 的暗青色描边，或者给角色脚下加一块小阴影。

## 四、生图提示词（按参考视频的结构，针对我们的规则修改）

参考视频的提示词结构很好用：**用途 → 素材类型 → 画面内容 → 风格 → 构图 → 抠像底 → 平铺要求**。下面沿用这个结构。参考视频用中文提示词出图效果就不错，所以这里以中文为主，GPT 和 Gemini 都能直接用。

> 场景暂定为「幽暗遗迹」，只是占位。题材定下来后，只需要替换「画面内容」一段，其余照抄。

### 尺寸说明

- 首选 2:1 超宽幅。工具不支持 2:1 时，用 16:9 或 21:9 生成，再裁成需要的比例。
- **无缝平铺 AI 经常做不好**。拿到图后先检查左右边缘能不能接上；接不上就用第六节的「修接缝」提示词。

### 1. 远景层（不透明）

```
用途：风格化概念美术
素材类型：2D 横版动作游戏的不透明远景层

生成一张超宽幅 2:1、严格侧视的幽暗遗迹远景。远处由多层青绿色和灰蓝色山脉剪影、模糊的废墟高塔、残破城墙和柔和的雾气组成。加入几处被空气透视弱化的远古石质建筑，只在极少数远处窗口加入克制的暖琥珀色微光。地平线保持较低且安静，为下方的游戏区域保留清晰空间。

风格：高品质手绘幻想游戏背景，水粉与绘画式概念美术，柔和笔触，丰富的空气透视，神秘、寂静；不要照片感，不要 3D 渲染感。整体明度中低，低对比。

色彩限制：以青绿、灰蓝、灰黑为主，饱和度偏低。画面中禁止出现紫色和高饱和蓝紫色。

构图：严格侧视宽幅风景，不要前景剪影，不要近处地面，不要人物、角色、文字、UI、边框、Logo 或水印。避免强烈的中央地标。

水平要求：可水平无缝平铺，左右循环。左右边缘的雾气颜色、山体高度、遗迹密度和空气亮度必须自然衔接。避免可见接缝、左右镜像对称和重复地标。
```

### 2. 中景层（透明，洋红底）

```
用途：风格化概念美术
素材类型：2D 横版动作游戏的透明中景视差层

生成一张超宽幅 2:1、严格侧视的遗迹中景。由不规则分布的断裂石拱门、开裂的墙体、风化石柱、坍塌石块和垂落藤蔓组成。使用深青灰、低饱和青绿和灰黑色石材，只在少量裂缝和石块边缘加入克制的暖琥珀色轮廓光。遗迹之间保留不规则空隙，画面中央下方 40% 的区域必须保持空旷，不放任何建筑。

风格：高品质手绘幻想游戏环境，水粉概念美术，石材轮廓自然清晰，有岁月感和柔和空气透视，达到正式游戏素材的完成度。整体明度中等，比远景亮一档。

色彩限制：禁止使用紫色和高饱和蓝紫色。

所有美术必须绘制在完全平坦、纯色的 #ff00ff 洋红抠像背景上。背景必须是绝对均匀的单一颜色，不得有渐变、阴影、光晕、雾气、纹理或光照变化。美术主体中禁止使用 #ff00ff，石块、藤蔓边缘必须与背景清晰分离。

水平要求：可水平无缝平铺，左右循环。左右边缘的遗迹高度、墙体密度、藤蔓分布必须自然延续。不要人物、角色、天空、完整地面、文字、UI、边框、Logo 或水印。避免镜像对称、成对重复的拱门和边缘突变。
```

### 3. 地面条带（透明，洋红底）

```
用途：风格化概念美术
素材类型：2D 横版动作游戏的实体可行走地面条带

生成一张超宽幅 2:1、严格侧视的遗迹可行走地面。顶部是一条连续、平直、清晰的行走线，位于画面高度约 58% 处。行走线附近的石板表面要安静：细节少、对比低、颜色统一，确保角色站在上面时脚下清晰可读。行走线下方是深色土壤与碎石剖面，复杂的树根、碎砖和苔藓只放在剖面里。

风格：高品质手绘幻想游戏地形，水粉概念美术，轮廓清晰。用低饱和青灰色和灰黑色，只有零星暖琥珀点缀。地面表面是整张图中明度最高的大块面。

色彩限制：禁止使用紫色和高饱和蓝紫色。

完整地面条带必须放在完全平坦、纯色的 #ff00ff 洋红抠像背景上。行走线上方必须是绝对均匀的 #ff00ff，不得有渐变、雾气、纹理、阴影或颜色污染。地形主体中禁止使用 #ff00ff。

水平要求：可水平无缝平铺，左右循环。左右边缘的行走线高度、石块密度、剖面厚度必须自然衔接。不要树木、人物、角色、天空、文字、UI、边框、Logo 或水印。避免等间距石块、中央地标和可见接缝。
```

### 4. 前景层（透明，洋红底）

```
用途：风格化概念美术
素材类型：2D 横版动作游戏的透明近景前景层

生成一张超宽幅 2:1、严格侧视的近距离前景。只在画面最底部 18% 范围内放置不规则的近黑色草丛、扭曲树根和低矮碎石；只在最左侧 12% 和最右侧 12% 各放一段近黑色残墙剪影。画面中央和上方必须完全空旷，不得有任何物体，确保玩家角色和战斗始终清晰可见。只在少量叶片边缘使用极其克制的青绿色轮廓光。

所有美术必须绘制在完全平坦、纯色的 #ff00ff 洋红抠像背景上。背景必须是绝对均匀的单一颜色，不得有渐变、阴影、纹理、光晕、雾气或光照变化。植被和石块中禁止使用 #ff00ff，细小边缘必须能被准确抠出。

水平要求：可水平无缝平铺，左右循环。避免高墙、镜像对称、中央物体、人物、文字、UI、边框、Logo 或水印。
```

## 五、风格一致性（第二批起必用）

四层分开生成时容易各画各的。先出远景，满意后，后面三层都附上远景图作参考，并在提示词开头加：

```
参考附图的画风、笔触、色调、明度和空气透视，保持完全一致的绘画风格，只生成下面描述的图层内容。
```

Gemini 支持多张参考图。可以把已经满意的两层一起附上，后续图层的一致性会更好。

## 六、辅助提示词

### 修接缝（AI 平铺没做好时）

先把图片左右各切一半、交换位置（中间就会露出接缝），再交给 Gemini 编辑：

```
只修改画面正中央的竖直接缝区域，让左右两侧的山体、雾气、石块和光照自然连续。保持画面其余部分完全不变，不改变风格、颜色和构图。
```

### 灰度校验

```
把这张图以完全相同的构图重新渲染为灰度明度稿，不要任何颜色。远景最暗，中景中灰，地面表面是最亮的大块面，中央行走区域明度平静、没有杂乱细节。
```

## 七、验收标准

- [ ] 合成 380 px 角色（轻度像素化版）后，缩到 1920×1080，角色轮廓不用猜就能看清。
- [ ] 角色在行走区任意位置都不会被前景遮挡。
- [ ] 角色脚下的地面纹理是安静的。
- [ ] 背景中没有饱和紫和高饱和蓝紫。
- [ ] 四层左右都能无缝平铺。
- [ ] 洋红底能干净抠出，边缘没有洋红残留。
