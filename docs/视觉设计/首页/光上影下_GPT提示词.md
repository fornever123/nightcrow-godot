# 首页「光上影下 · 影子先动」GPT 出图提示词（11-01 第二版）

- 用户看了程序画的样片说“样式不好”，选了“整体太白太素”和“程序画的质感不行”，所以改成美术图打底：用户用 GPT 出图，首页会话在图上做动效。
- 第一版提示词（只有教堂、白瓷像和水）用户说“不够帅”，所以改成这一版。

**这一版怎么变帅**：
- 主角上画面，当主体。
- 尺度反差：巨大的白瓷圣像压在她头顶，水里是同样巨大的黑影，从下面朝她伸手。
- 仰拍、广角，大明暗对比。
- 画面里全是动势：飘起的鸦羽、斜落的雨、半出鞘的紫光剑。

**流程**：先出图 0 一张总图，判断帅不帅、构图对不对。定了以后，再按图 1～4 分层出图，给动效用。

**动效计划（分层图回来后做）**：
- 光柱里的雨珠停着，光柱外的雨照常落。
- 水里的巨大黑影一直在动：手往上抓、头扭过来、墨丝往下淌。黑影先动，过 0.6 秒，上面的白瓷像才一顿一顿地照做（手指微动、头偏一下，裂纹多一道）。
- 她的鸦羽和发梢一直被风吹着，剑上的紫光沿刃口偶尔流过一次。
- 字标和菜单沿用暂停菜单那一套。菜单倒影在水里，选光标时倒影先动。
- 开场：5:59，旧光一熄、新光一亮（光柱在同一帧亮起）→ 黑影先从水底浮上来 → 白瓷像才显形 → 她的剑亮起紫光。
- 按“开始”：她一刀斩断光柱，停住的雨全部砸下来，白瓷像从斩口裂开，黑羽炸开，接进游戏。
