# 压掉 GPT 味：问题拆解与新提示词

对象：用户用 GPT 生成的「① 云海浮岛」（`ref/gpt-skyisland-v1.png`）。
合成检验：`art/gpt-skyisland-fit.png`（380 px，3 px 像素化角色）。

---

## 一、这张图能不能用

**场景选对了。** 浮岛、云海、锁链、霞光都在，天空开阔，适合击飞和浮空。合成后角色清楚，紫色刀光在青绿和暖金的背景上很跳。

但它有明显的「GPT 味」，同时有几处做不成游戏背景：

### GPT 味具体是什么

| 特征 | 表现 |
|---|---|
| 统一的暖黄滤镜 | 整张图像蒙了一层琥珀色，明暗都偏黄 |
| 「精致插画」质感 | 所有地方细节一样多，笔触均匀细碎，没有轻重 |
| 均匀的雾 | 雾气平铺在整张图上，没有疏密变化 |
| 标准构图 | 太阳居中偏右、两侧对称放废墟，像手机壁纸 |
| 过度平滑 | 缺少参考视频那种明显的笔触颗粒和色块 |

**原因**：GPT 生图有很强的默认审美，不给参考图时会自动往「漂亮插画」靠。只靠文字很难完全压住，**最有效的办法是喂参考图**。

### 更正（2026-10-15）

本节初版列了「地面是俯视的」「太阳太亮」等问题，**判断有误，已撤回**：
- 略带俯角、能看到地面表面的画法是对的，参考视频的遗迹场景就是这样，横版游戏常用它来增加空间感。
- 光照不是关键问题。
- 「地面下方的倒影」保留为可选修改项，不强制。

真正的问题是**角色比例**，见 `角色显示尺寸.md` 第零节。

## 二、压掉 GPT 味的四个办法

按效果排序：

1. **喂画风参考图（最有效）**：把参考视频的截图作为参考图一起上传，写明「只参考画风，不参考内容」。我已经裁掉了 B 站水印和头像，放在 `ref/ref-ruins-style.png`（遗迹）和 `ref/ref-night-style.png`（月夜）。用遗迹那张就行。
2. **写清楚「不要什么」**：在提示词里直接点名 GPT 味的特征：不要整体暖黄滤镜、不要均匀细节、不要均匀雾气、不要对称构图、不要壁纸感。
3. **换 Gemini 试同一条**：Gemini 的默认风格比 GPT 弱，更听参考图的话。两边都跑，哪边像就用哪边。
4. **出图后用「编辑」修，不要重新生成**：比如「只把整体色调去掉暖黄，其余不动」。

## 三、新提示词（可直接复制）

### 用法

1. 上传参考图 `ref/ref-ruins-style.png`（在 `E:\00game\nightcrow-godot\docs\视觉设计\ref\` 里）。
2. 粘贴下面的提示词。GPT 和 Gemini 用同一条。
3. 比例设 16:9，每次出 4 张。

### ① 云海浮岛 · 第二版

```
参考附图的绘画风格：水粉概念美术的笔触、色块和颗粒感，近处细节密、远处概括虚化，明暗对比清楚。只参考画风，不要参考附图的内容和构图。

用途：风格化概念美术，用于横版动作游戏场景
素材类型：2D 横版动作游戏的完整场景概念图

生成一张 16:9、侧视的横版游戏场景：黄昏时漂浮在云海之上的古代石岛群。
远景：层层云海和几座被雾气虚化的悬浮岛屿剪影，天空上半部分是偏暗的青灰色，只在地平线附近有一条克制的暖金色霞光，看不到太阳本体。
中景：几座挂着断裂锁链和垂藤的浮岛，岛底露出岩石根系，岛上立着残破的石拱和石柱。浮岛分布有疏有密，左右不对称。
近景：一块宽阔的浮岛石台作为可行走的战斗地面，可以看到略带俯角的石板表面和正面的岩石剖面。

风格：高品质手绘幻想游戏背景，水粉与绘画式概念美术，笔触明显、色块概括，有轻有重：近处和中景的边缘清楚，远处大面积概括。不要照片感，不要 3D 渲染感。

色彩：以低饱和青灰、灰蓝、冷灰石色为主，暖金色只出现在地平线和少数云边。不要整体暖黄滤镜，暗部保持冷色。画面中禁止出现紫色和高饱和蓝紫色。画面最亮处不要接近纯白。

构图：画面中央下方 40% 是空旷平静的石台和云海，细节少、对比低，用来放置玩家角色。石台顶边是明确的水平线，位于画面高度约 78%。近黑色前景剪影只允许出现在画面最左侧、最右侧和最底部边缘。避免对称构图和壁纸式的居中太阳。

不要：人物、角色、怪物、文字、UI、边框、Logo、水印；均匀的细节；平铺整张图的均匀雾气。
```

### 如果出来还是太黄（用编辑功能，不要重新生成）

```
只修改整体色调：去掉画面上的暖黄色滤镜，让暗部和天空上半部分变成冷青灰色，暖金色只保留在地平线和少数云边。构图、物体、笔触全部保持不变。
```
