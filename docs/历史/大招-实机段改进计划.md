# 大招「绝影 · 鸦羽止」实机段改进计划（2026-10-26）

> 范围：过场视频结束后、回到游戏的那 124 帧（第 124～248 帧）：冲击帧 → 静 → 咔 → 落。
> 现状截图：`docs/ult-v4-ingame.png`。本文只是计划，用户批准后再动代码。

---

## 1. 现在为什么难看（对照实机截图）

1. **太小。** 镜头已经放大到 1.5 倍，她和影卒在屏幕上仍只有 40～60 像素高。裂开、碎片、羽毛都只有几个像素，看不清发生了什么。
2. **画风打架。** 过场是高清插画，她的定格图也是高清，但地面、背景、影卒是像素画，放大后格子发糊。从过场切回来，画质一下子掉档。
3. **特效是"程序线条"。** 刀线只有 1～2 像素；羽毛是多边形色块，看起来像短横线；碎片是小三角。没有辉光、没有扭曲、也没有屏幕级效果。和过场里有体积、有光的羽毛完全不是一个级别。
4. **静的那 0.7 秒没东西可看。** 设计要的是"静"，但画面小、对比低，静变成了空。
5. **落的那一下不够狠。** 四个影卒同时、小小地裂开，颜色慢慢恢复；没有逐个斩开的节奏，也没有冲击感，画面也没有错位。
6. **镜头一直是一个机位。** 过场里镜头在推、在甩，回到游戏后整整两秒只有一个远景。

## 2. 网上查到的做法（能直接借用的）

- **刀光形状**（[Slash FX 教程：刀光形状基础](https://jasontomlee.itch.io/slashfx/devlog/629732/tutorial-2-slash-shape-fundamentals)）：刀光是一条干净的弧（月牙），前端宽、尾巴收尖，像旗子或风向袋；弧度跟着挥刀轨迹；**最饱满的那一张只出现 1～2 帧**。
- **卡通风特效的规矩**（[RealtimeVFX：Punk Strike 斩击讨论](https://realtimevfx.com/t/punk-strike-slash-cinematic-vfx-unity/27553)）：不用软渐变，改用两色硬边、网点或排线；冲击光芒的大小跟打击力度挂钩。
- **冲击帧**（[Know Your Meme：Impact Frames](https://knowyourmeme.com/memes/cultures/impact-frames)、[3DJuegos：什么是作画](https://www.3djuegos.com/manga-anime/noticias/que-sakuga-que-importante-para-anime-cuando-animacion-se-convierte-espectaculo)）：只闪一瞬、常用黑白、常配合慢放和变形。我们的白底黑剪影加反相方向是对的，问题是剪影太小。
- **打击感参数**（[Godot 论坛：手感清单](https://forum.godotengine.org/t/game-feel-checklist-for-godot-4-hit-stop-trauma-shake-coyote-time-and-more/145340)、[Wayline：Game Feel 第 2 课](https://www.wayline.io/learn/game-feel/1)）：顿帧 50～120 毫秒（3～7 帧）；震屏用 trauma²；受击闪白约 0.12 秒褪掉；一次只加一种效果，逐个调。
- **屏幕级效果现成可用**（[Godot Shaders：扭曲 / 冲击波](https://godotshaders.com/shader/distortion/)、[Godot Shaders：带扭曲的速度线](https://godotshaders.com/shader/distortion-speed-lines/)、[Godot Shaders：动漫速度线](https://godotshaders.com/?p=16778)）：都是读屏幕纹理的画布着色器，放在一个 CanvasLayer 的 ColorRect 上。我们的黑白层已经是这种写法，可以直接加。
- **我们引擎的限制**（[Godot 文档 PR：2D HDR 只在 Forward+ / Mobile](https://github.com/godotengine/godot-docs/pull/8285/files)、[Godot 论坛：拖尾粒子](https://forum.godotengine.org/t/slash-animation-with-trails/52513)）：项目用的是 GL Compatibility，**没有 2D 辉光（HDR 2D）**，粒子拖尾也不一定支持。所以光感要靠叠加混合的贴图自己做，不能指望引擎的 glow。
- **层次与可读性**（[80.lv：《Hades》特效幕后](https://80.lv/articles/a-behind-the-scenes-look-at-the-effects-in-hades/)，文章正文没抓全，只能参考大方向）：特效压在角色和地面之上，按"先看什么"分层控制亮度和密度。

总结：参考作品的共同点是**镜头近、形状干净、关键帧只闪一两帧、用贴图而不是线条做光**。我们缺的正是这几样。

## 3. 改法（按段落）

时间不变：仍是 124 帧（2.07 秒），整招仍 248 帧（4.13 秒）。

### 3.1 镜头：从一个机位改成三个机位（解决"太小""只有一个机位"）

| 帧 | 机位 | 内容 |
|---|---|---|
| 124～127 冲击帧 | 中景，放大约 2.2 倍，对准敌群中间 | 剪影大一倍，刀线横穿全屏 |
| 128～150 静（前半） | **近景，放大约 3 倍，对准她**，低位收势占画面三分之一 | 她只留紫色，背后是一排定住的影卒剪影，刀线从她的剑尖延伸出去 |
| 151～167 静（后半） | 慢慢拉到中景，能同时看到原地的影子和她 | 影子轻轻闪，刀线上被切开的羽毛错开 |
| 168 咔 | 硬切到近景（她的腰和剑） | 跳切到收剑姿势、一线白光、画面沿刀线错开 |
| 174～ 落 | 硬切回中景 | 影卒从左到右依次被补刀、裂开 |
| 末尾 30 帧 | 拉回平常的镜头 | 交还操作 |

做法：沿用现在的锚点和 snap_to_target，每个机位写好 zoom 和中心，用硬切而不是缓动（缓动只用在 151～167 那一段）。

### 3.2 画质：大招期间统一成高清（解决"画风打架"）

- 大招黑白期间，背景、地面已经被压暗、去色，再加一层**轻微模糊 + 暗角**，像景深那样往后推，像素格就不显眼了。
- 影卒在大招里换成**纯黑剪影 + 一圈冷灰边**（静的时候本来就该定住、看不清细节），不再露出像素细节。
- 她的定格图保持高清。

### 3.3 特效换成贴图（解决"程序线条"）

全部用 GPT 出图（按规矩先给提示词、附参考图），我负责抠图、切片和接入。每张都是黑底或纯色底，接入时用叠加混合，自己做出发光感。

| 素材 | 用在哪 | 说明 |
|---|---|---|
| 横向刀线 1 张（白芯、外缘一线紫、两头收尖、带一点毛边） | 冲击帧到静 | 代替 1 像素线；宽度按镜头缩放 |
| 鸦羽 8 片（单片、黑色带紫边、不同角度和大小） | 悬停羽毛、被切开的羽毛、影子碎羽 | 代替多边形；切开的用贴图加遮罩裁成两半 |
| 斩痕 3 张（短促的月牙形、两色硬边） | 落：每个影卒被补刀时闪 2 帧 | 按刀光形状规矩：前宽后尖，只出现 1～2 帧 |
| 墨羽碎裂 1 组序列帧（6～8 帧） | 影卒裂开后化成羽毛散掉 | 代替小三角碎片 |
| 腰间寒光 1 张（细长横向光芒） | 咔 | 代替 2 像素白线 |

### 3.4 屏幕级效果（新增，全部是读屏幕纹理的着色器）

| 效果 | 帧 | 说明 |
|---|---|---|
| 暗角 + 轻颗粒 | 静 | 压住四周，视线集中到她身上 |
| 画面沿刀线错开 | 咔的 3 帧 | 上半往右、下半往左，再合上（样片 v5 已验证过好看） |
| 径向速度线（带一点扭曲） | 冲击帧、落的第一下 | 只出现 2～4 帧 |
| 色差（红蓝错开） | 咔那一帧、落的第一下 | 1～2 帧，力度很小 |
| 冲击波扭曲 | 每个影卒裂开时 | 以影卒为中心的一圈小扭曲，3～4 帧 |

### 3.5 落的节奏（解决"不够狠"）

- 四个影卒**从左到右依次**被补刀，间隔 3 帧（样片 v5 已验证）。每一下：斩痕贴图闪 2 帧 → 影卒闪白 → 上半沿刀线滑开 → 化成墨羽碎裂 → 冲击波扭曲 → 伤害数字跳出。
- 每一下配一声斩切（音效已有，按逐个的节奏重新排时间）。
- 最后一个影卒裂开时：镜头猛推一下再回落，颜色从刀线往上下恢复。

## 5. 需要你定的

1. **大招期间要不要统一成高清**（背景模糊加暗角、影卒变剪影），还是保留像素画风？
2. **近景机位要多近**：放大 3 倍时，她大约占屏幕高度的四分之一。
3. **逐个补刀加画面错位**（样片 v5 的做法）是否采用。v4 没有这两样，但你之前说过后面要"帅一点"。
