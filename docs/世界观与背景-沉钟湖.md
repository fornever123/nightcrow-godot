## 1. 世界观：「止钟之夜」

**一句话**：城里的大钟停在零点前一分，天再也没有亮；人们睡去，影子离开了身体。最后一个夜鸦要走到钟楼，把钟重新敲响。

- **暮钟城**：湖边一座哥特古城，全城的时间由大教堂顶上的「暮钟」报时。某一夜钟停在 11:59，黎明不再来——这就是「止钟之夜」。
- **沉钟**：钟停的那一夜湖水上涨，老城的一半沉进湖里，只剩尖塔和钟楼的拱顶露出水面。湖因此叫「沉钟湖」。
- **影**：长夜里，睡着的人的影子脱离身体，披着兜帽四处游荡，想找到新的身体。这就是游戏里的敌人：影卒（普通）、甲影（穿着旧守卫盔甲的影）、影弓、影爆。
  它们怕光，所以城里还亮着的琥珀色灯火就是活人最后的据点。
- **鸦羽修会**：守钟的修会，成员叫「夜鸦」，生来背上有鸦翼。衣服上的白色十字就是修会的纹章（对应主角靴子、袖口上的十字）。
- **主角**：修会最后一个夜鸦。钟停那一夜，她把自己的一半影子封进暮钟，拖住了整座城被长夜吞掉——代价是背上只剩一只翼。
  - **大招「绝影·鸦羽止」就从这里来**：她短暂召回封在钟里的那半影子，影子补出另一只翼；而那半影子带着“停住的钟”的力量，所以画面里时间停止、世界褪成黑白。人设（单翼）、大招（影子补翼）和画面（时停、黑白）都有了解释。
- **关卡里的「月光封印」**：修会留下的结界，靠月光维持。影聚到一定数量会把封印染黑；斩尽这一波，封印解除，路才能继续往前。（玩法不变，只是给现有机制一个说法。）
- **主线方向**：一路向右，就是一路走近那座大教堂。第一关在城外湖岸，大教堂远在湖对岸；以后的关卡越来越近（城墙 → 街巷屋顶 → 钟楼内部的齿轮 → 钟顶）。背景里的地标就是目的地，玩家每一关都看得到自己离它多近。

为什么适合她：鸦（尖塔、钟楼是乌鸦栖息的地方）、十字（修会）、黑白配紫（灰银色的城 + 琥珀灯火，正好衬出她的紫色）、单翼和时停大招（钟和影子）。这一套都是从角色身上已有的东西推出来的，没有另外加设定。

## 2. 第一关背景「沉钟湖 · 渡口」

和上一版（哥特湖岸）相比，改了这几处：

1. **湖里多了一层「沉没的老城」**（新的中景层，视差约 0.25）：湖面远处露出两三座半沉的哥特尖塔、钟楼拱顶，以及一口卡在拱里的旧铜钟，上面停着乌鸦。它们在水里有倒影。这是这一关最有辨识度的轮廓，同时也拉开了远景和近景之间的纵深。
   这些东西只放在湖的远半边（屏幕 y 约 330～450），**角色身后那条湖面（450～580）照旧保持平静**。
2. **对岸地标换成“停住的钟”**：大教堂主塔上有一面巨大的钟盘，指针停在 11:59。钟盘不发光，只被月光照亮边缘；窗户里透出零星暖光。它是整个画面的视觉焦点，取代了大月亮。
3. **月亮更小**，躲在主塔后面，只当光源用。
4. **栈道 = 渡口**：湿木栈道上有系船柱、铁链、铸铁路灯，零件里加一块写着渡口的木牌（不写字，只画形状）和一条拴着的小渡船。
5. **鸦**：沉塔上、系船柱上停着乌鸦剪影；远处偶尔有一小群鸦飞过（程序画）。平时都是黑色剪影，不带紫光，紫色留给主角和大招。
