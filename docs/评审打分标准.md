# 《断晓》评审打分标准

> 2026-11-17 用户定：“要打分吧，最好给自己打分。评审方式要严格全面，画面的话兼顾动效和画面，美术和视角冲击力，真实感。玩法的话也要全面。”
> 所有会话交付前**必须给自己打分**，按本文执行。分数是用来找差距的，不是用来报喜的。

---

## 一、刻度（画面、玩法通用）

分数必须锚定在**点名的参照游戏**上，不能凭感觉给：

| 分 | 含义 |
|---|---|
| 10 | 超过点名参照游戏在这一项上最好的那一刻，能拿出并排证据 |
| 9 | 与参照游戏同级，并排看分不出高下 |
| 8 | Steam 上好评的商业独立游戏水准，挑不出硬伤，但还不到参照级 |
| 7 | 能上架，但平庸，玩家不会记住 |
| 6 | 明显有业余感或拼凑感 |
| 5 | 原型水平，或有一眼可见的硬伤 |
| ≤4 | 坏了 / 缺失 / 拖后腿 |

**严格规则：**

1. **每一项都要有证据**：实机截图或录像时间点。没证据的项不准打分，标"未验"。
2. **8 分以上必须有并排对比图**（实机帧 vs 参照游戏对应帧）。没有并排图，最高只能给 7。
3. **每一项低于 10 分，都要写出扣分点**，至少一条，越具体越好（哪一帧、哪个动作、哪里不对）。
4. **不准只报平均分。** 总评同时写：平均分、**最低分那一项**、和上一版相比每项的升降。最低项低于 7 必须醒目标出。
5. **改前、改后都要打分**，用同一张表，让变化看得见。
6. **素材原图不算数**，只按游戏实机里的效果打分（同屏、运动中、有 HUD）。
7. **校准**：用户的判断永远高于自评。用户否掉或说"没变化 / 不好看 / 不好玩"的东西，如果自评 ≥7，就在本文第四节「校准记录」里记一笔：自评几分、用户原话、差在哪。之后同类项按这次校准往下压。

## 二、画面评审（7 项，动效与静帧并重）

| # | 维度 | 看什么 |
|---|---|---|
| V1 | 静帧美术 | 构图、色彩与光影层次、材质细节、画风统一；截任意一帧能不能当宣传图 |
| V2 | 动效 | 动作帧数与流畅度、预备 → 打击 → 收招的节奏、刀光与特效的动态、镜头运动、转场、UI 动效 |
| V3 | 视觉冲击力 | 打击瞬间（顿帧、闪白、震屏、粒子、色散）、大招演出、奇观场面、剪影是否有力；第一眼会不会"哇" |
| V4 | 真实感 / 可信度 | 角色、刀光、背景是否被**同一套光**照着；重量与惯性、布料与发丝、雨与空气、空间纵深、材质反光是否可信 |
| V5 | 整帧统一 | 角色 + 刀光 + 敌人 + 背景 + 光 + HUD 同屏是否一体，有没有"贴上去"的割裂感 |
| V6 | 世界观表达 | "白光驱逐时间、暗处狂影、5:59"是否一眼可见、在动起来时可见；红线（禁紫、禁白瓷、禁水淹等）零违规 |
| V7 | 战斗可读性 | 激烈战斗中，主角、敌人、攻击预警、伤害是否一眼看清 |

## 三、玩法评审（10 项）

| # | 维度 | 看什么 |
|---|---|---|
| G1 | 操作手感 | 输入响应、取消窗口、输入缓冲、重量感、手柄与键鼠都顺 |
| G2 | 战斗深度 | 招式之间的连携与取舍、风险与回报、技巧上限、有没有"更高级的打法" |
| G3 | 敌人与遭遇 | 敌人种类与组合、AI 是否逼玩家做选择、读招与应对 |
| G4 | 节奏与心流 | 10 分钟曲线：紧张与释放、有没有拖沓或空档 |
| G5 | 肉鸽成长 | 构筑多样性、每次选择是否有意义、每局是否真的不同 |
| G6 | 关卡与路线 | 空间利用、路线选择、探索回报（不加场地机关） |
| G7 | 高潮 / 首领 | 有没有让人记住的高潮时刻（Boss 归零留白期间写"未验"，不跳过） |
| G8 | 反馈与清晰度 | 玩家是否知道发生了什么、为什么死、下一局该怎么改 |
| G9 | 重玩动力 | 打完一局想不想马上再来一局，为什么 |
| G10 | 主题融合 | 玩法本身是否在表达"光与时间"，而不是通用砍杀套了皮 |

## 四、交付时的打分格式

```
评审（改前 → 改后）
画面：V1 6→7 | V2 5→7 | V3 5→6 | V4 4→6 | V5 5→7 | V6 6→6 | V7 7→7
  平均 5.4→6.6｜最低 V4 6（⚠ 低于 7）
  扣分点：V4 刀光没有照亮地面和角色（00:12）；V3 打击只有闪白，没有顿帧……
  并排图：<路径>
玩法：G1 … G10（同上格式）
```

校准记录（用户判断 vs 自评，新的写上面）：

- **2026-11-19 Boss 线 v5 多层绿幕抠图 + 3D 石桥**：自评 `V1 7.0 / V4 7.0 / V5 7.0 / 平均 6.8`，用户：`“这不是还是很差吗”`。复盘差在哪：迷信像素统计指标（`gap=0.15`、`neon_red=0.02%`）而忽视了肉眼观感——① 独立抠出的 `L2_mother_tower` 像一张纸片孤零零浮在泛白灰云壁纸上，左右建筑突然截断没有世界连续性；② 塞在塔后的 3 个圆形黑铁齿轮像 3 张扁平贴纸硬贴上去；③ 底部 3D 石桥（`Deck3D`）仍是明显重复的蓝灰砖块盒子，和上方厚涂 2D 原画画风严重打架；④ 整片上空灰白泛糊、缺乏暗黑史诗明暗聚焦，且截图中开场黑条横幅仍挡在钟心。**校准铁律**：凡是“2D 绿幕抠图卡片 + 重复贴图 3D 砖块盒”硬拼、肉眼存在纸片浮空感或上下画风割裂的，无论像素色温指标多好看，`V1 / V4 / V5` 一律 `≤4` 分，不准再给过 5。

- **2026-11-19 背景 3D 街体原型（RAIN_3D=1）**：自评 `V1 6 / V3 5 / V4 6 / V5 5`，用户：`“你这完全不行”`。复盘差在哪：用户要的是“能走的地方都是 3D、近景按真实距离”，我只加了一块 3D 地板 + 把整张原画当一张卡片往后推——墙还是纸，本质没变；地面是一块重复的小石子贴图，和厚涂原画画风打架，像廉价地毯；2D 雨溅圈浮在地上排成一行；石桩是没受光的薄片；镜头平视，3D 地面只显成一条暗带。数字（下方亮度 0.03→0.10）变好不代表画面变好。另外颠覆档跳过了“先出 2～3 张目标效果图让用户挑”直接开做。**校准铁律**：只给原画加地面、墙仍是一整张卡片的“3D 化”，V1/V3/V4 一律 ≤4；3D 场景里任何一张可平铺贴图在实机里一眼能看出重复的，V1 ≤4；颠覆档没给效果图就动手的交付不算数。

- **2026-11-18 背景立体感 A+B 合并版**：自评 `V1～V7 全 6 / 最低 6`（改前最低 4），用户看完并排：`“这不是差不多吗”“还有这个蓝色滤镜估计也是问题”`。复盘差在哪：只看“有没有 3D 灯影、视差”这些技术项，没量整帧明度和色相——实测 A+B 反而更暗更平（亮度标准差 0.149→0.137，暗部 <0.08 占比 34%→53%），蓝得更重（平均 B/R 1.56→1.88，原画才 1.15）；画面立体感首先来自远近的明度 / 色相分层，技术细节缩到 640 宽并排图里根本看不出。**校准铁律**：背景类改动，缩到半屏并排一眼看不出区别的，V1/V3/V5 一律 ≤4；交付前必须附整帧明度 / 色相量化（均值、标准差、偏蓝占比），比改前更暗更平或更偏单色的不准给过 5。

- **2026-11-18 角色动作补齐首轮交付**：首轮自评 `V2=7.0 / 平均 7.0`，用户一眼指出 `“这个普攻都没对齐啊”`。复盘差在哪：只抽看了单张静帧而未拉逐帧红绿十字准星带核验序列连续性，漏掉了 `attack_2_settle` 漏乘原显示宽高比导致悬空 `-66px` + 横偏 `-65px`、`attack_1` 部分帧靴底入地 `+13px` 以及 `V6` 收招尾段推镜蹿高 `+16px`。**校准铁律**：凡涉及序列帧实装，未过「逐帧脚底绿线 + 脊柱红线十字准星带」与实机慢放逐帧核验前，`V2 / V4` 严禁给过 `5` 分；存在单帧脚底悬空/入地 `>3px` 或脊柱跳变 `>6px` 一律按硬伤压至 `≤5` 分。
