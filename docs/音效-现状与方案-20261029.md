# 音效线 · 现状与方案（2026-10-29）

本轮只盘点、出方案，**没有改任何代码和音频文件**，也没有下载新素材。用户 10-29 的新要求：

- 来源以 **Kenney（CC0）** 为主；特别重要的、或者免费素材不够好的，用 **ElevenLabs** 生成。
- 先搜一批候选，**做成试听页给用户听**，用户审核后再接进游戏。

第 6 节是待批准的下载清单，第 8 节是分批建议。

## 2. 缺口

### 2.1 四类敌人的预警（最关键）

规划第 3 节：抽 10 次受击，至少 8 次玩家能指出是谁打的；预警要有独立的声音，不能只靠视觉。现在的问题：

| 问题 | 影响 |
|---|---|
| 近战、弓手、投弹者**共用同一个起手声**，只有甲影换成 heavy | 只听声音分不出是谁要打 |
| 所有声音**没有左右声像** | 屏幕外的敌人起手，玩家不知道在哪一边 |
| 弓手“瞄准锁定”（出手前 8 帧瞄准线变粗）**没有声音** | 最该躲/弹的那一刻只有视觉 |
| 投弹者扔出、炸弹落地 / 引信**都没有声音**，扔弹用的还是挥刀声 | 炸弹几乎是“无声杀” |
| 起手声走 `SFX_Motion`（−4dB），和脚步、挥空同一档 | 混战里会被盖住 |

起手时长（`shade.gd` 的 spec）：近战 16 帧（0.27s）、甲影 26 帧（0.43s）、弓手 24 帧（0.40s，最后 8 帧锁定）、投弹者 28 帧（0.47s）。预警声的“峰”要落在出手前，不能比起手更长。

建议每类敌人一个**招牌声**（听一次就能对上号）：

| 敌人 | 起手预警（windup 开始） | 第二段 | 出手 |
|---|---|---|---|
| 近战影 | 短促的刀出鞘“嚓”（高频、干） | — | 轻刀风 |
| 甲影 | 低沉的铠甲铿锵 + 拖地重刀刮擦（低频、长） | 霸体白光时一声闷响 | 重刀风 + 低频 |
| 弓手 | 弓弦拉紧的吱嘎（渐强） | **锁定瞬间一声“叮”或弦绷紧** | 放箭“嗖” + 箭矢飞行 |
| 投弹者 | 引信点燃的嘶嘶声（持续到扔出） | — | 抛掷“呼” + 炸弹落地后的短引信 |

| 类别 | 现状 | 缺什么 / 哪里不对 |
|---|---|---|
| 玩家受击 / 死亡 | 有 | 用户反馈现有音效整体不够好，受击和命中要一起重选；死亡只有倒地声 |

## 3. 混音结构

### 3.1 总线

```
Master（硬限幅 −1dB）
├─ Music        BGM。压缩器侧链跟随 SFX，战斗重音时自动让 3–4dB
├─ Ambience     雨、河、远处。侧链跟随 SFX，让 2dB
├─ SFX          设置菜单里的“音效”
│   ├─ SFX_Impact   命中 / 弹刀 / 撞墙 / 大招（保留现有名字，大招线不用改）
│   ├─ SFX_Motion   挥刀 / 脚步 / 跳跃（−4dB，保留）
│   └─ SFX_Warning  新增：敌人预警。不被侧链压低，优先级最高
└─ UI           菜单与提示音，独立音量（现有 SFX_UI 改送到这里）
```

- 用 `default_bus_layout.tres` 固定下来（新文件，不碰其他线的文件）；`_ensure_buses()` 保留为缺总线时的兜底。
- 现有三条 `SFX_*` 总线名不变，只是把它们的输出从 Master 改到 SFX。`ult_fx.gd` 走 `SFX_Impact`，所以**大招声音自动受“音效”音量控制，不用改大招线的文件**。
- 设置菜单接口（给 UI 线用）：新建 `scripts/presentation/audio_mix.gd`（自动加载）提供 `set_volume(bus, 0..1)`、`get_volume(bus)`，内部 `AudioServer.set_bus_volume_db(linear_to_db(v))`，保存到 `user://settings.cfg`。UI 线只需要调这两个函数，不需要知道总线细节。
- `battle.json` 的 `masterVolume / musicVolume / sfxVolume` 改成各总线的**默认值**；`audio.volume` 不再乘到每个声音上，避免和总线音量重复。

### 3.2 同屏多敌人时的发声控制

现有的“同事件 3 个、同帧 2 次、连续压低”保留，另加：

| 规则 | 做法 |
|---|---|
| 预警数量上限 | `SFX_Warning` 同时最多 3 个；超了按“离玩家最近 + 最先出手”保留，其余掐掉 |
| 同类合并 | 同一类敌人 3 帧内同时起手只放一声，音量 +2dB 代替叠加 |
| 左右声像 | 敌人相关的声音改用 `AudioStreamPlayer2D`（跟镜头听），屏幕外的预警额外做轻微的左右偏置和高频衰减，让玩家听出方向 |
| 距离衰减 | 屏幕内基本不衰减，屏幕外 1 屏距离内衰减到 −6dB，再远不放 |
| 让路 | 预警响时 `SFX_Motion` 临时 −3dB（Godot 压缩器的 `sidechain` 直接做） |
| 总数 | 全局 `max_voices` 从 12 提到 20，按总线分配：Impact 8、Motion 6、Warning 3、UI 3 |

### 4.3 ElevenLabs

只用在第 2.1 节的敌人预警，以及试听后 Kenney / OGA 都不满意的那几项。生成前需要用户决定两件事：

1. **套餐**：付费版生成的可以直接进正式包；免费版要署名，而且商用许可有疑问，建议只用来试听、定方向。
2. **怎么生成**：
   - 用户在 ElevenLabs 网页上用我写的提示词生成，下载后把文件放进指定目录；或者
   - 用户在系统环境变量里设好 `ELEVENLABS_API_KEY`，我用脚本调接口批量生成。**我不会在任何地方输入或保存密钥。**

### 4.4 雨夜河岸街环境声的接入

不改背景线的文件。新建独立的 `scripts/presentation/ambience_layer.gd`（`Node`），由场景入口挂上：

- 雨：全屏常驻循环，走 `Ambience`；
- 河：一个 `AudioStreamPlayer2D` 放在河面位置，镜头靠近河时变大；
- 远处：低音量循环 + 每 20–40 秒随机一次钟声 / 远雷。

需要背景线提供的接口（**只是需要，本轮不改**）：`rain_street.gd` 在 `_ready()` 里 `add_child(AmbienceLayer.new())`，并告诉它河面的 x 范围和 y；河面位置也可以从 `rain_street_layout.json` 读（只读）。这一行需要背景线或用户同意后由背景线加。

## 5. 试听流程

1. 用户批准第 6 节的下载后，下到**仓库外的新目录** `E:/00game/work/nightcrow-音效试听-20261029/downloads/<包名>/`，每个包单独一个子目录，原文件不动。
2. 按游戏事件挑候选，切好、统一响度后另存到 `processed/`（原始文件不覆盖）。
3. 做一个本地试听页 `index.html`：每个事件一行，**左边是游戏现在的声音**，右边是 3–6 个候选；预警类附带“按游戏时序连放”（起手 → 锁定 → 出手 → 命中），可以对比四类敌人能不能分辨。每个候选旁边写来源和授权。
4. 用户在页面上选，我再接进游戏，接入的文件放进 `assets/audio/` 下的新目录，`LICENSE.txt` / `README.md` 逐条登记，署名汇总进新的 `assets/audio/CREDITS.md`。

## 7. 和其他线的接口
