## 3. 版本历史与结论

| 版本 | 要点 | 结果 |
|---|---|---|
| v2–v3 | 平灰色块 → 明暗草图，每栋楼的窗型不同 | 结构偏差缩小到约 10 像素，但楼的构造不真实 |
| v4–v5 | 统一成维多利亚哥特复兴；修正方楼配圆锥顶、山墙、烟囱、门；改成真正的尖拱 | 用户指出窗"位置不对、太密" |
| v6 | 仓库街 | **否决** |
| v7 | 回到住宅街，门窗按竖向轴线排（上下对齐、左右对称、越往上越矮） | 成图评分约 6.5 / 5 |
| v8 | 月亮压暗、朱红偏橘、只留 3 扇暖窗、厚石阳台和亮边、路灯两倍人高、花岗岩护墙、石像鬼 | 成图评分：我 7.5，新子智能体 5.5 |
| **v9（当前，已发给用户，等出图）** | 见下 | — |

v8 评审共识，也就是 v9 要解决的：
- 画法：满墙砖纹、细节平均，是 AI 味的主要来源。
- 楼层高度改不了，导致"玩具屋"感，所以改从造型上拉竖向。
- 光没有方向，街面最暗，黑衣角色会消失。
- 钟楼一层被整片染红；暖灯太多。
- 路灯和系船环等距复制。

v9 的改动（用户采纳了"每栋楼一个身份"和"阳台按楼错开高度"）：
- 四栋楼：
  - 河岸货栈：吊货梁、装卸门列、细铸铁廊，二层 310。
  - 行会会馆：最华丽的一栋，实心石矮墙阳台，第二只石像鬼，二层 285。
  - 商住楼：招牌带、两扇大橱窗、铸铁花栏，二层 305。
  - 小酒馆：凸窗、弓形窗、壁挂灯、只有石檐。
- 竖向壁柱线；屋顶更陡。
- 街面后墙底部加一条冷蓝湿反光带，给黑衣角色衬底。
- 钟面做成中心亮、边缘暗；其他暖光改成低饱和的暖黄。
- 中景屋顶层；云缝里的月光。
- 系船环只留 1 个；杂物只集中在巷口。
- 提示词第一条就是"平涂大色块、不画砖纹、三到四个明暗大块"。

用户没有采纳的建议：远景改成密集尖塔（和"不要尖塔森林"冲突）。

## 4. 改布局时的校验（每次都要跑）

- 顶头：两块平台上下重叠，而且高度差小于 188（角色 168 加余量），就算不合格。
- 能上去：每块平台下方 300 以内要有能起跳的面，水平距离不超过 380；或者同层 ±60 以内、水平距离不超过 450 的地方有另一块平台。
- 代码：`tools/art/build_rain_street_v9_layout_check.py` 结尾那段（注意它会重写 v9 草图脚本和布局，只抄校验部分）。
- 最难的一跳（高差 300）实测还有约 56 的余量。
