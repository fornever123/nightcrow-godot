## 4. 改布局时的校验（每次都要跑）

- 顶头：两块平台上下重叠且高度差 < 188 → 不合格。
- 能上去：每块平台下方 300 以内要有能起跳的面、水平距离 ≤ 380；或同高 ±60 以内、水平距离 ≤ 450 有另一块平台。
- 竞技场右边界 x = 2400。
- 校验代码（三段都跑）：

```python
import json
L = json.load(open('assets/data/rain_street_layout.json', encoding='utf-8'))
for si, sec in enumerate(L['sections']):
    surf = [(a, b, y) for a, b, y, _ in sec['platforms']] + [(a, b, y) for a, b, y, _ in sec['blocks']]
    bad = [(A, B) for A in surf for B in surf if A is not B and A[1] > B[0] and A[0] < B[1] and 0 < B[2] - A[2] < 188]
    unreach = [(a, b, y) for a, b, y, k in sec['platforms'] if not any(
        (B[2] > y and B[2] - y <= 300 and max(0, max(a, B[0]) - min(b, B[1])) <= 380) or
        (abs(B[2] - y) <= 60 and (B[0], B[1], B[2]) != (a, b, y) and max(0, max(a, B[0]) - min(b, B[1])) <= 450)
        for B in surf + [(-1e9, 1e9, 580)])]
    print(si, 'headroom:', bad or 'ok', ' reach:', unreach or 'ok')
```
- 然后 headless 加载一次。

## 5. 经验（踩过的坑）

- **局部修图比重新出图可靠**：要改成图，就把成图当唯一底图、只列要改的几处、点名要保留的小物件（v9.2 成功）。让 GPT “只改画法”等于整张重画（v9.1 失败）。
- **分层**：每层只附标杆图一张、各开新对话。近景出纯绿底时，**贴着立面的阳台栏杆后面是墙，不能填绿**，只有真能看穿到天空的地方才填（第一次 GPT 把阳台全打成洞）。
- **绿幕抠图**要按“局部背景绿”估计透明度和还原颜色，否则暗绿边会变紫、雨水高光会变青边。细铁件按“比局部背景暗”从标杆补回。
- GPT 爱擅自改颜色（烟囱帽变陶红）、往门洞里画尖塔天际线、加圆窗和常春藤——每次成图都要和标杆做差分检查。
- 成图结构偏差通常整体平移即可（v9 系列只差 1–2 像素），不要逐块改碰撞。
- 草图的毛病会被 GPT 原样画出来：右半边第一版就是草图把楼画成两栋一样宽矮的盒子。明暗要和左半边同档（拿标杆量街面带和楼体带的平均亮度对比）。
