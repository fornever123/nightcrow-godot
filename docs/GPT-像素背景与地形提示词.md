# GPT 像素背景 + 地形 提示词（第四轮，等用户出图）

> 用途：把「月下堤岸」背景和地形重画成真正的像素画（3 倍像素点 = 每个美术像素在屏幕上 3×3）。
> 规则：用户 2026-10-19：“以后你觉得需要 gpt 生图的，都给我生图，而不是自己制作粗糙的素材。希望你能够制作精细的素材再自己制作。”
> 参考图（仓库里）：`docs/视觉设计/ref/moon-embankment/` 下的 `orig-far.png`（远景原画）、`orig-mid.png`（中景）、`orig-near.png`（近景）、`game-now.png`（第三轮游戏截图，亭子段）。

## 怎么用

1. 最好在**同一个 GPT 对话**里按顺序出。
2. 先出 **第 0 张**（画风样张），发给我确认画风。
3. 确认后，再出 1–11，每张都**上传第 0 张**当画风参考。
4. 尺寸、数量不准没关系，我会调整。出好直接发回来；抠洋红底、对齐像素格、做无缝、接进游戏都由我来做。
5. 某张不满意可以让 GPT 重出，或者发给我看要不要重出。
