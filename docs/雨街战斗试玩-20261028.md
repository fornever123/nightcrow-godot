### 6. 问题清单

**§3.4 里没验证的项**
1. 真人通关时长：没有真人数据。机器人打完一轮 5.4～6 分钟（含 4～5 次死亡重来），和 5 分钟目标接近；但 7 局里 3 局卡在廊桥段打不完（见 §5）。
2. 难度：机器人的近战受击里甲影占 40%～60%，死亡也集中在有甲影的第二、三处。甲影伤害 15、打不浮空、只能站着磨 220 血，难度主要来自它 + 堆数量，不是来自读招。
3. 手柄：**完全不支持**。`player_factory.register_input()` 会把每个动作的输入先清空、只绑键盘；暂停菜单认手柄，游戏本身不认。
4. 性能：1080p 128 fps，没问题（只测了这台机器）。
5. 高处弓手驻守不射：**代码里确认会发生**。影弓优先刷在最高的出生点（钟楼屋顶 −260、河岸屋顶 −260），而它只在高差 < 300 时才开弓，瞄准又限 ±26°；玩家在街面（580）时它既不射也不下来（只有玩家水平距离 < 344 才往下追）。结果就是“一只看不见的弓手站在屋顶，波次结束不了”，玩家只能自己找上去。

**我看到的手感和敌人问题**
6. 敌人没有个性：四类共用一套“走近 → 前摇 → 一刀 → 后摇”，近战两类只差数值；每类只有一种攻击，没有连招、没有不同节奏、没有需要不同应对的招。
7. 防守靠掷骰子：玩家一出招，影卒 20% / 甲影 35% 概率瞬间举刀挡、影卒 15% / 影弓 40% 瞬间翻滚（带无敌）。玩家事先看不出来，体感是“随机被挡、随机打空”，越连越憋。
8. 失衡系统关掉后，“弹刀 → 破防 → 挑飞”这条最爽的链断了：弹刀只换来 34～40 帧硬直；甲影整场只能站着磨 220 血。
9. 读招太快太同质：影卒 0.3 秒出伤，三种提示颜色都是橙色；屏幕外的敌人照样出刀 / 放箭，屏外箭头只指位置不预警；炸弹飞行时不标落点。
10. 看不清敌人：实机里影卒是深蓝黑剪影，压在深蓝的雨夜背景上，主要靠黄眼睛和头顶小血条认；三只挤在一起时主角也被吞掉（见录像 33～46 秒）。外观以后换“晨使”，但现在的轮廓光 / 描边强度也影响读招。
11. 蓄力斩太拖：212 帧里有 139 帧后摇，只能跳取消，放一次等于 2 秒站桩。
12. 死亡千篇一律：四类都是同一套飞出去 + 淡出；没有“最后一刀”的定格和分量（只有每波最后一只有 0.45 秒慢动作）。
13. 底部常驻两行操作说明 + 屏幕中间的教学提示，在战斗里很挤（UI 线的事，转告）。
14. 站着不动挨打时日志里出现过 `Invalid polygon data, triangulation failed`（没定位，可能是敌人或特效画多边形）。

### 7. 改进方案（按收益排序）

只谈行为和手感；外观等“晨使”替换。凡是需要新动作帧的地方都标出来，那部分要用户出素材。

| # | 做什么 | 收益 | 成本 | 要新素材吗 |
|---|---|---|---|---|
| 1 | **修卡关的高处弓手 / 跨层待命 + 屏外预警**：弓手只刷在能射到街面的高度（≤ 一层楼）；玩家在别的层超过 3 秒，弓手换位（跳下 / 走到楼边）或改放抛射箭；近战敌人上不去时绕路找楼梯 / 平台，或干脆退到玩家下方等着、给玩家一个“下来打”的提示；先真人走一遍廊桥段 x≈11985 看主角会不会卡；屏外敌人进入前摇时，屏幕边的箭头变成闪烁的预警；炸弹飞行中就在地上标落点 | 消掉流程最大的坑；读招从“看到了才知道”变成“提前知道” | 小 | 不要 |
