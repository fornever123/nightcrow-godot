# 月下堤岸 · 试玩版 —— 怎么玩

## 先拿到更新
- 双击仓库根目录的 **下载GitHub更新.bat**（英文入口 PULL_GITHUB.bat 作用相同），看到 **GitHub download complete.** 就是拉好了。
- 如果提示 *Update stopped*：说明这台电脑上有还没上传、又和 GitHub 冲突的修改，本机文件不会被覆盖，让 AI 帮忙合并即可。
- 第一次打开时 Godot 会花几十秒导入新素材，属于正常现象。

## 启动
- 双击仓库根目录的 **OPEN_GAME.bat**：直接进入试玩关卡（月下堤岸夜景）。
- **OPEN_MODIFIER.bat**（编辑器预览）打开的是原来的木桩训练场。
- 游戏里按 **F3** 在试玩关卡和训练场之间切换。

## 操作
| 键 | 作用 |
|---|---|
| A / D | 移动（会播放转身动画） |
| W / 空格 | 跳，空中可再跳一次 |
| J | 地面三连斩；按住 J 蓄力再松开 |
| W + J | 挑飞（把敌人打上天） |
| 空中 J | 空中连斩（把敌人托在空中） |
| 空中 S + J | 下砸终结（往下砸，落地冲击波掀起周围敌人） |
| 空中按住前方 + J | 横扫终结（把敌人横着打飞，撞墙或撞到别的敌人） |
| L | 弹刀（敌人刀尖亮起白色星光时按）；按住 L = 格挡 |
| K | 远射 |
| Shift + J | 冲刺斩 |
| H / R / F1 | 隐藏说明 / 从头开始 / 显示判定框 |

## 第二轮更新（手感 / 音效 / 画面）
- **更快**：跑速提高到原来的约 1.8 倍，起步和急停都很利落；跳得更快、落得更快。
- **小跳**：轻点跳键是小跳，按住是满跳。
- **落地分轻重**：普通落地马上能动；从高处落下或下砸落地会顿一下（这时可以直接跳或出招）。
- **出招更快**：每一刀的前摇和收招都提速了。
- **取消后摇**：出招后摇里随时可以按 **L** 弹刀、**Shift + J** 冲刺斩；收招后段按方向键可以直接走开。
- **音效全换**：每一刀有自己的刀风，命中分轻 / 重 / 终结三档，另有脚步、起跳、二段跳、轻/重落地、弹刀、格挡、眩晕、挑飞、下砸、撞墙、连锁，以及敌人蓄力和出手的声音（出手前能听见，方便弹刀）。
- **画面**：夜景拆成多层，远的走得慢、近的走得快；角色缩小后边缘更干净、不发糊。
- 跑步动作暂未处理（等新的跑步序列帧）；有几张原图质量太差、代码修不了，清单和 GPT 出图提示词在 `docs/GPT-重画清单.md`。

## 核心玩法：眩晕连段
1. **打满失衡**：连续砍敌人，头顶的失衡条会涨满（弹刀成功涨得特别多）。
2. **眩晕**：失衡满了，敌人原地发晕（头顶转星），这时挨打更痛。
3. **挑飞**：W + J 把发晕的敌人打上天（发晕时飞得更高）。
4. **浮空连段**：跳起来空中连按 J，把敌人一直托在空中（越连托得越低）。
5. **方向终结**：S + J 往下砸，或按住前方 + J 横着打飞。
6. **撞墙 / 连锁**：横飞的敌人撞到墙伤害翻倍，撞到别的敌人会把它也撞飞，可以一串。

右上角的评价（D → C → B → A → S）主要看这条主线：眩晕、挑飞、下砸、撞墙、连锁、弹刀给大分，一直重复同一招普通攻击几乎不加分；挨打会掉分。

## 关卡
- 一路往右走，会遇到三处“月光封印”，进去后把影子全清掉才能继续走。
  1. 影卒（小兵）两波
  2. 甲影（大块头）带两只影卒 —— 甲影出刀时身上闪橙光，打不断，先弹刀或躲开
  3. 影潮：影卒和甲影混在一起，打到一半还有增援
- 每清一波回一些血；倒下后从这一波重来。
- 三处都打完会出本轮结算（用时、最高连击、各种连段次数、评价），之后自动开始下一轮，敌人会更耐打，场景无缝循环。

## 已知小问题
- 挑飞时的刀光是原序列帧里的灰白笔触，不会被灯笼染成暖色。
- 结算面板出现时会短暂挡住角色。
