# 绝影特效重做 · 第二版

用户认为第一版区别太小，已同意重新设计斩击形状、运动与爆发节奏。保留冷峻基调、立绘和现有战斗时间轴。第一版微调不作为本次验收目标。

1. 在`ult_slash_shape.gd`新增椭圆空间刀弧：独立的横纵半径、倾斜、扫角和首尾进度；尖头、厚刃、细尾形成明显弯月轮廓。先扩展几何回归测试并观察缺失能力失败。
2. `ult_fx.gd`三刀使用横向、反向、斜向三个大弧面，附黑色负形、白色切刃和淡灰外沿；挥出后沿弧长退尾，三刀余痕交错。切入结束时增加收拢的双弧蓄势，终结前短暂压缩。
3. `fx_ult_split.gdshader`终结改为大幅张开的尖端空间裂口，白紫边缘、内部幽暗；与全屏白刃爆发形成“开裂→定格→合拢”，不再只是细横线。所有参数继续读取原ult_frame，停顿期间不乱动。
4. 不更改玩家/敌人机制、伤害、命中帧、相机缩放、立绘素材或声音。原版及第一版都保留，不调用生图。
5. 截取真实OpenGL关键帧并录制完整演出；与原版同步对照，检查三刀造型是否在正常速度下有明显差别。跑几何专项与大招既有回归，记录实际结果；美术好看与否由用户看动态判断，不用测试数量代替视觉评价。
