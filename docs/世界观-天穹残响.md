# 《天穹残响》世界观

> 2026-10-27：按用户要求删掉了背景美术、区域地图和角色部分，只留剧情设定。

---

# 一、世界名称与核心概念

## 世界名称

**天穹残响**

“天穹”代表旧文明留下的巨大天空体系。

“残响”代表灾难之后仍然留存在现实中的异常状态。

---

# 二、旧文明——天穹王国

数百年前，整个文明曾经达到极高程度。

他们并不是现代意义上的科技文明，而是一种：

**古代幻想文明 + 巨型工程 + 神秘能量体系。**

他们建造了一个几乎横跨整个王国天空的超级结构：

# 穹环

穹环是一座巨大到难以理解的环形构造。

它横跨天空。

从不同地区抬头，都可能看到天空中巨大的弧形结构。

王国最繁荣的城市、天空庭院、铁路、浮空平台以及大量大型工程，都依赖穹环运行。

人们曾经认为：

穹环的主要作用是：

- 维持浮空城市
- 稳定天气
- 调整重力
- 维持运输网络
- 控制大型古代机械
- 保护王都

实际上，这些只是穹环的表层用途。

---

# 三、真正的秘密

这个世界本身其实并不稳定。

在没有穹环的时代：

- 水可能向上流动
- 重力方向会变化
- 物体可能失去坠落规律
- 时间可能留下残影
- 植物可能矿化
- 岩石可能悬浮
- 空间可能出现重复和错位
- 某些生命可能发生异常演化

古代文明建立穹环的真正目的，是：

# 强行把世界固定在一种“稳定状态”。

后来的人们已经忘记这一点。

他们误以为：

> 世界原本就是稳定的。

实际上：

> 所谓“正常世界”，才是穹环人为维持出来的结果。

这是整个世界观最重要的底层真相。

---

# 四、坠冠日

大约两三百年前，穹环发生了历史上最大规模的失谐。

具体原因在游戏前期并不公开。

当天：

- 穹环断裂
- 王都结构崩塌
- 大量天空建筑失去稳定
- 运输网络停止
- 部分地区的现实规律开始恢复原始状态

因为巨大的穹环像王国天空上的王冠，而王都也在那一天开始坠落，因此后世将这一天称作：

# 坠冠日

坠冠日并没有把世界彻底毁灭。

真正发生的是：

穹环失去了对世界的全面控制。

于是各地开始重新出现原本被压制的异常现象。

---

# 五、残响

灾变之后出现的所有异常现象，统称：

# 残响

残响不是“魔法污染”。

也不是普通的能量泄漏。

它更接近：

> 世界重新露出了它本来的样子。

不同地区的残响表现完全不同。

但必须遵守一个原则：

**异常必须与当地环境、历史和灾难瞬间有关，而不是简单划分成火、水、冰、雷属性。**

---

# 九、回潮

穹环虽然损坏，但并没有彻底死亡。

它会周期性尝试重新建立同步。

这一现象称：

# 回潮

发生回潮时，各地残响会短暂增强。

可能发生：

- 水流短暂倒转
- 漂浮建筑移动
- 古代灯光重新亮起
- 停止的巨大机械重新转动
- 玉化树木变得更加透明
- 天空中的环体出现青绿色发光纹路
- 隐藏道路短暂出现
- 某些遗迹打开
- 空间发生短暂重叠

回潮同时是：

- 世界观现象
- 地图变化机制
- 隐藏区域机制
- Boss 战阶段机制
- 特殊天气
- 视觉奇观

但不要滥用。

每次出现都应该有明显意义。

---

# 十四、最终主题

整个游戏最深层的问题不是：

> 如何恢复世界？

而是：

# 到底应该让世界恢复“正常”吗？

如果完全修复穹环：

- 世界重新稳定
- 人类社会更加安全
- 残响逐渐消失

但是：

过去几百年形成的全新生态，也可能随之消失。

包括：

- 玉化森林
- 特殊生命
- 悬空生态
- 水镜奇境
- 已经适应残响的人类聚落

如果彻底放弃穹环：

世界仍然自由、美丽、不可思议。

但异常可能越来越严重。

文明未来存在巨大危险。

最终主题：

> **恢复过去，还是接受已经改变的世界？**

---

# 二十九、一句话世界观

> 在数百年前的“坠冠日”中，维持世界稳定的巨大穹环断裂，现实重新显露出原本异常的规则。城市被冻结在坠落的瞬间，森林逐渐晶化，水流与重力开始失常，而人类也在这些美丽的遗迹之上重新建立了生活。
