用户原话（11-17）：“你看看有什么动作和特效可以优化，增加的，是现在没有的，是更能够增加角色动作流畅度的。我感觉现在主角动作非常不流畅，不够真实，不够高品质，需要增加更多动作，还有需要增加打击感。你研究以画质，角色动作为主的横版游戏，告诉我缺失什么，我应该怎么用ai生成视频补充”

- 移动类：`idle` 69、`run` 22（含 6 帧起跑）、`turn_left_right` 7 / `turn_right_left` 5、`jump` 9、`fall` 8（循环）、`land` 8。

- 其他：`draw` 50 / `sheathe` 39（待机 4 秒自动收刀）、`death` 124、蓄力 `charge_hold` / `charge_slash`。
- 特效：`impact_fx.gd` 里程序画的一整套（命中、弹刀、破防、撞墙、砸地、挑飞、击杀、跳 / 落地 / 冲刺扬尘、脚步、残影、命中定格、白闪），顿帧、震屏、挤压都有。11-14 用户评价程序特效“质感不行”，AI 手绘特效只做了第一刀样板（V4 / V5），没进游戏。

## 2. 为什么看着不流畅、不真实（按影响排序）

1. **主角挨打没有动作。** `player.gd` 有 `LAUNCHED`（被打飞）和 `DOWN`（倒地）两个状态，但 `character_view.gd` 没给它们配动画——被打飞时放的是跳 / 下落，倒地时放待机。挨打这一下最影响“真实”和打击感。
2. **动作之间是硬切。** 不接下一刀时，第一、二刀从出刀姿势下一帧直接变待机（11-07 方案还没做）；跑步松手直接变待机（没有急停）；站着转身没有动作（转向只在跑动中有）；落地只有一种。
3. **有几处是“定格图”。** `guard_hold` 只有 1 帧，架刀时人完全不动；`fall` 8 帧循环，下落久了像卡住。
4. **帧率和来源不统一。** 跑 30 fps、转向 18、跳 26.5、落地 17、下落 22、攻击 24；攻击是 R3 新画风，移动类还是旧源，同一个人前后两套画质。
5. **K 远程没有自己的动作。** `ranged_1` 借用第一刀动画、不同步播放。

## 3. 对照：画面和动作出名的横版动作游戏都多了什么

（按公开资料和实际游玩的通行做法归纳，不是逐帧实测。）

| 游戏 | 值得学的地方 | 我们缺的对应项 |
|---|---|---|
| 《空洞骑士》 | 出刀快、收得也快；主角挨打时整屏定格 + 黑白冲击 + 弹开，非常清楚“我被打了” | 主角受击动作 + 受击定格画面 |
| 《死亡细胞》 | 3D 做动作再转 2D，所以每个状态之间都有过渡：急停、落地翻滚、转身、攀边；出招有明显预备帧和拖影帧 | 急停、轻 / 重落地、站立转身、收招 |
| 《神之亵渎》 | 高帧数手绘像素，攻击后有完整的收势；弹反后有专门的反击动作；受击、倒地、起身齐全 | 收招、倒地 / 起身、弹反后反击 |
| 《九日》 | 只狼式弹反：每次弹开都有专门的弹刀姿势和火花，架势被破有踉跄动作 | 架刀呼吸（`guard_hold` 1 帧）、架势被破的踉跄 |
| 《胧村正》《龙之皇冠》（香草社） | 高分辨率手绘，大量中间帧，刀光巨大且和身体动作同一笔画出来；命中时人物有夸张的挤压拉伸 | 刀光已在 R3 补上；移动类画质要追上攻击类 |
| 《奥日》《失落的王冠》 | 动作之间全部有过渡、几乎没有硬切；跳跃分起跳、上升、顶点、下落、落地多段 | 跳跃拆段（起跳蹲、顶点翻身）、下落循环加长 |

共同规律：**每两个常见状态之间都有一小段过渡（2–8 帧）**；**挨打、倒地、起身一定有**；**命中那一帧会停住，并且是一张专门画的“最用力”的帧**；**同一个角色所有动作同一画质、同一帧率**。

## 5. 打击感还能加什么（动作线能出素材，接进游戏归战斗线 / 光线线）

1. **主角受击定格**：挨打那一下放受击第 1 帧（最痛的姿势）+ 短暂停顿 + 画面压暗，像《空洞骑士》那样一眼看出“被打了”。需要上面的受击动作。
2. **攻击“最用力的一帧”**：每刀选一帧当命中帧，顿帧时停在这一帧（现在顿帧停在碰巧那一帧）。只要在剪辑里标一个 `impactFrame`。
3. **命中 / 弹刀 / 落地扬尘改 AI 手绘序列**：用户 11-14 已否定程序特效质感。用 Codex 在暗底上画 6–8 格序列（命中火花、弹刀闪、落地尘、急停尘、起跳尘），替换 `impact_fx.gd` 里对应的程序画法。颜色守红线：**紫色只给朔的刀光**，火花用冷白银。
4. **收招也是打击感的一部分**：出刀后有收势，下一刀起手才有“蓄力再出”的节奏感。

## 6. 怎么用 AI 视频补（三条路线，按动作选）

### 路线 A：参考视频 → MiniMax-H3 动作迁移 → Codex 黄框重画（复杂全身动作首选）
适合：受击、被打飞、跳跃、翻滚、远程、踉跄。
1. 从 `E:/夸克/603-604` 挑参考片（原片只读）；**已有 H3 母带的直接用母带**（小受击、大受击、完整跳跃、远程、双向翻滚、蹬墙自旋斩都有）。
2. 没有母带的，用 `动作参考成片/H3_前4秒修正版_v6/` 的 `Ref2VA` 工作流：角色三视图 + 参考视频迁移。**只用一采，不要 2× 二采放大**（`v4-visual-issues.md` 实测二采更糊）；提示词锁死“笔直实体长剑”、清掉参考片的 UI 杂点。
3. 抽帧（保持原节奏，不补中间帧）→ 挑出要的帧 → 用 `codex_redraw_layout.py` 排黄框网格 → Codex 一次画出高清人物（+ 需要的刀光）→ `codex_redraw_map.py` 还原 → 写进 `battle.json`。

### 路线 B：Seedance 2.0 Fast 首尾帧（两端固定的过渡动作首选）
适合：收招、急停、起身、架刀呼吸循环。
- 首帧 = 上一个动作的末帧，尾帧 = 下一个动作的首帧（循环就首尾同一张），纯色底。两头和游戏里的帧天然对得上，这是它最大的好处。
- 11-02 跑步试验踩过的坑：模型一让手臂摆就会把剑甩平、一让人跑就会腾空。提示词要写死“剑始终垂在体侧 / 剑尖朝下”“双脚始终踩地”，并写完整时间线（几秒做什么）。
- 4 秒一条、720p，单条约 24 积分（11-02 价格）；只截需要的那一段，再走 Codex 黄框重画统一画质。

### 路线 C：Codex 直接画关键帧（极短过渡）
适合：站立转身（4–6 帧）、轻落地、起跳蹲。太短的动作用视频反而浪费，Codex 一张图画 4–8 格，首尾两格用现有帧当锚。

### 不用视频做的
特效（火花、尘、闪光）：视频模型会把特效画糊、画成发光雾，**用 Codex 画序列格**更清楚。

### 通用规则
- 每次生成前先给方案和完整提示词，等用户批准（`E:/00game/CLAUDE.md`）。
- 帧率统一到 24 fps；只改帧率不改跑速（`characters[0].speed` 归战斗线）。
- 新动作接进游戏要改 `character_view.gd` 的选动画逻辑（受击、倒地、收招、急停、站立转身），这部分和战斗线一起做；`player.gd` 状态已经有，不需要改玩法。
- 以后 4 名角色（朔 / 萤 / 薇 / 曜）都要整套动作，这条产线（母带 → Codex 黄框 → 还原工具）要做成可复用的模板。
