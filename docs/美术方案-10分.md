## 2. 现在的问题（第四轮截图，自评 3.5 / 10）
1. **千层饼**：天空/雪山/城堡/桥/海/步道/海全是水平条带，没有前后遮挡和斜线，纵深靠“摞”。
2. **背景比战斗区抢眼**：银河、大月亮、闪光海面最亮最细；战斗的步道只是一条细线；深色影卒站在深蓝海面前几乎看不见。
3. **三种画法打架**：GPT 绘画再像素化的背景 + 代码画的像素地形 + 平滑的动漫角色。
4. **主题混搭**：哥特城堡 + 中式亭子 + 红灯笼。
5. **高饱和蓝铺满全屏**（违反我们自己“背景不要高饱和蓝紫”的规则），没有冷暖对比结构。
6. **光不落地**：月光没在地面上形成亮面暗面，灯笼光圈小，没有光池引导视线。
7. **没有前景层**：角色前面只有几片很淡的花瓣。

## 3. 10 分标准（每条 1 分，验收时逐条打分）
1. 一眼看清：眯眼测试下，角色和敌人永远是画面里最先看到的。
2. 有纵深：≥ 8 层视差，越远越灰越淡；层与层有遮挡，不是千层饼。
3. 有前景：画面边角有近黑剪影，走动时滑得最快，绝不挡战斗区。
4. 光会落地：月光照出石面亮边，灯笼有光池和投影，角色走近会被染暖。
5. 色调统一：一套主调色板，冷月 + 暖灯，没有乱色。
6. 画法统一：背景、地形、道具同一像素尺度（1 美术像素 = 3 屏幕像素）、同一调色板。
7. 主题统一：东方水乡月夜河堤，所有物件同一文化语言。
8. 会动：柳枝、水波、灯火、雾、萤火、远处孔明灯。
9. 打起来更好看：刀光照亮周围、命中闪一下、大招全场变色。
10. 不重复：每个封印竞技场有自己的标志物和色调。

## 4. 方案

### 4.1 定调：「月下水乡 · 像素光影」
- 东方水乡月夜河堤：石拱桥 + 灯笼串、白墙黑瓦民居、垂柳、远处宝塔剪影和孔明灯、青石板河堤。
- 像素画 + 现代光影（HD-2D 的思路做在 2D 里）。角色暂不像素化（沿用用户第三轮决定），但吃同一套光。
- 退路：如果 GPT 两轮都出不了干净的像素画，改走奥日/九日的手绘路线——方案不变，只换出图画风。

### 4.2 主调色板（全部背景图会被脚本锁到这套颜色里，GPT 出图再不一致也能统一）
| 用途 | 颜色 |
|---|---|
| 夜空深青 | #101B24 → #1A2C38 |
| 远景雾青灰 | #4A6470 |
| 中景石灰 | #6E7F86 |
| 月光高光（只用于顶面小面积） | #C9D8D2 |
| 灯火琥珀 / 暖影 | #F0A04B / #A9542C |
| 前景剪影 | #080C11 |
| 敌人攻击预警（背景禁用这个饱和度） | #E2553A |

### 4.3 三层明度 + 分层表
- 背景：中等偏亮、低对比（越远越接近雾色）。
- 战斗层：全屏对比最强——石沿亮边、接触影、灯池；身后放一条中等亮度的“背光雾带”，让深色的影一眼跳出来。
- 前景：近黑剪影，只在左上/右上角和最底边。

| 层 | 内容 | 视差 | 雾量 |
|---|---|---|---|
| 0 | 天空渐变 + 满月（压暗银河） | 固定 | — |
| 1 | 远山 + 宝塔剪影 | 0.05 | 70% |
| 2 | 孔明灯（缓慢上升，暖点） | 0.08 | 50% |
| 3 | 云 / 雾带（自己飘） | 0.15 | — |
| 4 | 远岸民居 + 稀疏暖窗 | 0.25 | 45% |
| 5 | 石拱桥 + 灯笼串 | 0.35 | 30% |
| 6 | 河面：灯笼竖向倒影、波光（逐行视差） | 0.35→1.0 | — |
| 7 | 中景垂柳 / 河岸 | 0.6 | 15% |
| 8 | 背光雾带（在角色身后） | 0.9 | — |
| 9 | 战斗层：河堤步道 + 地形零件 + 石灯笼 | 1.0 | 0 |
| 10 | 前景剪影：柳枝、石栏、芦苇（轻微模糊） | 1.4 | — |
| 11 | 空气：光束、萤火、柳絮、雾丝 | 屏幕 | — |
| 后期 | 统一调色（LUT）、只对亮光泛光、暗角 | — | — |

### 4.4 Godot 里怎么实现
- `CanvasModulate` 给夜色底调；`PointLight2D` 做灯笼（暖色 + 火苗抖动）；`DirectionalLight2D` 做月光。
- 地形零件和角色自动生成法线图（按亮度算高度的小脚本）→ `CanvasTexture` 的 normal → 灯笼和刀光实时照出立体感。
- 刀光 / 命中 / 大招：短暂的 `PointLight2D` 闪光，照亮周围地面和敌人。
- `WorldEnvironment` 开 2D HDR + glow，阈值只让灯火、月亮、刀光泛光。
- 雾：噪声着色器层插在 3/5/8 层之间；柳枝/芦苇用顶点着色器摆动；孔明灯、萤火用 `GPUParticles2D`。
- 调色板锁定脚本：检测像素格 → 缩回真实像素尺寸 → 量化到 4.2 主调色板 → 最近邻放大 3 倍。

### 4.5 色调脚本（每轮三个封印竞技场）
1. 一封「清月」：冷月为主，灯少。
2. 二封「灯会」：整条河的灯笼亮起，暖橙占比最大。
3. 三封「浓雾」：雾最厚，只剩剪影和灯点，影卒的黄眼最显眼。

## 5. 执行顺序（每步做完就推、给截图）
1. **不用等出图**：现有素材先降饱和、加冷暖对比、加大气透视雾、背光雾带、灯笼真光 + 光池、泛光、前景剪影、刀光照明 → 目标 3.5 → 6 分。
2. **定调图**：用户用下面的提示词出 1 张，我做眯眼测试 + 调色板测试，最多改 2–3 轮。
3. **零件套件**：按定调图出 10–12 张分层素材（洋红底），我抠图、对齐像素格、锁调色板、做无缝、法线图 → 目标 8 分。
4. **竞技场标志物 + 色调脚本 + 战斗光效** → 目标 9–10 分。

## 7. 第五轮修订：角色与环境融洽（2026-10-20，取代 4.1 的题材和画法；第 3 节第 7 条随之改为“幻想哥特水城”）

用户决定：用 GPT 出底图，我负责拆层、统一颜色、做动态。要求“角色和环境融洽”。

### 7.1 先看角色（更正：游戏里用的是 `assets/image/desktop-actions/`，即 battle.json 的 activeArtCollection = desktop-actions-20261018）
- 之前误用了旧的 `characters/nightcrow`（修长版），已改正；`tools/art/keyart_check.py` 默认用 `desktop-actions/待机/frame_00001.png`。
- 画法：**Q 版约三头身**，粗而干净的深色描边，光亮的赛璐璐 2~3 阶明暗，颜色鲜。
- 颜色：深紫黑 #231623（约 41%）、#4A3442，白色上衣 #E6CBD6（14%），发尾和剑是蓝紫渐变 #2A1067 / #3914BB / #9D4BDE。
- 造型：大头、圆润的身体，配尖的点缀（刺发、羽饰肩甲、长剑）。
- 结论：背景要往“Q 版卡通游戏背景”靠一档——形体简化、圆润厚实、近景粗描边、少碎细节；她的蓝紫发尾意味着背景更不能偏蓝。
- 第一张定调图（GPT，写实比例、细碎精致、偏蓝）合成真主角后：锁色加雾后可读性好，但写实比例 + Q 版角色像“娃娃放进真城市”，需要按 Q 版风格再出一版定调图。

### 7.2 因此改两件事
1. **背景不走像素画**，走“日系动漫手绘背景”（近景干净描边 + 平涂渐变，远景无描边、雾化）。像素背景 + 平滑角色就是第 2 节说的“画法打架”。
2. **题材改成「月下堤岸 · 幻想哥特水城」**（待用户确认）：运河河堤、石拱桥、尖拱窗民居、铸铁路灯、常春藤、远处尖塔钟楼。理由：和她的哥特裙、长剑、尖羽造型同一种文化和形状语言；白石 + 深石板呼应她的黑白配色。东方水乡做备选，不混搭（不要中式亭子、红灯笼、雪山）。

### 7.3 融洽的 7 条规矩（出图验收和 Godot 实现都按这个）
1. 同一画法：近景物件和角色一样有深色细描边；越远越无边、越灰、越糊。
2. 颜色分工：紫色只属于主角和她的剑气；敌人预警用红橙 #E2553A；世界用冷青灰 + 银灰月光 + 琥珀灯光 #F0A04B（琥珀是紫的补色，衬她）。背景饱和度不超过角色。
3. 明度分区：角色身后（步道上方约 1.5 个身高）是中等明度、少细节、带薄雾的“安静区”；细节集中在画面上三分之一和左右两边。
4. 同一盏灯：主光右上方月光，辅光路灯。Godot 里给角色加：走近路灯染暖 10~15%、空旷处偏冷；脚下软影子；湿石面上淡淡倒影（翻转、模糊、低透明）。不加白色轮廓光。
5. 比例统一：角色 1.6 米 ≈ 87px（720p）。门 2.1 米、栏杆 1 米、路灯 3 米，提示词里按“角色身高的几倍”写。
6. 前景夹住角色：画面两边偶尔有很暗、虚化的常春藤/铁栏杆尖挡在角色前面，让她“在场景里”而不是“贴在场景上”。
7. 形状呼应：尖拱、尖塔、铁艺尖头呼应她的尖羽和长剑。形体按 7.1 简化厚实（配 Q 版），但轮廓收尖，不要软萌圆胖。

### 7.6 第 2 版定调图（Q 版画风）检查结果 + 去“AI 味”（2026-10-21）
**结论：定调通过，不再重抽。** 真主角（desktop-actions 待机帧）放进去和 GPT 画的角色几乎同一画法，融洽这条过了。
数据（`keyart_check.py`）：饱和蓝 78%（比第 1 版 64% 更蓝）、紫 1.5%（紫色旗子）、平均饱和 0.45；角色身后细节是天空 2.5 倍；角色占画面 1/3.5（要 1/8，GPT 没照做）、步道顶在 71%（要 78%）。比例和构图在分层拼装时由我按游戏尺寸重排，不靠定调图。

用户反馈“有点 AI 味”。来源和对策（对策都放在分层出图 + Godot 拼装阶段，不靠重抽整图）：
1. **深蓝 + 橙灯的万能夜景配色** → 锁色到青灰（脚本已有，效果最大）。
2. **哪里都一样细、一样亮，没有可以歇眼的地方** → 远景压对比、中景加雾，角色身后留安静区（7.3 第 3 条）。
3. **路灯约 12 盏一模一样、均匀排、左右对称框住画面** → 路灯单独出道具图，游戏里按节奏摆，每屏 2~3 盏、间距不等。
4. **糊掉的花纹**（桥栏杆像乱码、青苔像抹布、远处窗户位置随机）→ 提示词要“简单、数得清的重复花纹”，给数量（几块砖、几扇窗）；栏杆和步道只出“一节”，代码重复拼接。
