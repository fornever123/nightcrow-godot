# 场景美术 10 分方案（2026-10-19）

用户：“现在游戏的风景美术效果还是太差了……去网上找美术顶级的游戏学习参考，给我一个 10 分的游戏美术方案。”

## 1. 参考了谁、学什么

| 游戏 | 公开资料里的做法 | 我们照着做什么 |

## 2. 现在的问题（第四轮截图，自评 3.5 / 10）
1. **千层饼**：天空/雪山/城堡/桥/海/步道/海全是水平条带，没有前后遮挡和斜线，纵深靠“摞”。
2. **背景比战斗区抢眼**：银河、大月亮、闪光海面最亮最细；战斗的步道只是一条细线；深色影卒站在深蓝海面前几乎看不见。
3. **三种画法打架**：GPT 绘画再像素化的背景 + 代码画的像素地形 + 平滑的动漫角色。
4. **主题混搭**：哥特城堡 + 中式亭子 + 红灯笼。
5. **高饱和蓝铺满全屏**（违反我们自己“背景不要高饱和蓝紫”的规则），没有冷暖对比结构。
6. **光不落地**：月光没在地面上形成亮面暗面，灯笼光圈小，没有光池引导视线。
7. **没有前景层**：角色前面只有几片很淡的花瓣。

## 3. 10 分标准（每条 1 分，验收时逐条打分）
1. 一眼看清：眯眼测试下，角色和敌人永远是画面里最先看到的。
2. 有纵深：≥ 8 层视差，越远越灰越淡；层与层有遮挡，不是千层饼。
3. 有前景：画面边角有近黑剪影，走动时滑得最快，绝不挡战斗区。
4. 光会落地：月光照出石面亮边，灯笼有光池和投影，角色走近会被染暖。
5. 色调统一：一套主调色板，冷月 + 暖灯，没有乱色。
6. 画法统一：背景、地形、道具同一像素尺度（1 美术像素 = 3 屏幕像素）、同一调色板。
7. 主题统一：东方水乡月夜河堤，所有物件同一文化语言。
8. 会动：柳枝、水波、灯火、雾、萤火、远处孔明灯。
9. 打起来更好看：刀光照亮周围、命中闪一下、大招全场变色。
10. 不重复：每个封印竞技场有自己的标志物和色调。

## 4. 方案

### 4.1 定调：「月下水乡 · 像素光影」
- 东方水乡月夜河堤：石拱桥 + 灯笼串、白墙黑瓦民居、垂柳、远处宝塔剪影和孔明灯、青石板河堤。
- 像素画 + 现代光影（HD-2D 的思路做在 2D 里）。角色暂不像素化（沿用用户第三轮决定），但吃同一套光。
- 退路：如果 GPT 两轮都出不了干净的像素画，改走奥日/九日的手绘路线——方案不变，只换出图画风。

### 4.2 主调色板（全部背景图会被脚本锁到这套颜色里，GPT 出图再不一致也能统一）
| 用途 | 颜色 |
|---|---|
| 夜空深青 | #101B24 → #1A2C38 |
| 远景雾青灰 | #4A6470 |
| 中景石灰 | #6E7F86 |
| 月光高光（只用于顶面小面积） | #C9D8D2 |
| 灯火琥珀 / 暖影 | #F0A04B / #A9542C |
| 前景剪影 | #080C11 |
| 敌人攻击预警（背景禁用这个饱和度） | #E2553A |

### 4.3 三层明度 + 分层表
- 背景：中等偏亮、低对比（越远越接近雾色）。
- 战斗层：全屏对比最强——石沿亮边、接触影、灯池；身后放一条中等亮度的“背光雾带”，让深色的影一眼跳出来。
- 前景：近黑剪影，只在左上/右上角和最底边。

| 层 | 内容 | 视差 | 雾量 |
|---|---|---|---|
| 0 | 天空渐变 + 满月（压暗银河） | 固定 | — |
| 1 | 远山 + 宝塔剪影 | 0.05 | 70% |
| 2 | 孔明灯（缓慢上升，暖点） | 0.08 | 50% |
| 3 | 云 / 雾带（自己飘） | 0.15 | — |
| 4 | 远岸民居 + 稀疏暖窗 | 0.25 | 45% |
| 5 | 石拱桥 + 灯笼串 | 0.35 | 30% |
| 6 | 河面：灯笼竖向倒影、波光（逐行视差） | 0.35→1.0 | — |
| 7 | 中景垂柳 / 河岸 | 0.6 | 15% |
| 8 | 背光雾带（在角色身后） | 0.9 | — |
| 9 | 战斗层：河堤步道 + 地形零件 + 石灯笼 | 1.0 | 0 |
| 10 | 前景剪影：柳枝、石栏、芦苇（轻微模糊） | 1.4 | — |
| 11 | 空气：光束、萤火、柳絮、雾丝 | 屏幕 | — |
| 后期 | 统一调色（LUT）、只对亮光泛光、暗角 | — | — |

### 4.4 Godot 里怎么实现
- `CanvasModulate` 给夜色底调；`PointLight2D` 做灯笼（暖色 + 火苗抖动）；`DirectionalLight2D` 做月光。
- 地形零件和角色自动生成法线图（按亮度算高度的小脚本）→ `CanvasTexture` 的 normal → 灯笼和刀光实时照出立体感。
- 刀光 / 命中 / 大招：短暂的 `PointLight2D` 闪光，照亮周围地面和敌人。
- `WorldEnvironment` 开 2D HDR + glow，阈值只让灯火、月亮、刀光泛光。
- 雾：噪声着色器层插在 3/5/8 层之间；柳枝/芦苇用顶点着色器摆动；孔明灯、萤火用 `GPUParticles2D`。
- 调色板锁定脚本：检测像素格 → 缩回真实像素尺寸 → 量化到 4.2 主调色板 → 最近邻放大 3 倍。

### 4.5 色调脚本（每轮三个封印竞技场）
1. 一封「清月」：冷月为主，灯少。
2. 二封「灯会」：整条河的灯笼亮起，暖橙占比最大。
3. 三封「浓雾」：雾最厚，只剩剪影和灯点，影卒的黄眼最显眼。

## 5. 执行顺序（每步做完就推、给截图）
1. **不用等出图**：现有素材先降饱和、加冷暖对比、加大气透视雾、背光雾带、灯笼真光 + 光池、泛光、前景剪影、刀光照明 → 目标 3.5 → 6 分。
2. **定调图**：用户用下面的提示词出 1 张，我做眯眼测试 + 调色板测试，最多改 2–3 轮。
3. **零件套件**：按定调图出 10–12 张分层素材（洋红底），我抠图、对齐像素格、锁调色板、做无缝、法线图 → 目标 8 分。
4. **竞技场标志物 + 色调脚本 + 战斗光效** → 目标 9–10 分。

```
请画一张横版动作游戏的「画风定调图」（只用来定风格，不直接放进游戏）。
场景：东方水乡的月夜河堤。从远到近：低饱和的深青色夜空，右上方一轮满月，月光克制、不要大片光晕；远处层层淡青灰的山影和一座宝塔剪影，越远越淡、越接近雾的颜色；远处天空有三四盏缓缓升起的孔明灯；中远处一座多拱石桥横跨河面，桥上挂一串暖橙色灯笼；河对岸是白墙黑瓦的民居和垂柳，少量窗户亮着暖灯；河面平静，灯笼在水里拉出竖向的暖色倒影。
战斗区（画面下方约三分之一处）：一条干净的青石板河堤步道，从左到右贯穿全图，步道顶面的边沿被月光照成一条清楚的浅色亮边；步道上方留出大片安静、干净的空间（角色在这里打斗），步道身后是一层中等亮度的薄雾，让深色人物站在这里能一眼看清。步道上有两座石灯笼和一段矮木栏杆，石灯笼在地面投出暖色光圈。
前景：画面左上角和右上角垂下深色柳枝剪影；画面最下边有一排近乎全黑的石栏杆和芦苇剪影，只占边角，不挡住步道。
明暗：前景最暗；步道和战斗区对比最强；越远越灰越淡（大气透视）。眯起眼看，画面要能清楚地分成前、中、后三层。
配色：深青、青灰、石灰色为主，中低饱和度；暖橙琥珀色只用在灯火、窗户以及它们的光圈和倒影上；不要紫色、粉色、洋红色，不要高饱和的蓝色或蓝紫色；不要白色描边或白色轮廓光。
画风：精细的像素画（pixel art）。整张图相当于一张 512×341 的像素画放大 3 倍——每个像素点都是 3×3 的同色小方块，像素格横平竖直、全图大小一致；不要抗锯齿、不要模糊和柔光、不要喷枪渐变、不要噪点颗粒；全图大约 40 种颜色，用像素色阶和少量规则抖动表现明暗，细节要精致。
不要文字、水印、签名、人物、动物。图片尺寸 1536×1024（横版）。
```
