## 3. 实现方案

### 3.1 时间轴（`scripts/gameplay/player.gd`）
- 用新的 `@export` 参数替换现在 5 拍版的大招参数：`ult_flash_frames`（8）、`ult_cutin_end`（40）、`ult_cut_frames`（[42, 54, 64]）、`ult_cut_stop`（8）、`ult_calm_start`（72）、`ult_final_frame`（100）、`ult_freeze_frames`（30）、`ult_total_frames`（172）。
- 信号：`ult_started` → `ult_strike(i, n)`（每刀命中那一帧）→ `ult_arrive`（站定）→ `ult_reveal`（终结那一刀）→ `ult_finished`。去掉 `ult_launch / ult_hit / ult_landed`。
- 位置：关卡在 `ult_started` 时给出 3 个出刀位置 + 1 个站定位置。她在 38 帧隐藏，命中帧现身在出刀位置、停 8 帧、再隐藏；72 帧起站在站定位置。全程不走物理。
- 姿势（都是已有动画）：出刀轮换 `dash_right` 第 12 帧画（大挥）、`source_空中攻击` 第 13 / 29 帧画；站定 = `sheathe` 第 19 帧画，大招结束后接着播完收刀。

### 3.2 路线（`scripts/night/night_trial.gd`）
- 敌群包围盒 [L, R]，敌群在她哪一边沿用现在的判断，放不下就整体换边。
- 三根斩线按样片的相对位置换算：一根左高右低、一根左低右高、一根水平，都穿过敌群胸口高度、两端出画；出刀位置分别在敌群两侧和上方。
- 站定位置：敌群远端外侧，站在地上，背对敌人。
- 影全程在原地不动（不挑飞）；定格结束才碎开 / 震飞。

### 3.3 画面效果（重写 `scripts/night/ult_fx.gd`）
- **黑白压暗**：新 `assets/shaders/fx_ult_mono.gdshader`，全屏读屏幕纹理做去饱和 + 压暗 + 提对比。放在角色和斩线之上、UI 之下，替换现在的背景褪色层。不受影响的紫色点缀（眼光、终结刃芯）和切入都画在它上面的 UI 层。
- **上下黑边**：UI 层两个 ColorRect，高度跟着时间轴伸缩。
- **斩线**：世界空间里一个 Node2D 用 `draw_colored_polygon` 画两头尖的菱形长条（样片的 `lens`），命中 2 帧扫完、顿帧期间最粗、之后收成 1 像素残线。
- **冲击帧**：不用二值化（黑暗背景和黑色影会糊成一片）。改成“场景内换色”：角色和影之下、背景之上铺一块全屏白色，她和影切成纯黑剪影材质，斩线画黑色；反相那一帧反过来（黑底、白剪影）。剪影用现有 `fx_ult_sil.gdshader`（`paint = 0`，加一个颜色参数）。
- **终结横断**：新 `assets/shaders/fx_ult_split.gdshader`（之前删过一个同名的，按新需求重写）：全屏读屏幕纹理，刃口上方整体往一侧错开、下方往另一侧，中间画黑缝；白刃紫芯画在 UI 层。
- **影被斩开**：`shade.gd` 的 `_draw` 都是 `draw_colored_polygon`，定格结束时把这一帧的多边形记下来，用 `Geometry2D.intersect_polygons` 按终结刃口切成上下两半：上半飞起、旋转、落下，下半留在原地，然后淡出。
- **定格**：所有影、她、特效时间都停住 30 帧（影用 `hitstop_frames`，她的大招帧数暂停推进，特效节点暂停 `_process`）。题字、印章、伤害数字画在 UI 层。
- **夜景前景**：`night_backdrop` 里挡在角色前面的 `_front`（z=15）、`_motes`（z=14）大招期间淡出；光影后期 `post` 层大招期间关掉。

### 3.4 切入「刀缝」（UI 层，新脚本 `scripts/night/ult_cutin.gd`）
- 一个 Polygon2D 当遮罩（`clip_children = CLIP_CHILDREN_ONLY`），每帧按“缝张开多少”改它的四个顶点；立绘 Sprite2D 是它的子节点，自然被裁进缝里。
- 立绘材质：一个很小的 shader 做去饱和 0.7、对比 1.18、亮度（刚张开时 2.2 倍，4 帧落到正常），四周径向淡出（不露原图的深蓝底方框）。
- 两条刃边是贯穿全屏的 Line2D（2 像素白 + 外侧 1 像素灰），最开始那一斩带一层模糊白光。
- 题字 Sprite2D 压在缝的下沿（1.18 → 1 倍），下面一条细线和一行小字「终 结 · 绝 影」，印章 Sprite2D 1.7 → 1 倍盖上；眼光是一根很扁的白椭圆 + 一点紫，从左往右扫过她的眼睛。
- 素材放进 `assets/image/ult/cold/`：`portrait.png`（用 `public/cutin2/portrait_hd.png`，已抠透明，立绘自身不再需要径向淡出，只淡掉图片边缘的硬边）、`title.png`、`seal.png`（样片工程 `public/cutin2/` 里拆好的那两张）。

### 3.5 声音（现有音效库）
- 发动：一声短促的金属“叮”（拔刀或弹刀音效）。
- 三刀：每刀挥刀声 + 刀刃命中声，命中那一帧响。
- 终结：大劈砍声，在定格开始那一帧切断，定格期间静音（看第 2 节第 2 条）。
- 收：碎块落地、影消散的声音。

### 3.6 去掉的东西
5 拍版的贴地拖尾、来回冲影子、俯冲长枪、巨鸦、白刃、细斩线、影翼，以及现在的背景褪色层和旧切入。`ult_fx.gd` 只保留镜头控制和 HUD 显隐的写法，其余重写。

## 5. 风险
- **黑白层的范围**：它必须盖住所有世界内容、又不能盖住 UI 和紫色点缀。实现时先截一张发动后的画面检查有没有漏网的彩色节点。
- **冲击帧换色**：所有可见的角色 / 影都要能切到纯色剪影；漏掉的节点会在白底上露出原色，要逐类检查（影卒、甲影、弓手、炸弹影、飞行物）。
- **敌人很分散或只有一只**：三根斩线可能穿不过所有人。斩线的角度和位置要按包围盒自动调整，截一只和五只两种情况检查。
