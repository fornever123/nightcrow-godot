# FrameBaker 手调与导入

FrameBaker 用来调整动作图片的位置、逐帧停留和角色／刀光的配合。修改器负责把导出的结果接到 Godot 招式里。

现有角色原图和游戏动作保留。FrameBaker 里的新动作还没有替换 `assets/data/battle.json` 中的实际游戏配置；完成下面的导入、绑定和保存后，游戏才会使用你选中的结果。

## 打开已经准备好的项目

1. 双击 `E:\00game\打开FrameBaker.bat`。
2. 打开[夜鸦 FrameBaker 项目](http://127.0.0.1:3210/project/3758d524-8b9c-4b32-8732-81255f1dd72a)。如果页面暂时打不开，等启动窗口完成后刷新。
3. 双击游戏工程的 `OPEN_MODIFIER.bat`，打开[修改器](http://127.0.0.1:4329/)，进入“动作工坊”。

FrameBaker 官方源码安装在 `E:\00game\tools\framebaker`，位于 Godot 工程外。准备好的项目包含 27 条动作轴、880 个时间步骤、1760 张 PNG，角色和刀光分轨，基础帧率为 24 FPS。先选择一条轴播放，再暂停到要调整的位置。

## 在 FrameBaker 里手调

逐帧查看角色与刀光的相对位置。要让某个姿势停留更久，调整该帧的停留时长；要让整段都快一些，之后也可以在修改器里调整招式“动作速度”。这两项可以一起使用。

以脚底或稳定的身体位置作为对齐参考。FrameBaker 舞台中心的共同原点，导入游戏后对应角色脚底。若动作围绕舞台中心摆放，角色图片可能整体偏高或偏低；先用参考帧对齐，再检查整段，避免逐帧追着画面修位置。

可以在 FrameBaker 中完成对齐，也可以导入后在动作工坊暂停，勾选“整段一起移动”，把角色脚底拖到画布十字。不要在播放时拖动，以免调错帧。

## 推荐方式：角色与刀光一起导出

1. 在 FrameBaker 中保留要输出的角色和刀光轨道可见，隐藏不需要输出的轨道。
2. 导出当前动作的 PNG 序列 ZIP 或图集 ZIP，保留一起生成的 `.frames.json` 文件。导出的图片会把当时可见的轨道合成在一起。
3. 在修改器动作工坊上方选“角色动作”。找到“导入 FrameBaker 手调结果”。
4. “导入方式”先用默认的“新增独立动作，保留现有动作”，填写容易辨认的名称。
5. 勾选“导出图片已经包含刀光”，再点“导入 FrameBaker ZIP”。也可以解压后点“导入解压后的文件夹”，选择只包含一个动作及其 `.frames.json` 的文件夹。
6. 播放检查；如整体位置不对，暂停并勾选“整段一起移动”，以画布十字校准脚底。

“导出图片已经包含刀光”会启用“动作图片已包含刀光（避免重复叠加）”。游戏因此不会再加原来的羽刃刀光，也不会加“同步附加特效层”。若导出的图片只有角色，应取消这个选项。

默认新增的动作只是候选项。确认效果后，按下面的“绑定到游戏”操作。需要直接更新已有动作时，先在上方选中目标，再把导入方式改成“替换上方当前动作”；替换后也要重新检查命中帧。

## 可选方式：角色与刀光分开导出

想保留独立刀光层时，用同一条动作轴导出两次：一次隐藏刀光，只输出角色；另一次隐藏角色，只输出刀光。两次都保留共同原点与时间节奏。

1. 按上面的方法导入角色，取消“导出图片已经包含刀光”。
2. 动作工坊上方切到“刀光特效”，导入单独的刀光 ZIP 或文件夹，建议同样新增独立片段并命名。
3. 切回“角色动作”，选中刚才的角色片段。
4. 在“同步附加特效层”中选中刚导入的刀光；保持“动作图片已包含刀光”关闭。
5. 逐帧检查剑与刀光的相对位置，再播放检查节奏。

角色与特效分开时，需要做相同的整体偏移校准。只移动角色不会自动修改刀光的原点；若角色整体向下移动了，刀光也应在对应片段中做相同校准。优先在 FrameBaker 中把两条轨道一起对齐，再分开导出。

独立刀光使用自己的逐帧停留，并跟随招式速度、翻向和受击形变；真实命中停顿时与角色一起暂停。刀光播放完会隐藏，不会一直挂着最后一张图片。选择这个同步层后，不会再额外叠加旧羽刃刀光。

## 绑定到游戏并保存

攻击动作：进入“战斗参数”，点击要修改的招式，在“对应角色动作”中选择刚导入的名称。保持“按动作帧同步”开启，重新设置“开始命中帧”“结束命中帧”和“允许接招帧”。结束命中帧包含当前这一帧。

待机、跑步、跳跃等基础动作由游戏固定名称选择。仅新增一条相似名字的片段不会自动生效。要更新它们，回动作工坊选中现有的对应动作，再用“替换上方当前动作”导入。待机和跑步需要循环时，开启“循环播放”；攻击和独立刀光通常不循环。

最后点顶部“保存并打开游戏”，或运行时的“保存并刷新游戏”。用实际游戏检查脚底、翻向、命中范围和接招。保存会重置训练场；需要回退可使用撤销或“备份与回收站”。

## 停留时间和命中停顿怎么区分

“当前帧停留”是图片本身的节奏：1 表示一帧，2 表示两倍时长，可以填写正的小数。以 24 FPS、动作速度 1 为例，停留 1 是约 41.7 毫秒，停留 2 是约 83.3 毫秒；动作速度 2 会把这些时间再减半。

修改器预览、整段时长、命中窗口和接招位置都按每帧实际停留累计。调整前面某一帧的停留，会把后面的命中时间一起后移。命中停顿是碰到木桩后另外产生的冻结，不应靠拉长动作图片来代替。停顿期间仍能提前输入下一刀。

## 常见情况

| 现象 | 检查方法 |
|---|---|
| 导入后游戏仍是原动作 | 新增片段需要在战斗参数里绑定并保存；待机／跑步／跳跃要替换对应原动作。 |
| 刀光出现两份 | 合成导出时开启“动作图片已包含刀光”；分层导出时只选择一个“同步附加特效层”。 |
| 角色或刀光位置偏移 | 检查共同原点；角色和特效分层时应用相同整体校准。 |
| 刀光突然少了 | 合成图片没有刀光时不要勾选“已包含刀光”；分层方案需选中同步特效。 |
| 文件夹导入失败 | 一个文件夹只放一个动作的导出结果，保留唯一 `.frames.json` 和其引用的 PNG。不要只选 PNG。 |
| 换动作后命中太早或太晚 | 在战斗参数重设命中帧和接招帧，再到 Godot 检查真实碰撞。 |
