# 外部工具 / 仓库调研

用户发来的 GitHub 仓库逐个看过，结论记在这里。新看的往上加。

“已装”指本机 Claude Code 的技能列表里有同名技能，直接调用即可，不用再装。

---

## 2026-11-02 · 哪个适合做首页

**结论：没有一个能直接做出游戏里的首页。** 首页是可交互的界面，需要分层视差、雨、光、菜单和按键，最后要在 Godot 里用场景、shader 和粒子来实现。这些工具输出的是网页动画或 MP4，只能用在设计和预演阶段。

按对首页的帮助排序：

| 排名 | 仓库 | 对首页的用处 |
|---|---|---|
| 1 | showheyohtaki/motion-prompt | 定动效最好用。字标进场、菜单光标、转场都能在它的效果库里挑一个有名字的效果，用名字和首页会话、GPT 沟通。示例代码是 Canvas 函数，可以照着改写进 Godot |
| 2 | anthropics/skills · frontend-design（已装） | 菜单排版、字体、留白，用来出首页的 HTML 样图，避免模板味 |
| 3 | win4r/video-director（已装） | 只适合做首页前面那段预渲染开场或预告，比如“5:59 旧光一熄、新光一亮”。不能做可交互的首页本身 |
| 4 | Vincentwei1021/mg-styles-15 | 只能当参考看。“Liquid Motion”那一版和之前提过的黑白液体意象有关 |
| 5 | cth9191/animate | 和 video-director 功能重叠；自带的剪纸、丝网印刷、像素这些画风和游戏的哥特半写实风不搭 |
| — | patch-gg/pixelfx（已装） | 像素风特效，和首页的高清画风不搭。可能对光线线有用，见下 |
| — | 其余几个 | 和首页无关，见下 |

## 每个仓库是什么

### showheyohtaki/motion-prompt
- **是什么**：动效名称库，8 个包共 192 个有名字的效果，覆盖动态图形、镜头运动、UI 组件、落地页效果、照片质感。每个效果都配了动图、一句话说明和示例提示词，另有 Claude Code / Codex 技能，选中效果后由 AI 改写进自己的项目。
- **怎么做**：每个效果是一个 Canvas 2D 函数，画面只取决于时间。依赖 Node 18+，不调付费接口。MIT 协议。
- **限制**：只讲网页和视频的移植，不涉及游戏引擎，写进 Godot 要自己改。
- **对夜鸦**：首页、暂停菜单、UI 的动效都可以先在这里挑名字定下来，再写进 Godot。

### anthropics/skills · frontend-design（已装）
- **是什么**：Anthropic 官方技能，给界面设计定审美方向、字体和版式，避免做出“模板味”。
- **对夜鸦**：首页和 UI 的 HTML 样图阶段可以用；最终效果还是要做进 Godot。

### win4r/video-director（已装）
- **是什么**：让 AI 用代码（HTML/Canvas、SVG、Three.js、GSAP、Remotion）逐帧渲染短片，输出 MP4。带两个检查脚本：时间线检查，以及成片检查（字号、对比度、闪烁、循环接缝、响度）。不调任何生图、生视频模型。MIT 协议。
- **依赖**：ffmpeg、Python（numpy、Pillow），Node 加 Playwright 或 Remotion。
- **对夜鸦**：可以做首页前的开场短片和预告片。大招线已经在用 Remotion，可以借它的成片检查脚本。

### Vincentwei1021/mg-styles-15
- **是什么**：15 部 10 秒动态设计短片的展示仓库，每部都是 AI 按一条提示词用代码写出来的，公开了提示词、风格说明和源码，配乐用 Python 合成。MIT 协议，字体文件没附带。
- **15 种风格**：逐帧线条抖动、等距 2.5D、扁平矢量、线稿、Blender 3D、形状变形、贴纸讲解、赛博 HUD、拼贴、极光玻璃、包豪斯、80 年代合成波、像素、液体、竖版字幕。
- **对夜鸦**：只当风格参考。它的提示词写法（风格说明加审片标准）可以借来写首页或大招的动效提示词。

### cth9191/animate
- **是什么**：Claude Code 技能，在 canvas 上程序化做动画，输出 HTML 和 MP4。有故事节拍、看样、分镜三道确认，自带 7 种画风（剪纸、丝网印刷、像素等），也可以照参考图匹配画风。MIT 协议。WebGL 3D 画风还没做出来。
- **对夜鸦**：和 video-director 功能重叠，画风也不搭，暂时不用。

### patch-gg/pixelfx（已装）
- **是什么**：244 个像素风特效（火、爆炸、魔法、天气、UI、拾取等），可导出透明 PNG 精灵表加 Aseprite JSON（Godot 能导入），也能导出 GIF 和 MP4。MIT 协议，自带的像素字体不在 MIT 里。
- **限制**：贴在角色身上的特效是按 24×38 的假人做的，要用在自己角色上得重新生成。
- **对夜鸦**：首页用不上，画风不搭。不过命中特效画在 `pixel_fx.gd` 的半分辨率画布上，光线线如果要参考像素特效的节奏和形状，可以翻一翻。

### vibe-motion/auto-motion
- **是什么**：把 SRT 字幕自动做成竖版动态图形视频的流程。Codex CLI 负责拆场景，Claude Code 按场景生成 HTML 动画，ffmpeg 拼接。输出 1080×1440、30 帧、无声，跑一条要 1.5 小时以上。页面上没有写协议。
- **对夜鸦**：不适用。它是做口播字幕视频的，竖版、无声、慢。

### 0x0funky/agent-sprite-forge（11-01 看过）
- **是什么**：用一张角色定稿图做图生视频，生成待机、走、跑、攻击、跳、受击动作，再抠像、对齐、找循环点，导出 Godot SpriteFrames。
- **对夜鸦**：不原样用，因为它会自动付费重出，而且接的是 OpenAI、Gemini 等模型，不是即梦。可以拆它的后处理脚本（柔边抠像、逐帧对齐、自动找循环点、颜色锁定）接到“即梦视频 → 帧序列”流程上。首页用不上。

### kaankiziltug/logo-design-skill（11-01 看过，已装为 logo-design）
- **是什么**：做 logo 的完整流程，从需求到 SVG 概念，再到小尺寸测试和品牌规范。自带 1400 多个参考 logo，不调付费接口。
- **对夜鸦**：适合做游戏图标、字标骨架和小尺寸徽记。UI 会话 10-31 用它画过血条，精致度不如 GPT。首页的字标可以先用它定版式骨架，再交给 GPT 出质感。

### Donchitos/Claude-Code-Game-Studios（11-01 看过）
- **是什么**：把 Claude Code 变成“游戏工作室”的项目模板，带 49 个智能体、七十多个斜杠命令、7 阶段流程和检查钩子。
- **对夜鸦**：不装。它太重，和本项目的分线规矩、`项目进程.md` 冲突，作者自测流程越重成绩越差。只借思路：战斗手感清单、按目录生效的代码规范、交付时附 QA 证据。

### NanmiCoder/MediaCrawler
- **是什么**：爬小红书、抖音、快手、B 站、微博、贴吧、知乎的公开帖子、评论和媒体的 Python 爬虫，靠 Playwright 和登录态实现。README 写明只限学习研究，**禁止商业用途**。
- **对夜鸦**：和首页、游戏制作都无关。拿来爬竞品反馈有平台条款和法律风险，不建议用。

### togg53192-cmd/jailbreaks
- **是什么**：收集针对各家 AI 模型的越狱提示词、角色设定和配置文件。
- **对夜鸦**：无关，不用，也不要拿里面的内容去对付生图或生视频工具。
