# GitHub 保存与更新

正式工程是本目录中的 Godot 游戏。它有独立的 Git 仓库，与上一级旧 Maker 仓库分开。

## 平时怎么更新

1. 正常制作游戏；修改器中改过参数或素材后，先点保存。
2. 双击工程根目录的 **上传更新到GitHub.bat**（英文入口 SYNC_GITHUB.bat 作用相同）。
3. 看到 **GitHub update complete.** 就表示本次修改已上传。

每次上传都会保留一份带时间的历史记录，以后可以找回旧版本。已经上传过且没变化的文件不会再生成新版本。上传只在运行这个入口或让 AI 更新时发生。

上传前会检查大文件和明显凭据；缓存、引擎安装文件、依赖包、备份和回收站不会上传。美术原图、去绿边副本、刀光、声音、配置、代码和修改器源码均保留。

如果 GitHub 上已经有另一台电脑的新修改，入口会停止并提示，不覆盖你本机的工作。可让 AI 先合并这些修改。

## 首次发布

仓库： https://github.com/fornever123/nightcrow-godot 。已按用户要求改为公开，其他人可以浏览和下载已上传的工程。

本机使用 Git Credential Manager 已有的 GitHub 登录完成身份验证。首次仓库创建和上传由 AI 执行；之后更新入口使用 Git 的已有登录。新电脑需要在 GitHub 官方页面登录。

登录使用 GitHub 官方网页授权；不要把密码、验证码或访问令牌写进工程文件或发在聊天里。本机 GitHub 连接复用了已经运行的本地代理，地址只保存在本地 .git 配置内。

## 换电脑使用

克隆这个仓库即可获得工程和素材。引擎文件的放置方法见 engine/README.md。修改器需要 Node.js，第一次启动会安装 package-lock.json 中锁定的依赖并构建页面。目前启动脚本沿用原电脑的 E:\node.exe / E:\npm.cmd 路径；在其他安装位置需要相应调整。
