## 1. 表演（和样片一致）

化影 → 乱斩 7 刀 → 站定（静）→ 咔 → 斩开 → 宣纸洗回夜色。全程约 3.3 秒（60 帧/秒）。

| 帧 | 拍 | 画面 | 玩法 |
|---|---|---|---|
| 0～10 | 起 | 她拔刀（`draw` 动画），眼睛一点紫 | 全场定住、她无敌（沿用现在的冻结逻辑） |
| 10～30 | 化影 | 墨从她脚下不规则晕开，整个世界变成宣纸；她从脚往上变成墨色剪影 | — |
| 34～89 | 乱斩 | 她是一道黑影，在敌群里来回冲 7 次（每次 3 帧冲 + 停 7→3 帧，越来越快）；每冲一次沿路径“写”出一笔墨痕，刚写出来透紫光；路上和落点留淡墨残影 | 每刀给屏幕里每只影一次不致死伤害（数字先攒着） |
| 89～93 | 站定 | 最后一冲落在敌群另一头，背对敌人 | — |
| 93～137 | 静 | 一切不动，镜头极慢推近，一片鸦羽飘落，她眼里一点紫 | — |
| 137 | 咔 | 腰间紫色横闪 → 1 帧反相冲击帧（黑底，墨痕 / 影 / 她变白） | 终结伤害这时结算 |
| 138～147 | 斩开 | 主墨刃 3 帧横扫整排、所有墨痕透紫、墨点顺刃甩出；影定住 5 帧再沿墨刃 + 一道墨痕碎成四块飞散 | 砍死的影碎掉；没死的（甲影）被震飞 |
| 157～197 | 收 | 墨从起笔被抹掉，宣纸淡出、夜色回来，她褪回原色，HUD 回来 | 大招结束、放开所有影 |

## 2. 需要你拍板的 4 件事

1. **切入立绘**：用户已换成新立绘（横剑遮脸 + 题字「绝影」+ 红印章，2026-10-24 提供，拆好的素材在样片工程 `public/cutin2/`）。切入界面样片 `src/UltCutIn.tsx`（`out/ult_ink_full.mp4`）：立绘装在一笔大墨刃里从笔头扫进来，背后淡紫细墨速度线，题字带墨点落下 + 白闪，印章“啪”地盖上，最后墨刃从笔头被抹掉；约 0.75 秒，期间战场定格在她拔刀那一帧。原图只有 768×792，进游戏前最好要一张高清原图。
2. **影翼要不要保留？** 现在大招里有一对鸦翼。墨刃版里她是纯剪影，翅膀会让剪影变乱。建议去掉。
3. **巨鸦俯冲要不要保留？** 墨刃版没有它的位置。建议去掉（素材留着以后用）。
4. **要不要加笔刷音效？** 每笔墨痕配一声短促的“唰”，咔那一下配收刀声和墨溅声。现有音效库里有挥刀和收刀声，可以先凑；想要专门的毛笔声需要生成音效（要你批准）。

## 3. 实现方案

### 3.1 时间轴（`scripts/gameplay/player.gd`）
- 用新的 `@export` 参数替换现在 5 拍版的参数：`ult_paper_frames`、`ult_rush_start`、`ult_dash_travel`、`ult_dash_holds`（数组 7,6,5,5,4,4,3）、`ult_calm_frames`、`ult_click_hold`、`ult_tail_frames`。
- 信号改成：`ult_started` → `ult_dash(i, from, to)`（每冲一次）→ `ult_strike(i, n)`（落点那一帧）→ `ult_arrive` → `ult_reveal`（咔）→ `ult_finished`。去掉 `ult_launch / ult_hit / ult_landed`。
- 路线由关卡在 `ult_started` 时给（`ult_route: PackedVector2Array` + 每点姿势），玩家按帧插值位置（和现在的 `_ult_path_point` 一样不走物理）。
- 姿势映射（都是已有动画）：冲刺 = `dash_right` 第 24～34 帧画；落点出刀轮换 `dash_right` 12（大挥）、`source_空中攻击` 13 / 21 / 29 / 37 帧；站定 = `sheathe` 第 19 帧画，咔之后接着播完收刀。

### 3.2 路线（`scripts/night/night_trial.gd`）
- 敌群包围盒 [L, R]（屏幕里活着的影），敌群在她哪一边沿用现在的判断。
- 7 个落点用样片里的相对坐标表：x 用敌群宽度归一化（-0.13～1.46），高度用“离地多高”（地面到约 290 像素空中，换算成世界单位）。终点 = 敌群远端外侧，站在地上，朝向背离敌群。
- 敌群太窄时宽度至少按 300 世界单位算，免得 7 冲挤在一起；放不下就整体镜像到另一边（沿用现在的放不下就换边逻辑）。
- 影全程站在原地不动（不再挑飞），只在咔之后碎开 / 震飞。

### 3.3 宣纸世界（新 `assets/shaders/fx_ult_paper.gdshader`）
- 替换现在的背景褪色层 `fx_ult_grade`：同一个位置（z = -3，夜景和地形之后、角色和影之前），画宣纸色 + 细颗粒 + 底部淡墨地平线。
- 遮罩：以她脚下为圆心的半径（屏幕空间）+ 噪声扰动边缘（样片里的“墨晕开”），收尾时整体淡出。
- 夜景里在角色前面的东西（`night_backdrop` 的 `_front` z=15、`_motes` z=14）大招期间淡出，不然会挡在宣纸前面露馅。
- 光影后期 `post` CanvasLayer（辉光 / 暗角 / 调色）大招期间关掉或压到最低，避免把宣纸染成夜色。

### 3.4 角色和影变成墨
- **她**：`character_view` 的 Sprite2D 大招期间换成剪影材质（现有 `fx_ult_sil.gdshader`，`paint = 0` 纯剪影 + 加一圈紫边），化影时按高度从脚往上切换（shader 加一个 `fill_y` 参数），收尾时从头往下褪回。
- **残影**：每冲一次在 1/3、2/3 处留两个当前帧的淡墨副本（Sprite2D，灰墨色、12 帧淡出）；落点留一个出刀剪影副本。
- **影**：`shade.gd` 加 `ink_mode`：斗篷画成墨黑、去掉黄眼和血条。
- **影碎开**：`shade.gd` 的 `_draw` 全是 `draw_colored_polygon`，碎开时把这一帧的多边形记下来，用 `Geometry2D.intersect_polygons` 按两条斩线（主墨刃线 + 离胸口最近的墨痕线）切成四块，分别往外推、下落、旋转、淡出；砍死的影走这个碎块表现，不再走原来的消散。

### 3.5 墨笔触（新 `assets/shaders/fx_ink_stroke.gdshader`）
- 素材：用户生成的三张水墨图，抠好的透明墨层放进 `assets/image/ult/ink/`（`main.png`、`thin_1～6.png`、`splatter.png`；抠图脚本沿用样片工程的 `tools/prep_ink.py`）。
- 每笔墨痕是一个 Sprite2D：放在冲刺线段中点、转到线段角度、长度 = 线段 + 两头各 80。
- shader 参数：`reveal`（笔锋写到哪）、`erase`（起笔被抹到哪）、`soft`（软边宽度）、`hot`（外圈紫光，取周围几个像素的 alpha 最大值做描边，和现有 `fx_shadow_wing` 的做法一样）。
- 主墨刃：同一个 shader，压扁到约 0.42 倍高，咔后 3 帧写完、第 14～36 帧被抹掉。墨点飞溅：两张 `splatter.png` 顺刃甩出、错开 2 帧。

### 3.6 冲击帧和镜头
- 冲击帧沿用现有 `fx_ult_impact.gdshader`（二值化 + `flip`）：在宣纸世界里二值化后 flip 一次就正好是“黑底、白墨”。
- 镜头：起手时把敌群和她的起点、终点一起框进画面（锚点 + 缩放，沿用现在的 `ult_fx._update_camera` 写法）；站定后极慢推近约 3.5%，咔时猛推 4.5% 再回。
- HUD：大招期间隐藏，咔之后约 40 帧回来（沿用）。

### 3.7 去掉的东西
5 拍版的贴地拖尾、来回冲影子、俯冲长枪、巨鸦、白刃、细斩线；影翼和巨鸦按第 2 节决定。`ult_fx.gd` 里这些代码删掉，保留切入立绘、冲击帧、镜头、HUD、伤害数字。

## 4. 验证
1. 全部测试 0 失败（跳过本机会卡死的 `ai_hd_visuals`）；`test_shades_v4` 的 `test_ult` 改成：7 刀 strike、咔时一次 reveal、影卒被砍死、甲影活着被震飞、屏幕外的影不受影响、飞行物被斩碎。
2. 用 `tests/dev/ult_shot.gd` 截 12 张关键帧，和样片同一时刻并排对比。
3. 按评审模板让独立子智能体打分。

## 5. 风险
- **宣纸层盖不住的东西**：凡是 z 比 -3 高、又不是角色 / 影 / 大招特效的节点，都会露在宣纸前面。实现时先截一张“全宣纸”画面逐个查。
- **局内小人剪影**：她的序列帧带半透明刀光残影，剪影阈值（`step(0.62, a)`）要调，不然剪影会多出一坨。
- **敌群很分散 / 只有一只**：7 冲路线会显得空，需要截图检查一只和五只两种情况。
