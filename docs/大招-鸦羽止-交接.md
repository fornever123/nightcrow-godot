## 3. 鸦羽止的设计（约 3.5 秒，60 帧/秒）

招牌意象：**时间停住，满屏鸦羽悬在半空；她一刀过去，刀路上的每片羽毛都被切成两半。** 黑白世界，紫色只做点缀（眼睛、发丝、刀刃一线、断口、刀线外光）。

| 帧 | 拍 | 画面 |
|---|---|---|
| 0～36 | 止 | 世界褪成黑白，落下的鸦羽慢慢停在半空；她压低成居合架势，眼里一点紫；镜头慢慢推到她身上 |
| 34～76 | 特写 | 一道白线斩开画面，开出一格**眼睛特写**；再斩开一格**握刀特写**（刃上寒光走过、“咔”）。格子外仍是停住压暗的世界，前景羽毛压在格子前面 |
| 76～80 | 一闪 | 镜头瞬间回全景，她消失（原地留横向紫色残影）；一条白芯紫光的线横贯全屏，**同时把两格特写沿刀线斩开飞走**；冲击帧白底黑剪影 → 反相 |
| 80～138 | 静 | 她已在敌群背后、背对敌人，**低位收势**；刀路上的羽毛断成两半悬着，断口一线紫；全场无声 |
| 138～210 | 落 | 转刀 → 收刀“咔”；半片羽毛翻落，敌人上半身碎成黑色碎片，颜色和暖色灯光回来，一行伤害数字 |

用户对特写的反馈：v1 全屏硬切“不协调” → v2 改成“在画面里斩开的分格”。v2 之后用户没再提特写问题，转去做角色动作。
