# 视频原声 · 游戏用片段

从用户选好的六段动作视频中切出的 **16 份声音**，已接入训练场和夜景试玩版。

- 地面第一、二、三刀：来自 `mmh3_action_00014` 的对应动作。
- 强化挑飞、蓄力出刀：使用同一强化动作的原声。
- 空中三刀：分别使用 `空中a` 的三次挥剑，兼容空中上挑使用第一刀原声。
- 左右冲刺：分别使用 `mmh3_冲刺攻击_v2` 的对应方向；原声已有冲刺与挥剑，取消额外叠一层旧冲刺声。
- 格挡、弹刀：来自 `mmh3_左侧格挡_v5` 的两组反馈。**2026-10-26 起弹刀改用 [`../parry/parry_a2.wav`](../parry/README.md)**；这里的 `parry.wav` 仍照常切出留档，格挡不变。
- 拔刀、收刀：来自 `mmh3_拔刀40`，实际播放该动作时才响，被跑动或攻击打断时停止。拔刀结束进入待机时允许金属尾音自然结束。
- 死亡反馈：只取 `mmh3_死亡_v1` 的倒地短声，沿用此前排除中间人声的约定；在游戏死亡事件时响。

文件是 32000Hz 双声道 PCM WAV。只做裁切、短淡入淡出和固定音量调整；没有额外合成层、滤波、随机变调，也不会混入另一招的随机声音。挥剑声音的能量峰值在片段开始后约 50 毫秒，与既有的提前三帧出刀提示对齐；前摇不足三帧时按实际提前量跳过相应开头。格挡/弹刀的峰值提前到开始后约 12 毫秒，避免成功反馈迟响。

没有合适视频片段的脚步、起跳、落地、真实命中、敌人、眩晕、撞墙、远射、蓄力准备、结算等声音保留。被替换的 27 个旧生成变体已从当前文件中移除，仍可通过 Git 历史找回。旧 WAV 中仍用于蓄力、远射或缺文件时兜底的声音保留。

完整原音轨保存在 [原声归档](../../../art/selected-video-audio/README.md)，不覆盖。每个游戏片段的源文件、裁切秒数、音量改变量和 SHA256 见本目录 [manifest.json](manifest.json)。音效库入口为 `assets/audio/sfx_v3/manifest.json`，其中对应事件直接指向这里的 WAV。

重新制作（从仓库根目录执行，需 Python 3.11+ 和 FFmpeg，无额外 Python 包）：

```powershell
python tools/audio/apply_selected_video_audio.py
```

旧工具 `make_sfx_v3.py` 重新生成整个音效库时，也会在最后应用这套原声规则，防止又换回旧声音。

本次验证：原声专项 14、原音效回归 25、命中反馈 52、手感 27、夜战逻辑 50，共 **168 项通过**。另核对 16 个 WAV 的格式、时长、峰值与校验值，以及 44 个保留音效变体与更新前字节完全相同；角色动作、战斗和场景配置没有改动，仅将左冲刺声音单独映射。
