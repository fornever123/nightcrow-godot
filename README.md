# 夜鸦 · Godot 游戏开发版

GitHub 公开仓库：[fornever123/nightcrow-godot](https://github.com/fornever123/nightcrow-godot)。双击根目录 `上传更新到GitHub.bat` 上传已保存的代码、素材与配置。操作说明见 [GitHub更新说明](docs/GitHub更新说明.md)。引擎安装文件、依赖缓存和本地备份不提交。

这是现在要使用的正式工程。E 盘旧角色素材和动作保留，战斗使用 C 盘 Godot 的基础；场景清空，只留下训练木桩。旧工程保留作备份。

## 你只需要双击这两个文件

- `OPEN_GAME.bat`：打开 Godot 游戏。
- `OPEN_MODIFIER.bat`：打开修改器。

文件都在 `E:\00game\nightcrow-godot`。修改器地址是 `http://127.0.0.1:4329/`，启动后会自动打开。不需要 Maker。

## 游戏怎么操作

| 按键 | 作用 |
|---|---|
| A / D，或左右方向键 | 跑动 |
| 空格 / W | 跳跃，可以二段跳 |
| J 点按 | 普攻；及时再按可衔接下一刀 |
| J 长按 | 进入蓄力，松开释放；蓄满也会自动释放 |
| W + J | 上挑 |
| K | 远射 |
| L | 弹刀 |
| R，或右上角重置按钮 | 恢复木桩血量、位置和统计 |
| F1 | 查看攻击判定框 |

木桩不会还手，所以平时无法在这里练弹刀时机。代码中已保留并验证弹刀机制。

## 修改器怎么用

1. **动作工坊**：选动作，点暂停，拖动角色图片就能调整这一帧的位置。勾选“整段一起移动”才会移动整段。滑条和上一帧、下一帧用于定位。
2. **战斗参数**：调伤害、动作速度、命中范围。默认速度 1 倍；改成 1.2 会让动作和攻击判定一起加快。命中停顿单独计算。
3. **素材工坊**：选择图片，可画笔绘制、擦除、裁剪、调色，另存结果。再点“替换动作工坊当前帧”，或回动作工坊的图片列表选择结果。
4. **打击感**：调命中停顿、震屏、受击形变、战斗声音和伤害数字。默认震屏倍率 1.55、停顿倍率 1；单招强度在“战斗参数”中调整。
5. 点顶部**保存并打开游戏**（运行中显示“保存并刷新游戏”）。游戏已经打开时，保存后会自动应用并重置训练。这里的画布预览用于看素材，实际战斗判定以 Godot 游戏为准。

需要替换一整段动作时，在动作工坊选择动作，再导入 PNG 文件夹；文件按数字顺序排列。精灵图集填写一格宽高和总帧数后导入。原图片不会被绘画、裁剪覆盖。

每次保存都有备份。改错可用撤销，或者进入“备份与回收站”恢复历史版本，再保存。正在使用的动作图片不能直接删除，先替换并保存。

## 这次整理了什么

- 使用 Godot 本地运行，去掉 Maker 启动和运行依赖。
- 正式美术目录只有 E 盘夜鸦角色动作和关联紫色刀光，241 张原图未再次压缩或重画。
- 角色默认显示倍率 1，沿用 E 盘 168 高度的角色设置；不同姿势的可见图片高度会变化。
- C 盘的连段、蓄力、远射、弹刀、击退、击飞、撞墙伤害、命中停顿保留。
- 出招和生效窗口按动作帧同步；命中停顿期间同时暂停动作。
- 修改器与游戏共用一个配置文件，保存后自动生效，不再分别编辑两套数据。
- 图片只加载一次；其余动作分批缓存。修改器前端只在源码变更时构建，正常打开不重复构建。

上挑、空中上挑、弹刀和远射目前复用现有动作或基础图形，后续需要补专门美术。这里只做木桩训练场，未加入新关卡或玩法。

下一步建议先在这个版本里确定三段攻击的速度和命中范围，再补上挑、弹刀、远射的动作与特效。

开发交接细节见 `docs/开发交接.md`。

## 去绿边修复 · 2026-10-10

角色原图有绿幕抠图残留。游戏与修改器现使用 assets/image/cleaned/nightcrow 下的 218 张去绿边副本，原有 241 张角色及刀光图片保留不动。只校正污染的绿色通道，并补齐完全透明像素下的边缘颜色；图片尺寸、所有透明度值与动作固定点保持原样。刀光素材未更改。

## 清晰度修正 · 2026-10-10

当前角色源帧本身较小（待机为 116×168），大幅放大不能恢复原本不存在的细节。角色显示方式已改为 nearest（像素硬边），原图不重新缩放或压缩。动作工坊画布按实际显示尺寸 × 屏幕像素比建立绘图缓冲，避免预览反复缩放柔化；拖动仍沿用原 900×460 编辑坐标。刀光保持平滑显示。可在“图片显示方式”切换回原画平滑。

Canvas 屏幕适配参考：https://developer.mozilla.org/en-US/docs/Web/API/Window/devicePixelRatio#correcting_resolution_in_a_canvas 。
